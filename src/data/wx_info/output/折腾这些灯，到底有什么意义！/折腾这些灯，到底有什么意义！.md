# 折腾这些灯，到底有什么意义！

在很多人的想象里，动物园的工作似乎并不复杂。给动物准备食物、打扫场馆、照顾健康，再为它们打造一个舒适的环境——只要足够用心，好像就能把动物照顾好。但真正走近这些工作时，事情远没有那么简单。动物园的环境在两种常见的状况之间摇摆，动物既不完全在野外，但也不是被驯化和长期圈养的物种。

这也意味着如果不去深入思考，就很可能会把动物园的目标简化为完全地模拟自然。而动物园工作的难点，恰恰在于不断放下人的经验，重新学习动物的需求。

红山森林动物园野生动物收容救护中心两栖与爬行类动物饲养员-朱鑫钰大家好，我叫朱鑫钰，是红山动物园野生动物收容救护中心的一名饲养员。
我的主要工作，是负责两栖爬行动物的饲养管理以及救助。
接下来会有一场灯光体验。
![Image](images/img_001.gif)
这个灯光是故意要闪大家的。因为我们的动物，可能就是生活在这样的光环境当中。
在我的身旁，是一个灯具框架。接下来，我会带领大家一起去看一看，在动物园里，动物眼中的世界到底是什么样子的，它们又生活在什么样的灯光之下。
![Image](images/img_002.png)
这是一个白炽灯。在LED灯普及之前，我们家里使用的就是白炽灯，动物园里也一样。过去很多动物园，都是用白炽灯来给动物内舍提供照明。
![Image](images/img_003.png)
在爬行动物饲养中，白炽灯虽然能够提供热量，但单个灯泡覆盖范围太小，所以我们通常会增加更多的白炽灯。比如浴霸灯泡和卤素灯。
![Image](images/img_004.png)
这样一来，我们解决了动物照明和加热的问题。
但问题依然存在：只有白炽灯的世界还是太暗了，像一个无尽的黄昏。对于昼行动物来说，如果一直生活在黄昏之中，它们可能根本不知道一天进行到了什么时刻，也不知道自己应该做些什么，这是非常不好的。
所以，我们做的第一步改造，就是提高亮度，这是一个LED灯。当我们打开它以后，就初步解决了亮度不足的问题。
![Image](images/img_005.jpg)▲不同类型的LED灯具

它是一盏全光谱LED灯，但这里有一个问题，它所谓“全光谱”，其实是针对人类设计的。
![Image](images/img_006.png)▲现场LED灯的光谱图

对于人类来说，我们拥有三种视锥细胞，因此只能看到由三种颜色组合而成的世界，但很多动物还能看到一种我们看不到的东西——紫外线。
![Image](images/img_007.png)▲人类和鸟类的视锥细胞可感受到的光谱范围

缺少紫外线对动物来说意味着什么？
大家不妨把视线转移到这几个苹果上。在正常光照下，我们看到它们的颜色都比较正常。但如果放到偏色光环境下，大家还能很清楚地分辨出哪个苹果更成熟吗？
![Image](images/img_008.png)▲在蓝光下几乎无法分辨出苹果是红色还是黄色的

对于动物来说，也是一样的。紫外线的缺失，会让动物眼中的世界变得没有那么清晰。
这张图模拟了成熟浆果在人类和鸟类眼中的视觉效果。左边是人类眼中的浆果，中间是紫外线摄影下的浆果，而右边则是模拟鸟类眼中的浆果。更加鲜明的颜色，可以帮助鸟类更有效地寻找食物。
![Image](images/img_009.png)
同样，紫外线也会影响动物的繁殖。
比如说，安乐蜥的喉扇以及身体上的斑纹，还有虎皮鹦鹉头部的羽毛，都会因为紫外线的存在而显得更加耀眼。而这些特征，恰恰有助于它们吸引异性。
![Image](images/img_010.png)
说到紫外线，大家最容易想到的可能还是防晒。因为紫外线会促进皮肤合成黑色素，让我们变黑，所以大家都希望防晒。
但紫外线还有一个非常重要的作用。它能够帮助皮肤合成维生素D，而维生素D会直接影响骨骼发育。
![Image](images/img_011.png)
这张图是一只苏卡达陆龟，它是我们救助的一个个体。大家可以看到，它的背甲高高隆起，这是典型的代谢性骨病特征。
![Image](images/img_012.png)
当时兽医检查时发现，它的整个腹甲都已经变软了。轻轻按压，就会发生弹动。甚至会让人产生一种感觉：似乎稍微用一点力，它的甲壳就会碎掉。
因此，我们第一时间为它口服补充了维生素D。但更重要的，是提供合理的光照环境，让它能够自主合成维生素。
如今，这只陆龟已经恢复健康，重新回到了它的族群当中，甚至开始出现交配行为。
总有人问我：“龟蛋是软的吗？”
其实是硬的，大家可以听一下乌龟在下蛋时蛋壳碰撞的声音，非常清脆，而形成这样的蛋壳，需要大量钙质，这同样深受紫外线影响。

当我们拥有了浴霸灯、LED灯以及紫外线灯之后，对于动物来说是不是已经足够了呢？
![Image](images/img_013.png)▲全部灯具展示

其实这里还隐藏着两个不容易发现的问题。
第一个问题，就是频闪。也就是刚才大家体验到的那种闪烁感。
![Image](images/img_014.gif)
因为现在的灯光是为人设计的，灯具参数也是按照人眼来调节的。所以我们看起来不闪的灯，对于很多动物来说，可能是闪烁的。比如鸟类，还有一些依赖高速动态视觉进行捕猎的动物，比如变色龙。它们眼中的世界，可能更接近刚才大家体验到的状态。
但是我们并没有把之前的旧灯全部淘汰。相反，我们通过增加整流器等方式减少了部分频闪问题。
第二个问题，是光与热量的不一致。
当我们安装了这些灯具之后，我们发现，鬣蜥总喜欢待在环境中最亮的位置，而不是我们希望它待的地方。
![Image](images/img_015.png)▲喜欢待在亮度集中区的鬣蜥

鬣蜥不会想，我今天想晒晒紫外线。或者我今天有点冷，要去加加热。对于它来说，最亮的地方，就意味着阳光所在的地方。而阳光下，本来就应该同时拥有光和热。
因此，我们重新调整了每一个灯具的角度，尽量保证光和热来自同一个区域。这样，这个问题也得到了解决。
带着前期实验积累下来的经验，我们开始把这些照明方案应用到场馆当中。
比如大家现在看到的这个非洲之歌辐纹陆龟展区，看上去已经非常完善了。上方安装的灯具数量，甚至比今天现场还要夸张得多。
![Image](images/img_016.png)
但新的问题又出现了，那就是灯光的开启和关闭。
大家想象一下，如果你早上还没睡醒，突然有人打开房间里的灯，你一定会被吓一跳。对于动物来说也是一样，突然变亮的环境，会刺激它们的眼睛，也会让它们受到惊吓。因此，我们又进行了新的改进。
接下来，我们一起看一看辐纹陆龟的一天是如何度过的。

总有人问我：“你折腾这些灯，到底有什么意义？”“你的动物真的因此变得更好吗？”
我想举一个在饲养过程中见到的例子。
在我身后的照片里，是一只正在偷偷晒灯的大壁虎。去过西双版纳或者东南亚的朋友，可能听过大壁虎的叫声。就是这样的声音。

为什么说它是偷偷晒灯呢？
因为大壁虎一直被认为是一种夜行动物。以前饲养它的时候，我们给它一个树皮洞穴，再配一个小盒子，它就在里面生活，这样似乎也能活得不错。
![Image](images/img_018.png)
但后来我们开始思考：既然我们已经为其他动物做了这么多灯光改造，为什么大壁虎不能拥有这些呢？于是，我们开始给它提供更加完整的照明环境。
结果发现，大壁虎居然会主动晒灯。它并不像我们想象的那样，白天睡觉、晚上活动，一辈子都见不到阳光。实际上，每天早上开灯之后，它都会跑到一个不容易被人发现、同时又方便逃跑的位置，静静地晒灯。而这一晒，往往就是八个小时。
在圈养条件下，我们反而有机会观察到一些在野外并不容易发现的自然行为。而这也意味着，我们在改造灯光的过程中，不仅仅是验证我们旧有的知识，更在拓宽我们认知的边界。
对于那些长期、甚至终生生活在室内环境中的动物来说，我们有责任为它们创造一个更接近自然、更符合需求的世界。
谢谢大家。
