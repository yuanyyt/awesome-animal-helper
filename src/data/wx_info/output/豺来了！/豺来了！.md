# 豺来了！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)

今天就带大家一起认识

**红山唐家河展区**的新住户

![Image](images/img_005.png)![Image](images/img_006.jpg)

**从广州动物园来的豺兄妹**

![Image](images/img_007.png)

**豺 来啦！**

豺，是犬科中体型中等的成员，整体大小介于狗与狼之间，但明显小于狼。

![Image](images/img_008.jpg)

它们的吻部比狼短，头骨更宽，额头平缓；耳朵呈半圆形，不像狼那样尖耸，也不似赤狐那般大而直立。尾巴长度略超狼尾，但仍不及体长的一半，尾毛浓密蓬松，形态上确实有几分狐尾的影子。

![Image](images/img_009.png)![Image](images/img_010.jpg)

狼与豺

在毛色上，豺身体背部与体侧呈鲜明的砖红、棕红至红褐色，腹部颜色稍浅；嘴周和下颌覆盖着一圈明显的白色毛发，耳廓内侧也为白色。

![Image](images/img_011.jpg)

豺的耳背颜色与颈背一致，为红褐色或棕褐色，这与赤狐耳背呈黑色的特征形成清晰区分。尾巴则多为灰黑至纯黑色，与红褐色的躯干形成强烈对比。

![Image](images/img_012.png)![Image](images/img_013.jpg)

赤狐与豺

**每一次靠近****都是信任信号～**

刚来到红山唐家河展区时，陌生的环境和陌生的饲养员让豺兄妹格外警惕。一点轻微的声响，他俩就会立刻缩进角落，竖起耳朵。

![Image](images/img_014.jpg)

为了帮助他们平稳度过这段适应期，饲养员并没有急于靠近，而是选择了“先观察，少打扰”的策略。前期主要通过监控远距离观察他们的精神和身体状态，给予充足的时间让他们熟悉内室环境。

![Image](images/img_015.jpg)

几天后，待他们的紧张感稍有缓和，饲养员开始将食物慢慢移至通道处。一开始，兄妹俩谁也不敢出来，只敢远远观望。

![Image](images/img_016.jpg)

直到片刻后，胆子稍大的哥哥终于忍不住了，率先打破僵局。他探出身，确认安全后火速冲上前叼起肉块，转身就缩回了内室；妹妹望着哥哥吃得香甜，几番犹豫后，终于鼓足勇气探头探脑地跑出来，叼起食物“嗖”地一下就躲了回去。

![Image](images/img_017.jpg)

当豺兄妹彻底适应通道环境后，饲养员便引导他们逐步进入缓冲区，脱敏计划也随之推进到第二步：**对人的脱敏**。

饲养员并不急于靠近，只是安静地站在笼舍外围，偶尔出现，让豺逐步习惯人的存在。起初，豺兄妹连望向饲养员的勇气都没有，不敢对视。

![Image](images/img_018.jpg)

慢慢发现周遭没有任何危险，熟悉的食物气味又持续勾着食欲，豺兄妹的戒备心开始悄然松动。饲养员先把肉放到网架上，随后默默退到十米开外，给兄妹俩留出足够的安全感，耐心等待着他们迈出试探的一步。等脚步声远去，豺兄妹才敢小心翼翼上前取食。

![Image](images/img_019.jpg)

日复一日，饲养员始终保持着同样的耐心与节奏。放食、后退、等待、记录。距离一点点缩短：从十米，到五米，再到三米…就这样兄妹俩的眼神里少了几分戒备。饲养员察觉到这份变化，依旧没有急于推进，只是在他们取食时，保持着同样的静止姿态，用无声的陪伴传递着“你是安全的”信号。

终于有一天，他们愿意接受饲养员用长夹子递来的食物，直接在网边吃下。这是信任建立的重要里程碑。

在此基础上，训练悄然升级为**定位训练**：饲养员手持目标棒，引导豺走到指定位置，一旦到位，立即给予食物奖励。

![Image](images/img_020.jpg)

从起初豺兄妹还带着几分犹豫到之后每一次准确的停驻，都是信任的又一次确认与加深。这也为后续的日常照料、健康监测打下了坚实基础。

![Image](images/img_021.jpg)

**腿在抖  心在飞**

**勇敢迈出第一步**

随着定位训练日渐熟练，豺兄妹的行为日趋稳定，对环境也越发熟悉，饲养员决定让豺兄妹试着走进外场，熟悉新的空间。

那天，外场的闸门缓缓拉开，阳光带着草木的清新气息涌了进来。哥哥站在门口，身体带着几分谨慎，四肢微微颤抖，迟迟不敢跨出那道“安全线”。可他的脑袋却忍不住一探再探，眼睛滴溜溜地打量着外面，新鲜又陌生的一切。

脑袋和四肢就是各有各的想法

饲养员始终静立在原地，没有发出任何声响，也没有做出任何靠近的动作，耐心地陪伴着他们，给予他们慢慢适应的空间。

哥哥嗅了又嗅，确认空气中只有草木的清香与熟悉的饲养员气息，没有任何陌生威胁，紧绷的身体悄悄舒缓了些许。

紧张与好奇激烈拉扯，

**最终，好奇心赢了。**

他试探性地抬起前爪，轻轻点了点外场的土地，感受到脚下松软的触感毫无异常后，便一步步小心翼翼地踏了进去。紧随其后的妹妹，见哥哥已然确认安全，也鼓足勇气，跟了出来。

![Image](images/img_022.jpg)

初入外场，哥哥仍带着犬科动物天生的谨慎，却没有了最初的过度紧绷。他沿着展区边缘慢慢巡视，每走几步就会停下嗅闻周遭气息，确认没有陌生威胁；最后站上石山，昂首环顾四周，耳朵轻轻转动着捕捉声响。

![Image](images/img_023.gif)

饲养员耐心等待着他们

按照自己的节奏熟悉这片天地

外场里错落的石山、茂密的灌木丛和精心设置的巢箱，都是饲养员根据豺的自然习性特意布置的隐蔽空间，为的就是让他们在开阔环境中也能随时找到“安全角落”。

豺兄妹很快发现了这些藏身之处。起初他们只敢在边缘徘徊，但一天、两天……随着对环境的熟悉度不断提升，他们的步伐渐渐稳了，眼神也愈发从容。如今，他们不再只是躲藏，而是主动穿梭于石山与草丛之间，嗅闻、刨地、巡视领地，探索欲悄然萌发，自在感也一点点生长。![Image](images/img_024.jpg)

在阳光下追逐嬉戏，甚至主动衔起饲养员铺好的羊草，拖到自己喜欢的角落，认真地重新铺成一个柔软的小窝。

不过，他们的适应之路仍在继续。这份不疾不徐的适应节奏，恰恰是野生动物最真实的状态，也被饲养员看在眼里、记在心里。

![Image](images/img_025.jpg)

行为愈发从容自然

未来，饲养员对于他们地外场还将根据他们的习性与喜好持续优化，让每一次探索都充满意义，让每一份天性都能自由表达。

![Image](images/img_026.jpg)

生命的适应，

从来不是一蹴而就的跨越，

而是一次次微小的信任累积。
