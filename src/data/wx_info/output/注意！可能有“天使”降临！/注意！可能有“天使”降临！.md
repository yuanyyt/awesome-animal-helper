# 注意！可能有“天使”降临！

![Image](images/img_001.png)![Image](images/img_002.jpg)

如果大家最近从红山动物园的南门入园，可能会注意到有一道特殊的检票口，撑着一顶醒目的保护伞，上方写明了此伞为“天使伞”。

这究竟是一把什么伞？它要守护谁？

***PART.1***

![Image](images/img_003.png)

**神秘的空投“天使”**

![Image](images/img_004.png)

故事要从今年开春说起。

我们南门检票口的工作人员发现有一道检票口的地面上，总是出现鸟粪。上午擦，下午有；今天擦了，明天还有。

实锤了！这上面肯定有小鸟筑巢！

检票员们仔细检查了南门门头，头顶上方的枝叶间，真的藏着一个鸟巢！

![Image](images/img_005.jpg)

南门上有个鸟巢~

经辨认，巢主是一对正处于育幼期的山斑鸠。

说到斑鸠，大家可能第一时间想到的是那位“鸟界潦草系顶流”——珠颈斑鸠。多年来，珠颈斑鸠凭借“几根树枝敷衍了事、巢比脸还平”的筑巢风格火遍全网，常年霸占“鸟巢差评榜”榜首。

![Image](images/img_006.jpg)

野外山斑鸠的巢

但同为斑鸠家族成员，山斑鸠可要讲究得多。它们偏爱树林、灌木丛等自然环境，巢材除了树枝，偶尔还会精心添上几根草茎、几片树叶，颇有几分“软装设计师”的意思。筑巢位置也很有讲究，喜欢在平展的树杈上做一个规规矩矩的盘状巢，方方正正，稳稳妥妥。

![Image](images/img_007.jpg)

表面稳妥，实际上还是垂下了一撮原材料~

而选择在南门上方筑巢的这对山斑鸠显然是“选房高手”中的“高手”。它们相中的这个位置，正好位于枝杈交错处，相当于天然的树冠层，隐蔽性极佳，还完美实现了风吹不到，雨淋不着，日晒不着。

我们考察后一致感叹：这对斑鸠，是真的会挑地方！

![Image](images/img_008.jpg)

是块好地方~

南门门头不仅征服了山斑鸠夫妇，还吸引来了不少“看房客”。白头鹎等城市常见鸟类也时不时飞来转悠几圈，前来考察。

其实，白头鹎、斑鸠这些早已适应城市生活的鸟类，非常善于利用城市建筑中的各种结构来筑巢。这不，红山动物园的南门门头就因其质感和结构，成为了它们心中理想的“楼盘”。

***PART.2***

![Image](images/img_009.png)

**“天使”降临与“天使”保护伞**

![Image](images/img_010.png)

说到这“天使”降临，在雏鸟还未出巢的日子里，南门地面反而很干净。因为山斑鸠亲鸟有着较为良好的卫生习惯。它们会主动吃掉或叼走雏鸟排出的粪便，飞到远处丢弃，从而保持窝的干净、干燥、舒适。这番操作自然让那个阶段的南门风平浪静，岁月静好。

然而，真正的“天使降临”，是在雏鸟出巢之后。

![Image](images/img_011.jpg)

两只刚出巢的小斑鸠

两个小家伙渐渐长大，羽翼渐丰，它们到了出巢的阶段。刚出巢的雏鸟会在附近的小树枝上四处探索。但它们可没有“定点排便”的意识，于是，那道检票口的地面上，开始频繁出现鸟粪的痕迹，随机掉落，防不胜防。

我们算了一下，按照山斑鸠一年繁殖2-3窝的节奏，这对山斑鸠夫妇很可能会继续在这里“添丁进口”。也就是说，未来一段时间内，这道检票口将持续面临“天使降临”的风险。

![Image](images/img_012.jpg)

一正一反的两只小斑鸠

既要保护野生动物，又要保障游客的通行体验，怎么办？总不能把鸟巢拆了吧！这可是受国家保护的有重要生态、科学、社会价值的陆生野生动物。更何况，小鸟又能有什么坏心思呢，就是想在这筑个巢、养个娃呗~

于情于理，我们都得让着点。

![Image](images/img_013.jpg)

于是，经过连夜赶工，一顶特制的“天使保护伞”在南门检票口上方支棱了起来。

这顶伞既不影响游客正常通行，又能有效阻挡“天降祥瑞”。伞的上方还简单说明了一下情况~毕竟，万一真有游客被“幸运”砸中，至少也要知道自己是沾了哪位“邻居”的光呀~

![Image](images/img_014.jpg)

“好邻居”本邻

从南门新区建设之初，麻雀利用建筑缝隙和空调管道衔草筑巢，繁育后代（[非洲的地盘怎么出现了本土“居民”？](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650868262&idx=1&sn=f9170278e7698d04d76e8542a5b27cc2&scene=21#wechat_redirect)）；到山斑鸠选择在南门“安家落户”，再到白头鹎等鸟类纷纷前来“考察”......

![Image](images/img_015.gif)

南门新区的麻雀在门缝里筑巢

城市中的小鸟们似乎都在用自己的方式解读这座城市。这座城市不止是我们的家，也是野生动物的家。

![Image](images/img_016.jpg)

一“腚”相见

下次你来红山，走到那道撑着“保护伞”的检票口时，记得抬头看一眼，也许上面正有一窝小生命，在悄悄打量着这个它们也参与其中的世界。

如果你刚好被“天使”选中了……嗯，就当是山斑鸠送你的一份特别见面礼吧~
