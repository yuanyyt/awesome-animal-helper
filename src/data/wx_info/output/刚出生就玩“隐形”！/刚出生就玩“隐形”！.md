# 刚出生就玩“隐形”！

![Image](images/img_001.png)

是谁家的小猴一出生，
连饲养员都得擦亮眼睛仔细看，
嵌在妈妈怀里连影子都藏！
小尾巴一缠，安全带已挂，
小太阳悄悄来啦～

![Image](images/img_002.jpg)

**是谁出生又隐身了？**

在红山冈瓦纳，生活着温馨的红脸蜘蛛猴一家：雄性南南，雌性美美、红红，以及美美的女儿小美好。最近他家又迎来了新成员啦！

![Image](images/img_003.jpg)

2025年11月12日，在历经约230天的孕期后，红脸蜘蛛猴妈妈红红顺利诞下她与南南的第一个孩子。这个新生命，饲养员给它取名为“红阳”，“红”是妈妈名字的延续；“阳”则寄寓朝阳初升之愿，盼其向阳而生，康健顺遂。

![Image](images/img_004.jpg)

红红与红阳

刚出生的红阳，自带“隐身技能”！它通体乌黑，和妈妈红红的深黑毛发几乎无缝衔接，一直紧紧贴在红红的臂弯与胸腹间吮吸乳汁，身形和母体贴得极近，就连饲养员初期都要仔细找，才能发现它的踪迹。

![Image](images/img_005.jpg)

“隐身技能”

那怎么确定这个小家伙

安全地待在妈妈怀里呢？

有一个小妙招：看幼崽那条灵巧的尾巴！它会像“第五只手”一样，一会儿牢牢缠绕在妈妈的尾巴根部、一会儿绕在腰间，一会儿又固定在大腿根部...随着妈妈的活动不断调整位置，如同一条天然的“安全带”，稳稳固定住自己。

![Image](images/img_006.jpg)

看见缠腰的尾巴了嘛

凑近看，刚出生的它脑袋圆滚滚的，尾巴上没有绒毛，皮肤乌黑又光亮。随着它的成长，会慢慢长出浓密的黑色毛发，而红脸蜘蛛猴标志性的绯红小脸，也会渐渐显露出来。

![Image](images/img_007.jpg)

“黑卤蛋”

**不打扰是最深的守护**

新生命诞生的第一天清晨，一家猴来到外场，安静地坐在一起。美美小心翼翼地伸出手，轻轻摸了摸红阳的小脑袋。但你知道吗？这温情一触，在红脸蜘蛛猴家族里竟格外珍贵。

![Image](images/img_008.jpg)

定格温暖（难得）的瞬间

与川金丝猴“全群育幼”的热闹不同，红脸蜘蛛猴没有“阿姨帮忙带娃”的行为。

![Image](images/img_009.jpg)

自红阳出生起，整个家族便默契地选择了另一种温柔：互不干扰，不围观、不触碰、不插手。这不是疏离，而是一份体贴的留白，只为给新手妈妈红红一个安静、安心的育幼空间。

![Image](images/img_010.jpg)

爸爸南南虽然不直接参与带娃，却扛起了“守护”的职责，频繁巡查活动范围的边界，时刻警惕周边动静，保护着整个家。

![Image](images/img_011.jpg)

偶尔，好伙伴美美也会为她梳理毛发，在忙碌育幼的间隙，送上片刻温柔的陪伴。

![Image](images/img_012.jpg)

而如今以两岁多的小美好，这段时间也悄悄变独立了，不再时时刻刻黏着妈妈美美，能自己进出内室通道，还能独自灵活地在树干和绳索间穿梭，自信探索属于自己的小天地。

![Image](images/img_013.jpg)

自己玩耍啦！

就连同住一片区域的松鼠猴们，那阵子也仿佛心领神会，减少了靠近，把宁静留给这个正在适应新身份的红红。

![Image](images/img_014.jpg)

**新手妈妈的“慢”生活**

虽然家族选择了“静默守护”，

但妈妈红红的爱，

却热烈而坚定。

第一次当妈妈的红红，护崽属性直接拉满。从红阳出生那一刻起，便开启了“全天候警戒模式”。

![Image](images/img_015.jpg)

曾经那个和南南在绳索间灵巧荡跃的身影不见了，取而代之的，是缓慢、稳重、每一步都小心翼翼的攀爬。

![Image](images/img_016.jpg)

抱的紧紧的

无论是在高高的广玉兰枝杈上晒太阳，还是穿行于栖架之间、安静休憩，她与红阳始终互相牢牢搂住。

![Image](images/img_017.jpg)

就连觅食，红红也悄然改变习惯：不再挤在群体中争抢，而是主动避开热闹，安静地独自取食饲养员分散放置在各处的食物。

![Image](images/img_018.png)

在妈妈怀里倒挂，打量周围的环境

面对南南先占据的悬挂式取食器，红红也有小智慧，不慌不忙地在下方等候，接住掉落的食物，趁机捡漏。

![Image](images/img_019.jpg)

给幼崽理毛的红红

红脸蜘蛛猴幼崽的成长速度比较慢，出生两个月后的红阳，依旧黏在妈妈怀里不肯撒手。

只有当红红轻轻挪动身子，或轻盈跃过枝叶时，红阳乌黑的小脑袋才会偶尔探出来，带着一丝好奇，一丝谨慎，打量周围的环境。

![Image](images/img_020.jpg)

曾凭乌黑毛色“隐身”的它，

现在已经悄悄露出脑袋啦！

不知前来探访的你，

是否已然寻得它的踪迹？

欢迎在评论区分享你拍到的红阳。

让我们汇聚这些瞬间，

陪着它一起慢慢长大吧！
