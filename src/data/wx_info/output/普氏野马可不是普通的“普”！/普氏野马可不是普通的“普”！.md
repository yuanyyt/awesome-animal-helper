# 普氏野马可不是普通的“普”！

![](images/img_001.png)![](images/img_002.png)![](images/img_003.gif)![](images/img_004.png)![](images/img_005.png)![](images/img_006.jpg)

提起马，我们首先想到即将迎来的马年春节，以及中华文化中那些非常鲜活的印记。

马对我们来说是潇洒肆意的象征。但在我们熟悉的骏马形象之外，还有一种“野性”的存在——它们就是被视为现存与原始野马亲缘关系最近的***普氏野马***。

![](images/img_007.png)

**一**

**“普”可不是普通的普!**

![](images/img_008.png)![](images/img_009.jpg)

© 花落成蚀

普氏野马这个听起来有些“普”的名字，来源于它的发现者沙俄探险家**尼古拉·米柴洛维奇·普热瓦尔斯基**于亚洲中部的探索发现。其后，学者**波利亚科夫**根据其提供的皮张及头骨标本，于**1881年**将这种普热瓦尔斯基发现的野马正式命名为——**普氏野马**。

普氏野马与家马最显著的差异在于普氏野马头部比例更大，咀嚼肌发达，鬃毛短而直立，且额部没有家马飘逸的“刘海”。身材较家马也更矮小更粗壮，毛色呈浅棕至红褐色，四肢通常为深色。它们的形象和家马相比也更显精神利落，颇有一份憨厚的气质。

![](images/img_010.png)![](images/img_011.png)

普氏野马不仅是国家一级保护野生动物，更是马属家族中保留原始基因的“活化石”。

它们并不是家马的“野外版本”！从基因层面看，它与我们熟悉的马有着清晰的区别。现代家马的染色体数量是64条，而普氏野马是66条。当人类开始选择性繁育马匹，用于运输、耕作和战争时，普氏野马沿着完全不同的方向继续存在。

它们一直在努力生存、繁衍，也在适应环境，它们是没有被外力强行改写原本的演化路径的神奇物种。它们在贫瘠、寒冷、干旱的荒漠—草原环境中书写的生命故事，一点都不普通！

![](images/img_012.gif)![](images/img_013.png)

**二**

**野马独苗，风雨飘摇**

![](images/img_014.png)

在亚欧大陆中纬度的草原与荒漠的记忆深处，野马曾是一个时代的象征。但随着人类捕杀及农牧业的冲击，荒野上的野马相继消失。

1876年，最后一匹欧洲野马倒在乌克兰草原上时，西方世界郑重宣告：***所有野生马已永远成为历史。***

直到**1878年**普热瓦尔斯基的发现，让普氏野马再度跑进了人们的视野之中，它们也成为世界上野生马种的“独苗”。但这份惊喜的野性的发现，也为野马种群带来了更深重的灾难。

在巨大利益的驱使下，西方贵族和商人纷纷派出探险队，捕获大量野马幼驹，猎捕过程导致了大量野马的死亡，普氏野马种群数量急剧下降。加上人类活动造成的草场退化，普氏野马在20世纪60年代末于野外绝迹，被一度认定为野外灭绝。而被捕获的野马经过长途运输，到达欧洲时仅剩53匹存活。

![](images/img_015.jpg)

© 花落成蚀

这53匹成为了普氏野马仅存的血脉。伴随着饲养繁育经验的匮乏，当时普氏野马的繁殖遇到了巨大的困难，圈养种群岌岌可危。

直至战后，随着国际动物园行业的交流和谱系管理的规范，普氏野马圈养种群数量回升，截至1990年，圈养种群数量达到961匹，使普氏野马暂时摆脱了彻底灭绝的局面。它们也得以有喘息的机会，重新谱写一篇荒野归来之章。

![](images/img_016.gif)![](images/img_017.png)

**三**

**漂泊百年，归来重生**

![](images/img_018.png)

普氏野马回归自然的历程颇为艰难，因为水草丰美的故土现已被家畜占据，偏僻的荒野才是它们的容身之所。并且普氏野马野外面临着酷暑、严寒、干旱、饥饿等严峻威胁。在野外，它们的身影已十分罕见。

它们最后的踪迹，出现于中国新疆准噶尔盆地至蒙古国西部的荒漠草原。尽管中国科学家长期寻找未果，但希望从未熄灭。

**1981年**，林业部在准噶尔盆地正式设立卡拉麦里有蹄类野生动物保护区，野马回归的梦想，终于提上了国家保护议程。

**1985年**，真正的转折出现了。我国引入18匹普氏野马，在新疆吉木萨尔县成立新疆野马繁殖研究中心，启动了一项“野马返乡计划”的保护工程。

**2000年**，在卡拉麦里山自然保护区北部划定野化放归区域。

**2001年8月**，首批27匹普氏野马重返阔别百年的故土。

**2003年春天**，放归的野马种群实现野外自然繁殖，标志着重引入项目取得关键突破。

此后的20多年间，18批共146匹普氏野马相继从繁育基地放归荒野，在卡拉麦里建立起28个野外种群。

如今，中国境内的普氏野马数量已突破900匹，占全球总数近1/3，成为世界濒危物种保护史上的一座里程碑。

![](images/img_019.jpg)

© 花落成蚀

普氏野马一度从这片土地上消失，如今它们再次回到了戈壁与草原。它们的故事不再是历史长河的一生哀叹，而是一条始终向前延伸的生命脉络。

当我们为普氏野马让出足够的荒野，它们便依然能在自己的轨迹上，续写生生不息的野性传说。

![](images/img_020.gif)![](images/img_021.png)

**四**

**野马能有多“野”呢?**

![](images/img_022.png)

在严酷的荒漠环境中，普氏野马发展出了令人惊叹的生存策略。它们以家族为单元，结成5-20匹的稳定群体，有着严格的社会等级。

家族群由一匹成年的优势公马、数匹成年雌马及其后代组成。身强力壮的公马作为守护族群的“头马”，雌马之间也有等级秩序的划分，高等级的雌马会带领族群高效寻找食物和水源。

为了适应严酷的野外环境，普氏野马能忍受长时间的饥渴，毛色会随季节由夏季的浅棕转为冬季的红棕。冬季来临前，普氏野马会长出致密的绒毛层和粗长的护毛，有效抵御寒风，隔绝严寒，夏季则换上短毛，便于散热。

荒漠环境中水源尤为稀缺，普氏野马可以忍受3~4天不喝水，还能在风中感受水的气息，找到隐蔽的水洼，并且可以饮用一定矿化度的盐碱水源，能在无水情况下依靠多汁植物存活数日。

它们的食谱也写满了适应荒漠的智慧，野外以针茅、羊茅、冰草等禾本科植物，以及驼绒藜、梭梭、芨芨草、芦苇等荒漠灌丛植物为食，依赖荒漠戈壁中斑块状的草原植被，冬季还会刨开积雪觅食枯草。

![](images/img_023.jpg)

© 花落成蚀

每年6月是它们的繁殖季节，到第二年春天，新生的幼驹在几小时内就能站立奔跑，跟随族群在辽阔的荒野中创造生命延续的奇迹。

![](images/img_024.gif)

如今，在马年到来之际，我们以**“神马” 都吉祥**为主题，将开启一系列科普活动。本篇作为**“神马”都知道——马年主题科普展**的其中之一，聚焦普氏野马野外种群保护历程，分享普氏野马保护成果及重要意义。

愿普氏野马所象征的原始生命力与自由精神，如同戈壁的风裹挟着不竭的生机，成为我们对新一年的美好祝愿。
