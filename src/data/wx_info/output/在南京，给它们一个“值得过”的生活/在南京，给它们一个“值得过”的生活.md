# 在南京，给它们一个“值得过”的生活

![](images/img_001.jpg)

在南门新区的马岛客厅充满了生活气息，让大家切身感受到了马岛的生活氛围。而有一间看起来有些复杂精密的操作间，不由得让人心生疑惑，这里是什么？

![](images/img_002.gif)![](images/img_003.gif)

**辐纹陆龟：来自马达加斯加的星光**

![](images/img_004.gif)

这里是属于辐纹陆龟的展厅，展示辐射陆龟的育幼所需的环境。目前这里生活着两只幼年辐纹陆龟。2025年1月，它们出生于红山森林动物园的救护中心，其亲代因罚没或弃养而被救助多年。

![](images/img_005.jpg)

生活在马岛客厅里的两只幼年辐纹陆龟

辐纹陆龟原产于马达加斯加岛南部干旱的多刺森林，被誉为“世界上最美丽的陆龟”之一。它们背甲上那如旭日般放射的金黄色纹路，在深黑底色的映衬下熠熠生辉。这身华丽的外衣，是数百万年演化的结果，与它们独特的家园紧密相连。

它们的家园干旱、缺水，而它们演化出了强大的适应性：在长达7个月的旱季末期，它们会大规模聚集在干涸的河床上，等待雨水汇集于此。

![](images/img_006.png)

马达加斯加南部的辐纹陆龟

其繁殖周期也与旱雨季密切相关。雌龟会在雨季末产卵，而龟卵会在旱季进入“滞育”状态，这一精妙机制确保幼龟总能在下一个雨季到来时才破壳而出。此时植物复苏，食物和水源都最为充沛，从而极大地提升后代的存活率。

然而，曾经是世界上数量最多的陆龟之一的辐纹陆龟，现在正面临严峻的生存危机。在过去几十年里，其种群数量锐减了80%，被IUCN列为极度濒危物种。

首要威胁便是捕杀和贸易。成年龟被大量猎杀作为食物，幼龟则因其美丽外表被非法捕捉，以满足国际宠物贸易的需求，形成了对其种群的双重打击。与此同时，伐木、放牧、种植等人类活动，也使得它们的栖息地减少了三分之一。如果没有紧急有效的干预，辐纹陆龟可能在未来20年内于野外功能性灭绝。那背甲上的星芒，正在故乡的天空下急速黯淡。

![](images/img_007.jpg)

生活在救护中心的成年辐纹陆龟

因为贸易，它们来到了这里，且难以回归故乡。除了栖息地丧失、非法贸易从未停止等现实的威胁，还有它们在辗转于人类饲养与流通环节后，它们可能携带原栖息地不曾出现的病原体。若贸然放归，可能会对本土种群产生威胁。

![](images/img_008.jpg)

辐纹陆龟展厅

它们也许再也无法重返故土。既然无法返回，目前我们能做的，也只有在这里为它们创造一个适宜的环境，让它们在南京能过上“值得过”的生活。

![](images/img_009.gif)![](images/img_010.gif)

**辐纹陆龟的南京生活**

![](images/img_011.gif)

然而，在南京想给这些陆龟提供一个值得过的生活并不容易。南京的气候、环境都与辐射陆龟的家乡相差甚远。要想还原它们原本生活的环境，需要付出很多远超想象的精力和花销。

![](images/img_012.jpg)

多层疏水

大多数人看到展缸，首先被吸引了注意力的就是展缸底部铺设的多层疏水层。

在野外，土壤中的水分会随昼夜温差自然蒸发与凝结，白天高温低湿，夜晚降温后，地下储存的水分缓慢释放，提升局部湿度。由于南京室外的气温与辐纹陆龟所需温度差别较大，陆龟们无法在室外获得这种条件，饲养团队便通过疏水层、保水层与表层覆盖物的组合，人工构建这一动态平衡，用来调节温湿度和储存水分。

![](images/img_013.jpg)

不同灯光，各司其职

我们尝试通过不同的灯光组合来模拟一个"太阳"。头顶的三个主灯并不是同时开启。而是通过智能程序模拟太阳的运行轨迹。有时仅一盏亮起，有时两盏交错，有时从左至右依次切换。这种设计不仅还原了日升日落的光照强度变化和野外环境中温度与辐射的梯度变化。正如野外陆龟会随着太阳移动而调整晒背位置，这里的灯光变化也促使小龟主动探索环境。

跟着太阳走~

这些灯的变化还提供了“太阳”的位置变化。小龟们想晒太阳，就会跟着“太阳”移动。太阳走了，小龟也会跟着走，避免它们长时间在同一个位置静止不动。

![](images/img_014.jpg)

中间4根长长的灯管，让整个展缸都成为了小龟们的晒区。这模仿了自然环境中“无处不在但强度不均”的UVB分布，树荫下弱一些，空旷处强一些。如此设计，让小龟们能根据自身需求自由选择晒背强度。

![](images/img_015.jpg)

小龟凝视

和全区域紫外线相结合的，还有展缸里的植被分布和地形设置。展缸内的大多是来自辐纹陆龟家乡的植物，既可作为食物来源，又能为它们提供遮蔽与安全感。草本植物高低错落，小龟能啃食低矮嫩叶，而稍高的部分则形成天然屏障，供其躲藏休憩。这种动态生长机制，也鼓励小龟不断探索与适应。

![](images/img_016.jpg)

石块营造地形

大小不一、高低起伏的石块不仅营造出丰富的行走路径，还形成了微小的温度与湿度梯度。小龟可自主选择攀爬、晒背或躲阴凉，让小龟们能在一个更接近野外的环境里，跟随自然的节律觅食、活动与休息，去选择自己想要停留的地方。

![](images/img_017.jpg)

有色彩，更快乐~

圆型可见光灯的引入，解决了小龟们色彩感知的关键问题。动物依赖可见光辨识颜色——例如，辐纹陆龟偏好红色果实，因其代表成熟可食。若缺乏可见光照明，它们的世界就是一片灰暗，觅食能力与生活质量都会大打折扣。
