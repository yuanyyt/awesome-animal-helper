# 听，非洲在唱歌

![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.png)![](images/img_005.gif)![](images/img_006.gif)![](images/img_007.gif)![](images/img_008.png)

当你走进动物园的“非洲之歌”展区，是否曾停下脚步，好奇那些色彩浓烈、造型神秘的木雕面具背后藏着怎样的故事？又是否注意到墙上的几何纹样、随风轻摆的布帘，甚至脚下农田里种着的芋头与木薯，其实都暗藏玄机？

今天，让我们一起走进非洲区，从细节刷新我们关于这片土地的印象~

![](images/img_009.png)

**神秘与多元**

![](images/img_010.gif)

很多朋友来到非洲区，都会和这些打扮华丽的神秘面具木雕合影。有人好奇：“这些到底是什么动物？”

其实，它们不仅是动物，更是不同族群的文化、信仰和自然力量的象征。

![](images/img_011.png)

在非洲区入口的科普教室旁，一只高挑优雅的羚羊面具来自西非布基纳法索的库伦巴族（Kurumba）。对这个以农耕和放牧为生的族群而言，羚羊代表活力与丰收。面具上尖长的耳朵、黑白棕红交织的几何图案，讲述着英雄伊里盖开垦土地、驱逐邪灵的传说。

![](images/img_012.png)

不远处，一头威严的非洲水牛面具来自科特迪瓦。作为“非洲五霸”之一，非洲水牛野性难驯，却极度依赖水源。展区特意在其旁设置一方水塘与直饮水机——水牛伫立于此，仿佛守护着生命之源，也提醒我们：人与动物共享同一片水土。

![](images/img_013.png)

进入“马岛客厅”前，一只卷尾高翘的变色龙木雕静静蹲守。之所以将它安排在这里，因为马达加斯加的变色龙种类丰富，有100多种，其中59种是马岛独有的。

此外，还有喀麦隆的母子猴面具、加蓬奎勒族的心形“森林精灵”面具、布基纳法索布瓦族的鹰面具……

![](images/img_014.png)![](images/img_015.png)![](images/img_016.png)

每一张“脸”都承载着一个族群的世界观。鹰面具上的三角形代表羚羊脚印，Z字形象征祖先通往神圣森林的路径，棋盘格则是长老坐的皮垫......这些符号虽已难解其全意，却仍传递着文化记忆的温度。

![](images/img_017.png)

非洲的文化是如此丰富多彩，它不仅仅体现在面具艺术上，更深入到了建筑、布料设计以及声音表达等各个方面。在展区的设计中，我们试图通过多种方式捕捉并展现这种多样性与复杂性。

![](images/img_018.png)

展区墙面的图案风格各异：长颈鹿内室的外墙上采用东非流行的廷加廷加画的风格，色彩明快、充满童趣；

![](images/img_019.png)![](images/img_020.png)

犀牛保护墙则借鉴南非恩德贝勒人的几何彩绘。这种由女性代代相传的墙绘艺术，用红、黑、白三色表达婚姻、信仰与身份认同。

![](images/img_021.png)![](images/img_022.png)

布帘复刻了马里的博戈兰菲尼（Bogolanfini）泥染布风格。这种用发酵泥浆手工染制的布料，图案常暗含谚语或历史事件，是马里文化身份的重要象征。

![](images/img_023.png)![](images/img_024.png)

而草编盘子则使用当地常见的拉菲草，展示了当地居民就地取材的智慧。

音乐也是非洲文化不可或缺的一部分。非洲区共设有五个音乐点，分别播放马达加斯加民谣、 非洲鼓乐、澳洲土著吟唱等。

“我们都是一家人，要彼此深爱。”

这首歌是马岛客厅播放的《SAMBY OLO RAIKE》，我们询问了马达加斯加当地的人，这首歌的名字意为“我们都是一家人”。歌词传递着朴素而有力的信念：无论出身、贫富或地域，人类本应彼此深爱、平等相待。

![](images/img_025.jpg)

通过花纹、图案、材质和声音的交织，我们希望将非洲大陆多元而复杂的文化肌理“折叠”进这个展区之中。让每一个参观者都能用心去感受一个真实而多彩的非洲，体验到这片大陆丰富而独特的文化。

![](images/img_026.png)

**远方与身边**

![](images/img_027.gif)

非洲展区并不只关于“远方”，他们脚踏泥土、仰望星空、依时耕作、就地取材的生活方式同样也和我们紧紧相连。

在展区里，我们围绕房屋开辟了几块小田，种植番薯、芋头、木薯、芭蕉等作物。这些都是非洲常见主食。在马达加斯加，许多地方仍无农药化肥，人们依靠双手、简单的工具、牲畜的力量，以及对季节与生态的深刻理解，维持着一种接近“刀耕火种”的传统耕作。

![](images/img_028.png)![](images/img_029.png)

今年，我们的农田已迎来收成。丰收的芋头整齐摆放在村口，我们可以触摸、观察。在地球另一端，有人正以同样的方式，在同一片阳光下劳作、生活、传承。

建筑本身，也延续着这种“接地气”的方式。在非洲的许多地方，房屋都是用泥土、稻草、木棍、黏土等身边随手可得的材料搭建，体现了极强的实用主义与适应力。

![](images/img_030.png)

受此启发，我们在展区建设中也采用回收材料，比如过去老长颈鹿馆废弃的彩钢瓦，被重新切割、组装，成为非洲区的遮阳棚；旧木料被改造成围栏或座椅，延续着材料的生命。

![](images/img_031.jpg)![](images/img_032.jpg)

在非洲许多地方，人们更习惯用双手和身边材料表达信息，所以非洲区大多数的解说展牌都坚持手绘完成。手绘的线条或许不够完美，颜料也可能随风吹日晒褪色，但正是这份质朴与温度，更贴近非洲当地亲切而直接的表达方式。

![](images/img_033.jpg)![](images/img_034.png)![](images/img_035.png)

在这里，非洲成为了一种可触摸的当下，一种可共鸣的生活逻辑。当我们站在由旧瓦搭成的棚下，看着手绘展牌上的一笔一画，或许会突然意识到：那片土地上的智慧，并未与我们隔山隔海。它就在我们对自然的敬畏里，也在对另一种生活方式的真诚理解之中。

![](images/img_036.png)

**未来与希望**

![](images/img_037.gif)

走进非洲区，我们希望传递的不仅是对非洲动物的喜爱。毕竟，它们的魅力早已深入人心。我们还想去理解那片土地上的人，并思考他们的生活方式与我们之间的差异与共鸣：我们是否在现代化进程中丢失了某些珍贵的东西？我们该如何与身边的动物更好地相处？

![](images/img_038.png)

在呈现非洲文化的过程中，我们的文化也在与其潜移默化地融合。本土的表达方式与非洲文化结合，形成属于这个展区的独特语言。通过接触非洲那种贴近土地、与野生动物共生的生活哲学，我们或许能重新审视自己与身边自然的关系，找回那些被城市生活遮蔽已久的感知力与责任感。

因此，我们期待非洲区能成为一座桥梁，促进中非之间更多的交流，推动实地参与保护工作。我们也希望这里能孕育出更多未来的动物保护者，哪怕这些愿景听起来宏大而遥远。

但我们依然愿意相信并尝试。
