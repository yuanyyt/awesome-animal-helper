# 谁在非洲区卖麻团呢？！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.gif)![Image](images/img_004.gif)![Image](images/img_005.png)![Image](images/img_006.gif)![Image](images/img_007.png)![Image](images/img_008.png)![Image](images/img_009.png)![Image](images/img_010.png)![Image](images/img_011.png)![Image](images/img_012.gif)

“麻花！麻花！”

“麻团！麻团！麻团！”

嗯？怎么回事？是谁在非洲区吆喝叫卖呢？听起来像是在喊两种小吃……

别误会别误会！麻花和麻团是咱们非洲区里两只山魈的名字。而刚才那两声字正腔圆的吆喝，可不是饲养员在喊，而是——

![Image](images/img_013.jpg)

是我，没错！

是的，你没听错。这群灰鹦鹉之前养在内室的时候，隔壁住的就是赤猴和山魈。每天饲养员要引导山魈和赤猴进出外场，就会反复喊它们的名字。灰鹦鹉听得多了……就学会了。

每年的5月31日是世界鹦鹉日（World Parrot Day），这个节日是由世界鹦鹉信托基金会（World Parrot Trust）于2004年发起的，旨在提高公众对鹦鹉生存困境和保护必要性的认知，唤起人们对鹦鹉的关注，同时普及保护鹦鹉及其栖息地的科普知识。

今天，我们就借这个机会，和大家讲讲这群非洲灰鹦鹉的故事。

![Image](images/img_014.gif)

**No.1**

![Image](images/img_015.gif)

**万物皆可模仿**

![Image](images/img_016.gif)

如果要给动物们评一个模仿天花板，非洲灰鹦鹉绝对榜上有名。它们从不局限于同类鸣叫，人类声音、动物叫声、人工信号，只要听过几遍，就能精准复刻，堪称行走的“活体录音机”。

除了我们在开头说的它们会模仿饲养员呼唤山魈和赤猴的声音外，它们会模仿许多其他的声音，可谓是可塑性极强，“技能库”十分丰富。

![Image](images/img_017.jpg)

如今灰鹦鹉的外场紧邻【耳郭】狐的展区，开放展区的周边野生鸟类云集，这也成了灰鹦鹉们新的“学习素材库”。

喜鹊、灰喜鹊、八哥等常见鸟类的声音都被它们轻松掌握。就连珠颈斑鸠在繁殖季的时候发出低沉的“咕咕咕”的求偶声，也能被它们完美复刻。

模仿哨声

甚至还能听到它们吹哨。那是我们饲养员在呼唤黑白疣猴时的信号，不知怎么也被它们偷偷掌握了。

像是叽呀呀的开门声

还有一些声音，饲养员也不知道从哪儿学的，但是咱主打的就是一个全面发展，万物皆可模仿！

那它们学这干啥啊？

超强的模仿能力，源自它们顶尖的智商与精密的身体构造。它们的智慧与思考都藏在了“语言”里。

![Image](images/img_018.jpg)

成年灰鹦鹉拥有接近五岁儿童的智力水平，具备突出的认知与感知能力。这份聪慧，尤其体现在它们丰富而精妙的社交行为中。发出不同的鸣叫和模仿不同的声音就是它们社交能力体现，而它们之所以能成为“口技大师”，全靠一套精密的“语音合成系统”。

气管底部的鸣管是“中央声卡”，在大量肌肉神经控制下精准发声。接着，当声音离开呼吸道，会通过它们的舌头和喙部进行“加工”。灰鹦鹉的舌头灵活有力，除了可以处理坚果和种子之外，也是灵巧的“调音师”，而坚硬却又灵活的喙部，则通过调整开合，配合着舌头一起，将不同的声音精准清晰的“塑造”出来。正是这三者的配合，才能演绎出它们那丰富的语言天赋。

![Image](images/img_019.jpg)

在它们看似随意的鸣叫与模仿背后，并不是为了迎合人类、配合人类的逗弄与学话。它们的叫声中往往藏着精密的社交意图与深刻的思考。无论是呼唤同伴、警示危险，还是通过模仿天敌叫声来驱赶竞争者，声音不仅是它们的工具，更是它们维系情感、建立“联盟”、传递信息的纽带。

![Image](images/img_020.gif)

**No.2**

![Image](images/img_021.gif)

**灰鹦鹉也有“江湖”**

![Image](images/img_022.gif)

我们南门新区一共住着10 只非洲灰鹦鹉，每一只都有自己的性格、小圈子，还有专属的社交“鸟设”。

![Image](images/img_023.gif)

一般来说，只要站在展区外面看一会儿，我们就能清晰地看出谁跟谁好。有几只固定待在一起，互相理毛；有几只则明显不大对付，虽然没有激烈争斗，但也会悄悄驱赶对方、抢占栖架。

在野外，灰鹦鹉会集结成一个几百只的大型族群。它们每天都生活在一起，一同觅食、夜宿，用丰富的叫声进行交流，像一个大型社会一般。它们也会有特别好的同伴，或是一生的伴侣；也会每天晚上都会聚在一起聊聊八卦，社交体系十分成熟。

![Image](images/img_024.jpg)

而生活在我们这里的10只灰鹦鹉也组成了一个小社会。

13号是去年年底从救护中心转来的灰鹦鹉，那时候它还刚断奶不久。刚来的时候，它还有点胆小敏感。虽然已经断奶了，但还保留着求奶的幼态行为。

![Image](images/img_025.gif)

灰鹦鹉13号求奶

为了让13号能够顺利融入大群，饲养员遵循灰鹦鹉的社交习性，让13号先观察、再试相处、后自主融入，循序渐进地让13号融入群体。

最开始，考虑到当时13号刚断奶不久，我们先让13号单独住在内室的一个小笼子里，监测它的采食、饮水、排便等数据，同时也和其他小伙伴们遥遥相望。

在小笼子适应了一段时间后，我们在白天把其他灰鹦鹉放到外场去玩，让13号独自在内室里活动，让它慢慢熟悉内室的环境。

![Image](images/img_026.jpg)

在内室顺利融入~

等13号对内室的环境完全熟悉了之后，我们开始让它跟三只不太爱出门的“宅鸟”——3号、12号，和10号，共处一室。

![Image](images/img_027.jpg)

好朋友~

10号成了13号的第一个好朋友。它们可以共享一碗好吃的，互不驱赶。3号和12号虽然“霸占”了半边的栖架，但也默许了13号的存在。

就这样，历经近四个月磨合，13号逐渐适应同类相伴的生活。

![Image](images/img_028.jpg)

灰鹦鹉13号

现在13号已经可以完全自主选择它想待的地方，顺畅获取生存资源，和同伴和睦共处，彻底摆脱了初来的胆怯孤僻，顺利融入了这个10只鸟的小社会。

![Image](images/img_029.gif)

**No.3**

![Image](images/img_030.gif)

**从智慧象征到濒危绝境**

![Image](images/img_031.gif)

如果我们只说灰鹦鹉很聪明、很有趣，那这个故事是不完整的。因为正是“聪明”这件事，让它们成为人类眼中的 “珍宝”，同时也把它们推向了濒危的边缘。

![Image](images/img_032.jpg)

在非洲加纳文化中，灰鹦鹉是象征善辩与智慧的生灵；殖民时期，它是欧洲贵族追捧的珍稀异兽；上世纪80年代全球宠物热潮兴起后，灰鹦鹉成为顶流宠物，巨大的市场需求催生了毁灭性的野外捕捉产业。捕鸟人布设陷阱、利用诱饵捕捉成鸟，掏取巢穴雏鸟，无数鹦鹉被塞进狭小容器转运，90%的灰鹦鹉会在运输途中死去。

数十年间，野生灰鹦鹉种群遭遇重创，叠加栖息地树木被大量砍伐、生存家园锐减的困境，野外种群数量断崖式下跌。为拯救这一物种，全球保护措施持续升级，2016年灰鹦鹉被列入CITES附录Ⅰ，全面禁止野生个体国际贸易；

![Image](images/img_033.jpg)

2025年，作为非洲灰鹦鹉最大、最核心的野外栖息地——刚果，颁布法令，在全国范围内禁止捕捉、持有或买卖非洲灰鹦鹉。当地的救助中心还会救治罚没来的非洲灰鹦鹉，再将其放归。截至2025年10月，已放归400多只灰鹦鹉。



从贸易管控到全面立法保护，人类用近十年的时间弥补曾经的伤害。世界鹦鹉日的意义，不止是让我们看见鹦鹉的可爱，更让我们懂得，生灵的聪慧与美丽，不该是被掠夺的理由。

希望每一只非洲灰鹦鹉，都能爱学什么学什么，爱喊谁喊谁。在属于它们的天地里，自由鸣唱，自在群居。
