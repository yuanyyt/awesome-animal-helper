# 600克到6000克，不平凡的“逆袭”路！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)

在南门新区的袋鼠角，温馨的一幕在饲养员和赤大袋鼠宝宝之间上演。

![Image](images/img_006.gif)

然而，这温馨的一幕背后，是一段更为曲折的守护旅程——人工育幼。

**01 茁壮成长的小树**

去年，南门新区的赤大袋鼠妈妈们相继孕育起新的生命。作为有袋类动物，赤大袋鼠的孕期极短，仅33天。刚出生的袋鼠宝宝需要凭借已发育的前肢，自己从产道爬进育儿袋中，完成生命中的第一次挑战。

袋鼠妈妈育儿袋的内壁柔软细腻，能够给娇弱的袋鼠宝宝提供一个温暖、湿润的稳定环境继续发育。直到8个月后才会基本发育完成开始出袋探索，11个月左右才会完全不依赖育儿袋生活。

2025年10月，一次意外打破了袋鼠角的平静，其中一只赤大袋鼠妈妈在活动时，她的宝宝意外从育儿袋中跌落了。

![Image](images/img_007.jpg)

通常，饲养员会判断袋鼠妈妈和幼崽的是否健康稳定，首选就是将袋鼠宝宝送回母亲的育儿袋中，继续自然成长。但这次情况特殊，我们发现这位袋鼠妈妈体型较小，而她掉袋之前宝宝的腿脚和身体部位已经开始过早暴露，说明这只袋鼠妈妈的袋子可能无法再满足宝宝的继续发育，所以经过尝试之后便放弃了将宝宝送回育儿袋的计划。

通过查询大量资料文献和观察自然育幼个体对比，饲养员团队判断这只幼崽目前应该在130日龄左右，距离它完全出袋还需要110天左右。为了它的健康成长，饲养团队决定对这只袋鼠宝宝开启人工育幼。

![Image](images/img_008.jpg)

人工育幼的第一天，袋鼠宝宝的体重仅仅只有600g，身体还透着皮肤的粉红色，没有毛发。

为了模拟妈妈育儿袋的包裹感与安全感，饲养员们用恒温育幼箱模拟育儿袋中温暖的环境，并在其中用毯子模拟了一个人工“育儿袋”给幼崽安全感，并每隔三小时用有袋类动物专用奶粉喂食，开启了24小时轮班守护。

![Image](images/img_009.gif)

袋鼠成长的轨迹与其他动物有所不同。随着袋鼠幼崽的成长阶段的不同，为了适应它们的发育进程，母亲乳汁的营养成分也会发生改变。饲养员们必须严格参照袋鼠幼崽的成长轨迹，调整适配袋鼠宝宝当前成长阶段需求的奶水。

给袋鼠宝宝提供的人工“育儿袋”也需要随着它一天天的长大而不断调整尺寸，从最初包裹全身的“襁褓”，到后来可以探头观察的“睡袋”。

![Image](images/img_010.gif)

就这样在无数个不分昼夜的喂奶、陪伴观察中，袋鼠宝宝在一天天的长大。饲养员也为它取了一个生机勃勃的名字——小树。

**02 十倍成长的轨迹**

从25年10月一直到26年的4月，历经半年时光，小树的体重从最初的600g已经称到到如今的6000克啦~

而这600到6000数字增长的背后，是一连串更为复杂的挑战。

11月初，外场自然育幼的小袋鼠们已经在悄悄探头观察世界了，偶尔悄悄露个脑袋晒个太阳，偷偷舔舔泥土，嚼嚼袋鼠妈妈吃过的食物。

饲养员敏锐观察着外场的这些小变化，记录着它们的点点滴滴并以这些自然育幼的袋鼠宝宝为“参照物”，通过拍照对比，为小树作成长对照。

![Image](images/img_011.jpg)

自然环境中长大的袋鼠幼崽

在自然育幼成长下的袋鼠宝宝，会在袋中经历无数次的“探头－警戒－缩回”的循环。

![Image](images/img_012.jpg)

外场的袋鼠幼崽随着母亲一起“锻炼”

每一次外界风吹草动带来的惊扰，都促使它们用力蹬腿、迅速缩回，这无形中锻炼了核心肌肉与反应能力。而小树安静温和的成长环境，缺少了这些刺激，使得它的运动能力稍逊于同龄幼崽。

于是，饲养员为它在室内搭建了小小的运动围栏，鼓励小树站立，行走，锻炼肌肉与平衡感。尽管一开始摇摇晃晃，经过一段时间的锻炼，小树的活动能力得到了很大进步。

![Image](images/img_013.jpg)

等到12月，它的同龄伙伴们已经在进行下一项“社会实践”吃青草时，饲养员为小树准备了新的训练场地——铺满红土、黄土、袋鼠外场取来的土壤和袋鼠吃剩的青草的地面。

![Image](images/img_014.jpg)

这些物质中含有微生物的物质可以帮助袋鼠宝宝建立健康的肠道菌群，袋鼠吃剩的青草还能帮助小树练习咀嚼。

![Image](images/img_015.gif)

然而，新的挑战还是来了。26年1月，当小树正式开始吃青草后，它出现了腹泻的情况。腹泻，对于幼崽来说是危险的信号，好在小树的精神状况还是很好。经过兽医判断，原因在于肠道菌群不足。治疗的关键，是让它有机会接触更多其他袋鼠，从而获得关键的菌群，于是饲养员调整了策略。

![Image](images/img_016.gif)

饲养员陪伴小树在外场

白天时，会更多地让小树和袋鼠大群待在一起。让它接触其他袋鼠的粪便，以及嗅舔其他袋鼠个体和环境物品来更多地获取菌群，晚上则是让小树回归人工“育儿袋”，继续享受饲养员安静又安心的照顾。

转机出现在坚持中，经过半个多月的治疗与持续的环境接触，小树已经可以自主排出成型的健康粪便了。能够吃青草的小树也终于可以和人工“育儿袋”说再见了！

**03 跃动的新生活**

新的烦恼也随之而来，在饲养员陪伴下长大的小树会很依赖人，甚至挠痒痒等行为也很期待饲养员的帮助。面对这份依赖，饲养员有些担忧，因为小树更需要的是学习如何做一只真正的袋鼠。

![Image](images/img_017.gif)

幸运的是，在日常观察中，饲养员发现其实赤大袋鼠们的社群关系比较松散，对于雌性和幼年个体的加入接受能力比较高，这让小树也自然而然的融入了这个群体之中。

在赤大袋鼠的互动中，幼崽们会自然而然的去观察学习，模仿大袋鼠们的行为。比如躺下前先用前肢刨地，比如如何与同伴进行适度的玩耍打闹。小树也在这样的环境中开始模仿，学习大袋鼠们躺卧的姿势，学习如何做一只真正的袋鼠。

![Image](images/img_018.gif)

如今，小树已经正式成为袋鼠角大家庭的一员。虽然它在1岁之前还是需要在饲养员的人工补奶的帮助下摄入营养。但更多的时候，它也能够和同伴一起在沙地里蹦跳，学着大袋鼠的样子咀嚼青草、沐浴阳光，和其他袋鼠一样享受外场的生活~

![Image](images/img_019.jpg)

这只名为小树的袋鼠宝宝，也正如一棵小树般，经历了种子萌芽的挑战，也经历了一些曲折与变化，但最终在大家的照料与关爱中生存下来，又在群体生活中茁壮成长。当您来到袋鼠角时。不妨放慢脚步，静静观察，一起找找它的身影，和我们一起记录下它温暖的成长时光～
