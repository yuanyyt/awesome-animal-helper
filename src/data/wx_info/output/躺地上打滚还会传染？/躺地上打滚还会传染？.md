# 躺地上打滚还会传染？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.jpg)

提到斑马，你能想到什么？

或许最先浮现在脑海的，是城市街头那道熟悉的“斑马线”。它借用了斑马身上最醒目的特征：黑白相间的条纹。我们似乎习惯了用“黑白条纹”来概括斑马。但斑马的魅力，却远不止于条纹。

**超越条纹的斑马**

斑马是常见于非洲的马科马属动物。虽然都是黑白条纹，但每只斑马的条纹都是独一无二的。目前，斑马被分为三种：平原斑马、山斑马及细纹斑马。

![Image](images/img_005.png)

平原斑马娇小圆润，条纹宽阔，腹部有条纹，尾尖为黑；山斑马体型中等，有“烤架状”条纹，腹部无条纹，尾尖黑白；细纹斑马体型最大，条纹细密，腹部无条纹，尾尖为白。

条纹是斑马的标志性特征。但条纹对斑马有什么用，长久以来都是未解之谜。科学家们提出了伪装、降温等各种假说，但目前最具说服力的见解是：黑白条纹能干扰吸血蝇类（采采蝇、虻）的视觉，从而减少叮咬和疾病传播。

![Image](images/img_006.png)

地理分布也印证了这一点：在吸血蝇类滋生的湿热赤道地区，斑马条纹清晰且遍布全身；而在虫媒压力较小的南部，条纹则逐渐变淡、稀疏。

![Image](images/img_007.jpg)

斑马的魅力远不止于它们醒目的外衣。在那身充满谜题的黑白条纹之下，它们还自带一种紧张感，明亮的眼睛、高昂的头颅、警觉的站姿，连耳朵也总在捕捉风吹草动。

但它们并非时刻处于紧绷之中，依然能从容地觅食、玩耍和休息。在警觉与松弛之间自如切换，是斑马百万年来演化出的生存智慧。

![Image](images/img_008.jpg)

斑马拥有卓越的视力。无需转头或移动眼睛，它们的视野就能覆盖前后大部分区域。即使在烈日下，独特的横向瞳孔也能确保敏锐的侧视能力。所以，别指望能神不知鬼不觉地从背后靠近一匹斑马——它早就看见你了。

![Image](images/img_009.jpg)

斑马的耳朵大而灵活，能独立旋转以捕捉不同方位的声源。耳位也是重要的社交信号：向后平贴代表敌意，竖直向上则示意友好。这种耳位常与张嘴动作结合，嘴巴张开的幅度越大，代表情绪越强烈。

一只打滚，两只打滚，最后三只都打滚

斑马喜欢通过打滚和摩擦来清洁皮毛、去除寄生虫。得益于低而圆润的臀部，平原斑马是打滚的好手，能轻松地从一侧翻滚到另一侧（山斑马臀部较高，只能先在一侧打滚，站起来再换另一侧），因此斑马可以享受到许多食草动物都无法体验的、在草地上来回翻滚的乐趣。

在野外，岩石、树干、白蚁丘是稀缺的“蹭痒桩”，为了摩擦难以触及的臀部，斑马们有时还需排队等候。

![Image](images/img_010.jpg)

斑马在夜晚睡觉。深度睡眠时，它们会将四肢收于一侧，甚至完全侧身平躺，头颈贴地，肢体处于完全舒展放松的状态。

![Image](images/img_011.jpg)

白天休息时，它们也会卧下，或站着打盹——依靠腿部精妙的韧带机制，它们能锁住关节，在肌肉放松的状态下依然屹立不倒。这种“时刻准备着”的姿态，确保它们一旦受惊，瞬间就能启动逃跑。

![Image](images/img_012.jpg)

群体成员之间通过理毛来巩固凝聚力——两匹斑马肩并肩站立，用门齿轻咬对方脖颈和背脊那些难以触及的部位。这种亲密互动有时持续半小时，双方还会默契地交换另一侧继续。

![Image](images/img_013.jpg)

当斑马群卧下休息时，至少会有一只保持站立和警觉状态。这个“哨兵”角色通常由家庭公马担任，当公马站岗时，其母马和马驹会紧挨着躺下。在危机四伏的野外，这种哨兵机制确保了其他家庭成员能获得彻底的放松。

![Image](images/img_014.jpg)

小斑马出生于严密的家庭单元中。日常行进时，幼驹紧随母马，受前后成员庇护。一旦遭遇威胁，这种庇护会瞬间升级：母马将幼驹护在身侧，公马主动断后拦截，整个家庭群迅速聚拢，将幼驹严密包围在核心，以紧密的队形共同突围。

![Image](images/img_015.jpg)

非洲大陆最长的哺乳动物直线迁徙纪录，是由南部非洲的一群平原斑马保持的。2014年，科学家通过GPS项圈追踪发现，这群斑马会在纳米比亚与博茨瓦纳之间往返，完成全长近500公里的旅程。不同于随雨季迂回的常规路线，这群斑马几乎沿直线南北穿梭，展示了非凡的耐力与方向感 。

**危机与共存**

斑马（Zebra）一词源于希伯来语tzěbi，意为“美丽”。然而，对这些美丽的动物而言，与人类共存的过程并不容易。

![Image](images/img_016.jpg)

**平原斑马**数量锐减，非法猎杀、栖息地破碎化是主要威胁。目前，平原斑马主要退守在塞伦盖蒂、马赛马拉等保护区内。非洲公园网络（African Parks）与国际爱护动物基金会（IFAW）正在马拉维等地开展跨国界的反盗猎行动。

研究表明，平原斑马的记忆力与适应力极强，即使迁徙路线被围栏阻隔超过30年，一旦拆除障碍，它们仍能重新找回从前的路线。因此，除了反盗猎，恢复生态走廊的连通性已成为保护工作的重点。

![Image](images/img_017.jpg)

山斑马（图片来自https://www.earth.com）

**山斑马**共有两个亚种，现存约35000只，其中绝大部分是哈特曼山斑马，开普山斑马不足2000只。

开普山斑马的复苏始于1937年南非山斑马国家公园的建立。为重建种群，散落各地农场的山斑马被集中于此。经过保护与管理，它们不仅在公园里繁衍生息，还被重新引入到其他保护区和私人土地上。

![Image](images/img_018.jpg)

细纹斑马（图片来自刘基文）

所有斑马中，**细纹斑马**最为濒危。它们曾广泛分布于东非，如今几乎只能在肯尼亚见到，仅剩3000只左右。狩猎、栖息地丧失、与家畜竞争、极端干旱等原因威胁着它们。目前，绝大部分细纹斑马仍生活在保护区之外。它们与牧民社区共享土地，面临人兽冲突、种群孤立等风险。

斑马不仅是草原上的风景，更是生态平衡中不可或缺的一环。保护斑马，就是保护它们身后广袤的生物多样性。

**国际斑马日**

每年的1月31日是国际斑马日，这个保护日由多家国际保护组织共同发起。为了让大家把目光聚焦在这个非洲标志性物种上，今天，我们在“非洲之歌”举行了“国际斑马日”的活动。

![Image](images/img_019.png)

虽然细雨绵绵，却丝毫未减大家的热情。游客们撑着伞、披着雨衣，兴致勃勃地参与各项互动环节。

![Image](images/img_020.jpg)![Image](images/img_021.jpg)

活动限定斑马手环和限定斑马臀部明信片

参与者收获了“斑马的秘密”，还可以带走专属的斑马手环和印有斑马圆润臀部的明信片，沉浸在这场斑马守护之旅中~

![Image](images/img_022.jpg)![Image](images/img_023.jpg)![Image](images/img_024.jpg)![Image](images/img_025.jpg)

领取手环，开始今天的斑马之旅吧~

沿途的科普牌和教室里的斑马日科普展板，是解锁平原斑马知识的重要窗口。大家站在黑板前把这些关于斑马的知识牢牢记在心里，靠这些知识来闯关赢奖啦~

![Image](images/img_026.jpg)![Image](images/img_027.jpg)![Image](images/img_028.jpg)![Image](images/img_029.jpg)

争做斑马知识小达人！

除了科普牌上的斑马小知识，游客们也纷纷带着问题驻足大草原，踮脚远望远处的斑马。

而我们的斑马也格外“给面子”。尽管细雨淅淅沥沥地飘落，它们依然悠然踱步到大家面前，甩甩尾巴、抖抖鬃毛。

![Image](images/img_030.jpg)

斑马在这里~

斑马日的活动在温馨而热烈的氛围中结束，而参与者们不仅收获了快乐和纪念礼品，还深入了解了斑马的特点与生存困境，树立了保护斑马、守护生物多样性的意识。

答题领奖啦~
