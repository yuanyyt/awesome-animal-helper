# 没有“终点”，只有“下一站”！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.gif)![Image](images/img_005.png)

**在**

**红**

**山**

**，**

大象的便便竟没有浪费，

而是变身“热门便签本”！

![Image](images/img_006.png)

倒木经历“三生三世”，从栖架、座椅到气味丰容道具，活出高光“树”生；三个堆肥点默默运转五年，让厨余、落叶、粪便统统“圾生重启”，成为保育区庄稼的口粮。

![Image](images/img_007.jpg)

更有一套“便便黑科技”闭环：

**动物吃植物→便便变肥料→肥料种植物→植物喂动物。**

![Image](images/img_008.png)

密闭式动植物废弃物发酵罐

而这场“万物循环”的奥义，也藏在保育区花园：保护生物多样性！

![Image](images/img_009.gif)

当枯枝落叶成了刺猬的席梦思，当废弃石材垒出宁波滑蜥的日光浴场，黄鼬、貉、獐子、鼬獾纷纷来串门，我们才真正读懂自然的“循环说明书”：

零废弃，不是让废弃物消失，

而是让万物活出“三辈子”，

让荒野在家门口重新扎根。

就在今天，3月30日国际零废物日，跟随我们一起来看看红山的“循环剧本”，又有哪些被温柔对待的废弃物，又长出了怎样的故事。

![Image](images/img_010.png)

**红山导示牌**

**开启“第二木生”副本**

![Image](images/img_011.png)

以前找路费脖子，现在导示牌集体“长”到了1.5米以上；大地图还会自己“转”，0°到330°，12个角度，主打一个“所见即所向”！

![Image](images/img_012.gif)

就连卫生间标识都悄悄开起了“小课堂”，12组动物用角、喉囊、毛色告诉你：什么叫雌雄有别...但这只是表面，背后藏着一本精打细算的“碳账本”：

![Image](images/img_013.png)![Image](images/img_014.png)

这些都是你看得见的，是木与金属混搭的导示牌，像从土地里长出来一样自然；

![Image](images/img_015.png)

**为地球，算好了“碳账本”**

而这些是你看不见的，是它们背后的“第二人生”：木质部分可能是“旧物新生”拆下来的旧材料，倒下的树木在这里重获新生，每一块FSC认证的木材都带着“身份证”，告诉你它来自负责任管理的森林。

![Image](images/img_016.png)

我们为导览地图想了个超实用的办法：把大地图拆成4块可拆卸的金属片，哪块展区更新就换哪块，比起整张重印，省下53%的成本和碳排放。

![Image](images/img_017.png)

同时，根据全球领先的建筑与环境碳⾜迹标准RESET、废弃物回收与再生数字化平台材见My-Loop的计算，通过这样的方式，我们在这次的新导览中，循环材料使用率为60.7%。

就连设计之初，我们就盘算好了它们的“退休计划”！91.7%的材料未来都能轻松拆卸、重新上岗。全生命周期算下来，减碳27吨。

![Image](images/img_018.png)![Image](images/img_019.png)

也因此，红山导览标识系统拿下了全国首个景观类RESET全生命周期认证，从FSC认证木材到可拆卸结构，每个环节都经得起碳足迹的追溯。

![Image](images/img_020.png)![Image](images/img_021.png)

**红山垃圾桶**

**加入“可持续内卷”**

![Image](images/img_022.png)

作为导览体系的新成员，我们给垃圾桶也定了个小目标：让你丢垃圾前，先“愣”一下。

你可能会好奇，怎么个“愣”法？我们在观察老式垃圾桶时发现，面对两个一模一样的开口，游客常常随手一扔，左边右边全凭心情。于是新垃圾桶悄悄动了点“小心思”：把可回收物的投放口特意错开，制造一点点“不顺手”的非常规体验。别小看这多出来的几秒钟，哪怕只是多思考一下，分类的准确率就可能大不相同。根据现场游客投递的数据评估：相比老桶，新的“可回收物”桶游客投递正确率提升了16%。

![Image](images/img_023.png)

更细腻的设计，藏在液体处理上。在全园摸查后，我们发现游客投递的垃圾中，液体占比不容小觑。于是，在大家倒液体需求量较高的点位，我们专门设置了沥水桶。液体倒进沥水桶，厨余、可回收物、其他垃圾各归其位，轻轻松松就能分得明明白白。

![Image](images/img_024.png)

我们希望用这些看似“不起眼”的设计，让每一个来到红山的人，都能在不经意间，成为零废弃的参与者。

因为每一次认真的分类，都是对红山、对自然、对未来的温柔回应。

![Image](images/img_025.png)

红山文创

住进你的日常

![Image](images/img_026.png)

当导示牌开启了“第二木生”，垃圾桶开始了“可持续内卷”，我们把同样的较真，悄悄缝进了你可以带回家的日常里。因为我们始终相信：可持续不应该是遥远的理念，而应该是可以被触摸、被使用、被温柔对待的东西。

2024年台风贝碧嘉吹倒了好多园内的树木，我们将其中一些做成了一些冰箱贴，希望它以另一种方式继续陪伴我们。

![Image](images/img_027.png)

我们把雨林的守护者，请上了T恤。就在春分这天，一款特别的T恤正式发布。**大猩猩空气T恤**，是红山“森灵野集”与腾讯“碳寻制造”的联合尝试。它的面料原料，来自工厂烟囱里捕获的二氧化碳——经过转化，变成聚酯纤维，再织成衣服。每一件，固定了35-40克空气中的碳。

![Image](images/img_028.png)

我们请大猩猩来“代言”，是因为它们的命运与雨林的存续紧密相连。它们是雨林的“园丁”，传播着具有强固碳能力的大树种子，守护着这座天然的“碳库”。而我们也希望这件耐用且美观的T恤，可以让你愿意穿的更久一些，最终也让它更好的回归资源的再循环，减少我们对石油的依赖。RPET刺绣贴，也是同样采用100%再生聚酯纤维制成。

![Image](images/img_029.png)

我们还为材料，设计了一条“回家”的路。传统的塑料制品耐用，却难以降解，容易成为“白色污染”。纸质吸管环保，但耐用性差强人意。如何在“好用”与“环保”之间找到平衡？

我们找到了一款由全新生物基材料（PHA）制成的自带杯。日常用，它像普通塑料一样耐用，喝热水完全没问题；即便不小心遗落野外，只要接触到微生物丰饶的土壤、河流或海洋，微生物就会慢慢把PHA当作食物一点一点的吃掉，最终分解成二氧化碳和水，彻底回归大地。

![Image](images/img_030.jpg)

如果还想了解更多，欢迎移步至“ZOO商城”—“森灵野集”专区。把这份对自然的善意，带进你的日常里。你带走的，不只是红山的记忆，更是我们想传递给你的那句话：**万物皆有来处，万物皆有归处。**

![Image](images/img_031.png)

**动物园为什么****要关注零废弃？**

![Image](images/img_032.png)

红山从来不是一个只负责“展示动物”的地方。我们更希望，每一位走进来的你，都能爱上这里的动物们，并开始好奇：它们在野外的家，是什么样的？那些远在千里之外的雨林、湿地、森林，还好吗？当你开始关心它们的野外家园，我们就离“保护”这件事，更近了一步。

![Image](images/img_033.png)

零废弃从来不是一道“环保附加题”。它是保护野生动物栖息地的底线，是减缓气候变化的关键一环，是让那些我们喜欢的动物。在动物园里看到的、在纪录片里惊叹的、在绘本里认识的，能继续在野外好好活下去的底气。

![Image](images/img_034.jpg)

自然教育活动

2024年起，美团青山计划联合北京市企业家环保基金会（SEE基金会），和红山一起踏上了这条推动城市生物多样性保护和零废弃倡导工作的研究与分析的路。我们做生境提升改造、增设零废弃导览和休憩设施、开展自然教育活动以及寻找属于红山自己的零废弃路径，一步一步，走得慢，但走得踏实。

在红山，万物没有“终点”，

只有“下一站”。

让我们一起，把这条路，

走得更远一些。
