# 糟糕！小水獭竟被生在了“厕所”里！

![Image](images/img_001.png)

**你的快乐补给来啦！**

亚洲小爪水獭带娃，各有各的节奏。隔壁茶茶家每天忙着搬家，核心议题永远只有一个：[这个家到底该听谁的？！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650888724&idx=1&sn=d66c6437a281fc2b5514238619b94670&scene=21#wechat_redirect)另一对水獭雌性韩信和雄性澜沧，也在第一次繁殖后，迎来了他们的独生幼崽。

![Image](images/img_002.jpg)

没有搬家纠纷，没有家庭地位大战。但这家的故事，精彩程度一点不输隔壁。

一切，要从那个冬天的傍晚说起。

**一个有味道的“产房”！**

![Image](images/img_003.png)

亚洲小爪水獭韩信（雌）和澜沧（雄）原本就是一对精力旺盛、爱四处探索的搭档。相处久了，两只水獭的日常互动越来越密切。很快就传来了喜讯，韩信怀孕了。

![Image](images/img_004.png)

韩信和澜沧

彼时正值秋冬交替、天气渐冷的时节，两只水獭的日常照旧：互相理毛、该吃吃该喝喝、该衔草絮窝就衔草絮窝。只不过他俩的絮窝方式有点“过头”：不管窝有多大，也不考虑自己的身材，执着地把所有能看到的干草全叼回窝里。

窝里塞满了，就往过道上铺；过道也铺满了，草堆成小山。结果澜沧那圆滚滚的身子，压根挤不进去。每次要回窝睡觉，澜沧都得像鼹鼠钻地一样，从草堆里硬拱出一条通道。

![Image](images/img_005.png)![Image](images/img_006.png)

考虑到韩信是初次生产、缺乏经验，饲养员提前做好了万全的应急准备：除了适当增加韩信的饲料总量、为其补充孕期所需营养，还备齐了干草、巢箱等必备物资；更细心筹备了奶瓶、奶粉等人工育幼材料，明确了人工育幼的场地与流程，全方位防范生产过程中可能出现的意外情况。

这样平稳的日子一直持续到2025年12月20日，傍晚18时许，一向活跃好动的韩信突然变了，褪去了往日的玩耍劲头，早早便钻进了巢箱，期间不时发出断断续续的嚎叫；夜幕降临后，随着宫缩逐渐加剧，她的嚎叫变得有规律、也更为急促，生产的信号愈发明显。

![Image](images/img_007.png)

宫缩间隙，韩信缓缓走出巢箱，在活动区域内来回走动了几圈，随后径直走向自己平时固定的排泄点。幼崽便在这个意外的地点悄然降生了。韩信似乎没有立刻发现幼崽已经出生，转身又独自回了巢箱。

大约过了两分钟，幼崽发出了叫声。韩信与澜沧立刻从巢箱中冲出，迅速将幼崽小心翼翼衔回巢内，开启了抚育模式。

![Image](images/img_008.jpg)

多少有点惊心动魄的乌龙

**相信獭们，獭们能行！**

![Image](images/img_009.png)

韩信的生产过程虽有小波折，让人捏了一把汗，这对毫无育幼经验的新手搭档，后续照顾幼崽的表现会如何呢？

![Image](images/img_010.png)

相信我们！肯定能行！

生产后的第二天，韩信和澜沧表现得十分谨慎，开启了轮流外出觅食的模式，始终确保有一只留在巢箱里，守护着幼崽的安全。原本以为会像隔壁茶茶一家那样，由雄性水獭澜沧率先外出觅食，可没想到，最先走出巢箱寻找食物的，却是韩信，澜沧则全程留守在巢箱，专注照料幼崽。

![Image](images/img_011.gif)

随着幼崽日渐长大，韩信与澜沧外出觅食、活动的时间也慢慢延长，偶尔他俩也会因专注于彼此间的互动而忽略幼崽的叫声，直到听到幼崽持续呼唤，才会立刻停下动作，急匆匆返回巢箱照料。

![Image](images/img_012.gif)

就连小崽也会帮这爸爸妈妈一起絮窝呢

育幼期间，澜沧的表现格外细致，常常会就地取材，要么衔取饲养员散放在场地里的干草，要么撕取场内干枯芭蕉根部的外皮，衔回巢箱，重新整理铺垫，始终让巢箱内部保持干燥；就连韩信和幼崽在巢箱里换了位置，他也会及时调整铺垫物的分布。

![Image](images/img_013.gif)

要是天气晴朗，韩信带着幼崽到巢箱外休息，澜沧还会提前衔来干草，铺在幼崽和韩信的身下。

![Image](images/img_014.png)![Image](images/img_015.png)

在韩信的孕期及哺育期，为了满足其自身营养需求及后续哺育幼崽的消耗，饲养员增加了虾、鱼、甲壳类及软体类等日常食物的总量。

![Image](images/img_016.png)

温馨一家

亚洲小爪水獭的哺乳期通常是3到4个月，等到幼崽出生一个多月后，它就开始对韩信和澜沧吃的食物，表现出了浓厚的兴趣。

这时候，饲养员更是细心调整，在饲料中添加细小的虾仁作为辅食，同时对所有食物进行精细化处理：去掉尖锐部位，把大块的分割成更小的小块，方便幼崽入口。

![Image](images/img_017.png)

爸妈给的就是好吃！

同时，韩信和澜沧会帮幼崽筛选食物，他们会先自己吃一部分，再衔取另一部分带回巢箱，让幼崽试着品尝；要是幼崽不愿意吃，他们再把食物吃掉，一点也不浪费呢。

![Image](images/img_018.png)![Image](images/img_019.png)

爸爸澜沧快乐觅食中

从出生地点的乌龙开场，到轮流带崽、衔草铺窝的默契配合，再到辅食添加、食物把关...韩信和澜沧这对毫无经验的新手搭档，愣是把幼崽养得壮壮实实的。毕竟这一切尽在獭的掌握之中！

![Image](images/img_020.jpg)

不过，爸妈给的“吃饱喝足”只是第一步。对于一只亚洲小爪水獭成长来说，还有一门比吃饭更重要的必修课，正在前方等着它呢。

那门课，叫水！

如何在水中活动、如何游泳、如何捕食，这只小崽的成长故事，远没有结束～
