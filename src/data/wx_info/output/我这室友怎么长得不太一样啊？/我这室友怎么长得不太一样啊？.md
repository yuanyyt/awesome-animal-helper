# 我这室友怎么长得不太一样啊？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)![Image](images/img_006.png)![Image](images/img_007.png)![Image](images/img_008.jpg)

**我这室友怎么长得不太一样啊？**

![Image](images/img_009.jpg)

当然不一样啦，这位是著名的“太阳崇拜者”，是最爱伸展四肢、把身子晒得暖洋洋的——**环尾狐猴。**

![Image](images/img_010.jpg)

而这位，是可以根据温度、光照灵活调整作息的“适应性大师”——**褐美狐猴**。

让这样两位“作息”不同

长相也各有特点的邻居住在一起

它们该如何和谐相处呢？

快一起来看看吧！

![Image](images/img_011.png)![Image](images/img_012.png)![Image](images/img_013.png)

**初来乍到**

在野外，环尾狐猴和褐美狐猴都住在它们同一个故乡马达加斯加岛，虽然主要活动区域不同，但也在共享土地的空间。

我们希望模拟马达加斯加岛这种自然的生态关系，让动物的生活场景更丰富、行为更多样。于是，这对新邻居的“同居计划”就开始啦～

![Image](images/img_014.jpg)

为了能够让比较谨慎的环尾狐猴能更好地适应新环境，饲养员让它们先搬进了新家。这段“独居”时间里，它们可以独享整个外场，熟悉每一根栖架、每一条通道，找到自己觉得安全舒适的地方。

![Image](images/img_015.gif)

等它们充分熟悉了外场，适应力更强的褐美狐猴一家才被“请”了进来。初来乍到的褐美狐猴们则更从容自在，稍作观察便轻松跃上栖架，开始了对新家的探索。

![Image](images/img_016.jpg)

环尾狐猴们则集体进入了“谨慎观察”模式，睁大圆溜溜的眼睛，远远关注着这些新邻居的一举一动。

![Image](images/img_017.jpg)

褐美狐猴们显得相当“自来熟”，在适应外场之后，它们大部分时间都在惬意地梳理毛发，或者享受美食，似乎并没把这些条纹新邻居的“注目礼”太当回事～

![Image](images/img_018.jpg)

合群初期，饲养员也会花时间在一旁静静观察，确保双方只是互相关注彼此的动静，而不会“动手动脚”发生冲突。令人安心的是，经过一段时间的评估后，它们之间并没有出现追赶或打斗，始终保持着一种礼貌而安全的“邻里距离”。

![Image](images/img_019.png)![Image](images/img_020.png)![Image](images/img_021.png)![Image](images/img_022.png)

**“餐桌”上的小风波**

看似平静的共处，在小餐桌上遇到了第一个小挑战。

对于环尾和褐美这两种狐猴来说，它们在野外的食谱很像，都爱吃各种水果、嫩叶和昆虫，这给饲养员准备“邻里套餐”带来了方便，但也带来了考验！

![Image](images/img_023.jpg)

在狐猴共同居住的外场中，设置有专属的喂食平台。饲养员在观察中发现，环尾狐猴在平台上进食时十分警惕，它们会关注褐美狐猴是不是在附近，或者有没有前来取食的动作。

只要褐美狐猴来到平台上进食，环尾狐猴就会跳开或在附近等着，这样一来轮到环尾再上前采食时往往只能吃到一些被挑剩下的食物。

![Image](images/img_024.jpg)

看来，天性谨慎的环尾狐猴，觉得和一群不那么熟悉的邻居在一起，没有办法自在的进食。这可不行！共享家园的前提，是每一位居民都能自在生活。

![Image](images/img_025.jpg)

饲养员立即对此做出了改造——分散喂食。

根据外场的环境，饲养员选择了许多木质碗架，然后把它们分散挂在不同高度、不同方位的栖架上。

![Image](images/img_026.jpg)![Image](images/img_027.jpg)

这样一来，吃饭的格局全变了。通过不同栖架的连接，环尾狐猴不用再纠结是否要上前和舍友共享，而褐美狐猴也有了更多选择，可以在自己喜欢的树杈上享受美食。

这个改变让取食变成了一个在树林中漫步、寻找的过程，既能够增加活动量，让狐猴有更多选择，也保证了每只狐猴都能轻松吃到食物。

![Image](images/img_028.jpg)

饲养员还会喂一些它们平时在野外不易获取的食物，比如南瓜、红薯、熟毛豆等。确保每只狐猴都能均等地吃到这些资源类的食物、摄入足够的营养，同时也是与它们建立信任、进行日常近距离健康观察的好机会～

![Image](images/img_029.png)![Image](images/img_030.png)![Image](images/img_031.png)![Image](images/img_032.png)

**共享家园的日常**

慢慢的，一种默契在它们之间形成。

环尾狐猴更多地在地面和低矮的栖架上活动，悠闲地享受日光浴。

![Image](images/img_033.jpg)

褐美狐猴则更偏爱在中高层的树枝间穿梭跳跃，展现敏捷的身手。

![Image](images/img_034.jpg)

它们在立体的空间里自由取食、自在活动，自然而然地找到了各自舒适的生活区域。

到了晚上，它们会回到各自独立的室内房间休息。昼行性的环尾狐猴早早进入梦乡，而褐美狐猴的夜晚，可能才刚刚开始。这样的安排，让彼此都能拥有不受打扰的安宁时光～

![Image](images/img_035.jpg)

不打扰~ 我只是路过~

在这片家园中，饲养员基于动物习性做了细心考量；为满足每个个体的需求需求而不断调整。最终，两个不同的家族在同一个空间里，找到了各自舒服的位置，也让我们看见——共享，可以是一种安静的默契；共存，也能成为一场自然的陪伴。

当你来到非洲之歌的狐猴之家，不妨放慢脚步，找找它们的身影。感受着同一片蓝天下的、安稳的幸福~
