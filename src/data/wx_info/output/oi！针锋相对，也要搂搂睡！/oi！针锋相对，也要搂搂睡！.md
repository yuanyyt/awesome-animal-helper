# oi！针锋相对，也要搂搂睡！

![Image](images/img_001.jpg)

向所有的烦恼说bye bye！向所有的快乐说Hi Hi~

明天就是大猩猩老三小蒜头的13岁生日啦~先让我们祝他生日快乐！

13岁，对于人类而言大概正是意气风发的初中时代，而对于大猩猩来说，这同样是一个充满变数与活力的青春期。他们的身体在悄然蜕变，力量在不断蓄积，而群体内部的关系也如同青春期的少年心事一般，变得微妙且丰富起来。

![Image](images/img_002.png)

**四兄弟的等级秘密~**

要读懂这群正值青春的少年，首先得解开四兄弟之间的“等级秘密”。

![Image](images/img_003.jpg)

老大香椿头

老大香椿头是这个群体里成熟的银背首领。作为大家长，老大掌控着群体秩序，一举一动都影响着其他三只弟弟。每当老大驻足观望、神情警惕时，弟弟们都会安分等候，直到它放松姿态，大家才敢自在活动。

老二马兰头、老三小蒜头、老四枸杞头今年同为 13 岁，但成长的步调却截然不同。

![Image](images/img_004.jpg)

老二马兰头

老二马兰头的银背特征愈加明显，体重一路增长至 150kg，体型也越发壮硕，不断逼近 173kg 的老大。也正因此，老大对老二格外关注，二者之间时常有着空间与地位的小小较量。

![Image](images/img_005.jpg)

老四枸杞头

老四枸杞头虽然同样步入青春期，但却保留着孩童般的天真。活泼爱闹的他热衷于和哥哥们追逐翻滚，是群体里不可或缺的“玩乐担当”。

![Image](images/img_006.jpg)

最左为老三小蒜头

老三小蒜头在四兄弟中则是格外特别的存在。相较于两位同龄兄弟，小蒜头的身形瘦小许多，身体发育节奏也更慢，整体状态似乎还停留在孩童阶段。

![Image](images/img_007.jpg)

老三小蒜头

但这并不妨碍他在兄弟们心中的地位。老大对他颇为包容，老四更是和他形影不离。老三自己也没有因为身材小就畏畏缩缩，反而充满了自信，在群体中的地位常常仅次于老大。

![Image](images/img_008.jpg)

独立自信

有时候饲养员在呼唤老四枸杞头时，被耳朵尖的老三听到，就想先老四一步吃到好吃的。他会毫不犹豫地从老四旁边挤过来。如果老四没有主动让位，老三还会用手推他一下，意思很明确：“让一让，我先来。”而老四往往也会乖乖配合，不大计较。

![Image](images/img_009.gif)

边喝边泡脚

天气热了，饲养员在展区内放置了大水盆，大家都沿着水盆边喝水。但老三却仗着身材瘦小，站在水盆中央，一边低头喝水，一边慢悠悠泡脚。

![Image](images/img_010.gif)

老大：？？？

![Image](images/img_011.png)![Image](images/img_012.png)

**相爱相杀的少年日常**

步入青少年阶段的大猩猩，亲密依偎与打闹博弈交织在一起。

![Image](images/img_013.gif)

环抱入睡~

他们会手拉手躺在地上睡觉，会互相环抱着进入梦乡，会对视，会轻轻拍打对方的头部…… 这些亲密的行为是大猩猩之间用来增强纽带、巩固关系的重要方式。

老三睡觉，老四亲密守护

在这方面，老三和老四之间的关系尤其特别。老三经常会把头埋在老四的胸口睡觉，或者伸出胳膊搭在老四身上。

但千万不要以为他们只有温情脉脉的一面！同样是小蒜头和枸杞头，有时也会因为一口吃的而产生冲突。

![Image](images/img_014.gif)

这种现象在四兄弟之间极为常见。推搡、追逐、拍打，一套行云流水的“组合拳”下来，谁也不让着谁，谁也不服输。

还有时候，四只猩猩会突然团在一起翻滚打闹，从温馨的理毛瞬间变成激烈的“battle”，完全是一副“打是亲骂是爱”的模样。

老四邀玩被拒

这就是青少年大猩猩群体的真实常态。他们需要在这些看似矛盾的行为中，反复试探并确认彼此的边界。既渴望靠近彼此，又想确立自己的位置；既有深深的依赖，也有不服输的倔强。

对于大猩猩而言，8~12 岁是青春期，12~15 岁则是迈向性成熟的重要转变阶段，15 岁之后便会完成性成熟，正式步入银背阶段。整个成长过渡阶段，也是他们社会关系不断重塑、磨合的过程。![Image](images/img_015.jpg)

互相打闹，却彼此陪伴

未来的岁月里，我们的兄弟团还会继续经历蜕变，解锁更多新鲜故事。而在13岁这个美好的年纪，愿小蒜头能继续在哥哥弟弟们的陪伴下，带着这份自信与快乐，继续成长~
