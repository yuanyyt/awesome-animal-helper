# 一夏一秋，它终于长大了！

![Image](images/img_001.gif)![Image](images/img_002.gif)![Image](images/img_003.gif)![Image](images/img_004.jpg)

本土区的野生松鼠

赤腹松鼠适应力强、生性机敏，常常在树冠间跳跃穿梭，成为本土区一道灵动的风景线。为了支持这些“常客”，我们也会不定期在林缘处放置新鲜水果、坚果，以及供它们磨牙和筑巢用的干草、树皮等天然材料（[你偶遇到他们了吗？](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650856678&idx=1&sn=1a316c98977ab2b4e63c752e29d77b70&scene=21#wechat_redirect)）。

而最近，本土区迎来了一位新成员。它的到来方式却与那些从林中自然闯入的同类有些不同......

![Image](images/img_005.png)![Image](images/img_006.gif)

**谢谢这位家长，也谢谢小朋友**

今年夏天，游客在中心广场捡到了一只尚未睁眼的动物幼崽，小朋友本想带回家自己养，但是在家长的引导下还是选择拨打了我们的救助电话。通过电话里的描述，我们猜测这可能是一只松鼠幼崽。我们接到电话后立刻前往中心广场接回了这只松鼠幼崽，进行了首次人工育幼松鼠的尝试。

![Image](images/img_007.jpg)

尚未睁眼

由于松鼠幼崽处于尚未睁眼的状态，初步猜测不是自己出巢走失的，而是松鼠妈妈在转移巢穴时不慎掉落所致。

![Image](images/img_008.jpg)

最初几天，小松鼠比较虚弱，粪便也不好，我们只能用注射器一滴一滴地喂。经过几天的精细护理，它终于开始有力吸吮，体重稳步上升，排便也趋于正常。

小松鼠从小就展现出了惊人的攀爬能力。它小时候生活在保温箱里的筐里，同在保温箱里的还有其他的幼年哺乳动物，大家各喝各的奶，各睡各的觉。

![Image](images/img_009.jpg)

从小就看出攀爬潜力

结果小松鼠在自己也是摇摇晃晃行动的时候，就能凭借本能从自己的小筐翻出，再爬进邻近筐里“串门”。发现小松鼠如此惊人的攀爬能力后，我们果断把它单独安置，以防打扰其他幼崽。

![Image](images/img_010.jpg)

一个多月后，小松鼠开始长牙了。发现它长牙之后我们就开始给它添加辅食了。

刚开始是尝试啃咬苹果片，一番努力操作之后苹果受了些皮外伤，小松鼠也只能从中吸一点苹果汁；几天后，便能咬下细小果渣。后来随着它逐渐长大，辅食逐步丰富：泡软的谷物粮、去壳的松子、核桃碎......

![Image](images/img_011.jpg)

两个月后，小松鼠从吃奶逐渐过渡到了固体食物，顺利断奶。它的毛发也日渐浓密蓬松，尾巴蓬松如穗，动作敏捷矫健。待它长到成年大小后，我们便开始计划它的去处问题了。

![Image](images/img_012.png)![Image](images/img_013.gif)

**本土小飞侠来咯~**

小松鼠断奶后，我们将其转移到室外适应区，让它接触自然光照、风吹雨露和真实植被，为可能的野外放归做准备。

![Image](images/img_014.jpg)

来到室外咯~

放归自然是野生动物救助的最终目标，但并非所有个体都适合。此前我们曾救护过一只被人长期饲养的松鼠，放归后总习惯性跳上行人肩头觅食，数次尝试均告失败，最终成为了救护中心的长期居民。

![Image](images/img_015.jpg)

爱观察点儿人

这只小松鼠也面临相似挑战。虽在喂养过程中已经尽量减少接触，但毕竟在喂奶的过程中不可避免地要跟松鼠接触，它对人类的警觉性依然偏低。几次户外适应训练中，它都表现出对人的过度亲近。经过一番讨论，我们为它安排了一个新家~

![Image](images/img_016.jpg)![Image](images/img_017.jpg)

黄缘闭壳龟展区

本土物种保育区中有一个展区，这里生活着黄缘闭壳龟，它们多数时间在地面活动，与小松鼠的树栖习性互不干扰。为了让小松鼠顺利过渡到新家，我们对其新居进行了精心改造，增设了枝干、栖架等适合小松鼠活动的设施，还保留了它从小居住的巢箱。

搬家那天，小松鼠带着它熟悉的小巢箱，一起正式入驻本土区啦~

![Image](images/img_018.jpg)

本土小飞侠来咯~

饲养员把小松鼠的巢箱固定在了树上，小松鼠没有表现出拘谨，很快就沿着树枝轻快地跑动起来。我们提供了一些棕榈丝作为巢材，天还没黑，小松鼠就开始忙碌起来，扯着棕榈丝到巢箱里絮窝。夜幕降临时，它准时回到了自己温暖的小窝。

![Image](images/img_019.gif)

絮窝、洗漱，准备睡觉~

如今，这只小松鼠已正式入驻本土区三个星期啦~随着季节变化，黄缘闭壳龟们已进入冬眠状态，常常隐于落叶之下、土壤之中，难得一见。

要跟上小松鼠的步伐~

但别失望！当你来访时，要是寻不见那些慢行的身影，就请抬头看看枝头树丛间。那里常有一抹灵动的灰色身影倏忽掠过，如风似影，在枝条间轻盈跳跃、腾挪穿梭~

![Image](images/img_020.jpg)

一个在沉睡中等待春天，一个在跳跃中温暖冬天。这样的组合，是不是很奇妙？

小松鼠的本土区生活才刚刚开始。我们心中有许多好奇：它将如何适应寒冷的天气？是否已经学会了储存食物？当春天来临，黄缘闭壳龟们苏醒后，它们之间会产生怎样的互动？这只特别的小松鼠会与那些野生邻居们如何相处？

![Image](images/img_021.jpg)

这些有趣的问题，都值得我们持续观察和记录。未来，我们会继续与大家分享这只小松鼠的的成长、探索，和它日常的小故事。
