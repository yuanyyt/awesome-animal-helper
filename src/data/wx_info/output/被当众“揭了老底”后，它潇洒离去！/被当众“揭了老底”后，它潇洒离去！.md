# 被当众“揭了老底”后，它潇洒离去！

![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.gif)![](images/img_005.gif)![](images/img_006.png)![](images/img_007.png)![](images/img_008.png)![](images/img_009.png)![](images/img_010.gif)![](images/img_011.png)![](images/img_012.gif)

“据目击者介绍，有三只‘老鹰’在天上打架，它是打输了的那只。”

它是谁？竟然在放归现场被当众揭了老底啦？！

![](images/img_013.jpg)

黑鸢13号放归现场

没错，它就是本次故事的主角 ——**黑鸢 13 号！**一只在南京天空 “争霸赛” 里不幸落败、摔落地面，却被幸运地捡到并送至救护中心，最终在大家的见证下满血复活、重返蓝天的年轻猛禽。

今天就带大家吃瓜式围观一下黑鸢13号的治愈重生记吧~

![](images/img_014.png)![](images/img_015.png)![](images/img_016.png)![](images/img_017.gif)

**黑鸢小分队再添一员~**

![](images/img_018.png)![](images/img_019.gif)![](images/img_020.png)![](images/img_021.png)

一直关注我们的朋友应该还记得吧~在2026年的爱鸟周仪式上，我们放归了一只戴着“小书包”（卫星定位器）的黑鸢。作为第13只背着“小书包”放归的黑鸢，它也被大家称为“黑鸢13号”。

![](images/img_022.jpg)

眉清目秀的黑鸢13号

在放归仪式当天，黑鸢 13 号凭借出众的颜值圈粉无数，现场不少人被它的帅气打动，纷纷称赞这只小黑鸢 “眉清目秀”，精气神特别足。结合它的体态、羽毛与行为表现，我们判断，它应该是一只年轻的黑鸢个体。

据救助人描述，他看到有三只 “老鹰” 在天上打架，黑鸢13号就是这场空中大战里打输了、不幸从天上掉下来的那一只。

刚被送到救护中心时，黑鸢13号全身上下都破破烂烂的，羽毛凌乱，看起来就是一副被狠狠揍过的样子。经过细致检查，它的伤势整体不算严重，主要是大腿有轻微皮外伤，羽毛多处破损，尾羽还有明显折痕。而且作为在争斗中被击落的“输家”，黑鸢13号大概在身体和心灵上都经受了不小的打击。

![](images/img_023.jpg)

住院柜中的黑鸢13号

被击落的恐惧、争斗落败的不安，让这只年轻黑鸢刚来时很拘谨，总是保持警惕，不敢轻易放松。我们没有频繁打扰，只是为它提供稳定、安全的休养环境，饿了有新鲜食物，困了有安静角落。让它慢慢放松、慢慢恢复。

对于身体上受的伤，我们为它仔细清洁消毒伤口，避免感染；破破烂烂的羽毛我们用温热的毛巾，小心翼翼给折痕熨烫平整。

日子一天天过去，时间慢慢冲淡了这场 “天空战败” 的阴影，黑鸢13号的状态肉眼可见地变好了。从紧张不安到从容淡定，从食欲一般到干饭积极，很快就从住院柜搬到更宽敞的放飞笼，开始自由舒展翅膀、练习飞行。只等天气转暖，等它的体能和状态再稳定一些后，就可以放归了~

而另一只黑鸢，就没有这么幸运了。

![](images/img_024.png)![](images/img_025.png)![](images/img_026.png)![](images/img_027.gif)

**另一只战败黑鸢**

![](images/img_028.png)![](images/img_029.gif)![](images/img_030.png)![](images/img_031.png)

在黑鸢 13 号被救助的同期，救护中心还接收了另一只因同类争斗落败受伤的黑鸢，可这一只黑鸢就没有这么幸运了。

![](images/img_032.jpg)

刚来时左侧脸颊受伤严重

这只黑鸢送来时，脸上血肉模糊，左侧脸颊有一个被爪子抓出的洞，伤口很深，血迹斑斑。

![](images/img_033.jpg)

我们为它进行了清创和护理，经过几天的休养，脸上的伤逐渐愈合，疤痕慢慢淡化。单从外表看，它似乎已经恢复得差不多了。

![](images/img_034.jpg)

脸颊上的伤很快就痊愈了

随着它身体状况的好转，我们按照康复流程将它转移到了放飞笼中，进一步观察它的恢复情况。

![](images/img_035.jpg)

因为眼神不好，看起来有点偷偷摸摸的

可很快，我们就发现了一丝不对劲。这只黑鸢每次试图降落栖架时，总是差一点点准头，常常在栖架前方直接垂直下落，始终没办法稳稳地站立在栖架上，飞行与降落的协调性明显异常。

![](images/img_036.jpg)

为黑鸢检查视力

为了找到问题根源，我们又对它进行了全面检查，排查原因。结果不太乐观，这只黑鸢看起来伤势很重的左眼没有问题，反而是看起来没有外伤的右眼已经失明，对光没有任何反应。

加上这只黑鸢刚开始来到救护中心的时候进食状态很差，几乎不肯主动进食，直到慢慢熟悉环境、和其他黑鸢共同生活后，才逐渐安心吃饭。综合身体机能、生存能力等多方面评估，我们最终判断，这只黑鸢似乎还不具备野外放归条件，只能暂时留在救护中心，接受长期的照料与保护。

![](images/img_037.png)![](images/img_038.png)![](images/img_039.png)![](images/img_040.gif)

**繁殖季黑鸢的“爱恨情仇”**

![](images/img_041.png)![](images/img_042.gif)![](images/img_043.png)![](images/img_044.png)

看到这里，很多人会好奇：为什么这段时间会接连出现黑鸢争斗受伤的情况？

![](images/img_045.jpg)

接收到的第3只被打落进水里的战败黑鸢

正在康复中......

其实，这是因为黑鸢的繁殖季到了。

自 4 月以来，南京黑鸢种群陆续进入繁殖季。

![](images/img_046.jpg)

繁殖季，正在孵卵的黑鸢6号 ©陈冬銮

而繁殖之前，还有一个必不可少的关键环节，那就是求偶。春天的南京天空，就像一座热闹的自然剧场，黑鸢们在这里上演着属于它们的 “爱恨情仇”：求偶期的黑鸢，会彼此追逐、上下翻飞、紧密相随，用优美的飞行姿态表达心意；

同时，为了争夺优质领地、争取繁殖机会，年轻的黑鸢个体也会主动发起挑战，与同类展开激烈争斗，为了生存与繁衍奋力一搏。

这两只黑鸢就是这个时候被送到我们救护中心的。

结合繁殖季的行为特点我们推测，黑鸢13号作为年轻的个体，可能是为了挑战繁殖机会，主动加入天空争斗，才在争斗中落败坠落。黑鸢13号虽然输了，但它的失败并不是一件坏事。从个体的角度看，这是一次挫折；但从种群的角度看，这可能恰恰是一次正常且必要的自然选择。

这场看似狼狈的空中争斗，也是黑鸢种群保持活力的重要因素之一。正是因为有了这样的竞争，不够强壮的个体可能会被暂时淘汰，而留下来的、或者康复后重新起飞的，往往是体能和意志都更胜一筹的“精英鸢”。它们在这样的环境中不断磨砺、不断成长，让整个种群保持了健康的竞争力和出色的活力与韧性。

黑鸢13号重回天空~

黑鸢13号的故事，到这里暂时告一段落，但它在天空中的旅程才刚刚开始。如今黑鸢13号正背着它的小书包，重新成为了南京天空的一部分。而那只无法回到野外的黑鸢还会暂时留在救护中心继续生活、康复。

![](images/img_047.jpg)

留在救护中心继续生活

竞争是自然的法则，而守护是人类的温柔。希望南京的天空，永远有黑鸢翱翔。希望每一只勇敢挑战过、落败过、又重新站起来的“黑鸢13号”，都能飞得更高、更远。

转眼，黑鸢13号已经放归快20天了。后续的追踪数据显示，黑鸢13号现在大多活动在潜洲附近。每天认真觅食。小日子过得有模有样。关于它会不会再次鼓起勇气，发出新的繁殖挑战？会不会从“落败方”逆袭成功？我们不知道答案，但我们一起期待看看吧~
