# 变红，是早晚的事儿

**它们怎么黑漆漆的！**

**和旁边的红色是一类吗？**

**它们到底是谁家的崽呀！**

**...**

这样的质疑声时常在红山冈瓦纳美洲红鹮住所门口响起，而作为“当事鸟”的它们，也有话要说！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)

“误会！我从小，就是鸟界里反差十足的‘别鸟家的孩子’。幼时一身乌黑，和我的爸爸妈妈毫不一样，也毫不起眼；历经漫漫成长，才会褪去暗绒，慢慢从黑变红！”

而这份极具冲击力的色彩蜕变，

就像美洲红鹮成长的魔法。

走！一起去瞧瞧！

![Image](images/img_004.png)

**这块育儿宝地，**

**我先预定啦！**

![Image](images/img_005.png)![Image](images/img_006.png)

当春季的暖阳渐浓之时，平日里早已两两配对的美洲红鹮，悄然开启了属于他们的繁殖季。雌鸟与雄鸟的喙色由粉转黑，喉部微微鼓起，仿佛在宣告：新生命的孕育即将开始。

![Image](images/img_007.png)

为了让红鹮的巢穴更加稳固，饲养员提前在地面摆放好长短、粗细各不相同的树枝与竹条，鸟儿可以随心挑选建材，搭建缝隙更小、更结实的巢穴。

![Image](images/img_008.png)

这是我看中的“育儿宝地”！

不过筑巢初期，林间总上演着热闹的“邻里小纷争”。一对红鹮夫妇刚刚搭建好巢基，隔壁邻居便会悄悄飞来“偷袭”，叼走关键树枝，打乱对方的筑巢进度。你来我往的小争执持续数日，都是为了抢占心仪的巢位。

从0开始，合力完成

待巢位尘埃落定，红鹮们便褪去打闹心性，专心筹备繁衍大事，分工协作各司其职：雄鸟主动外出采集、搬运巢材，雌鸟则留守巢穴，精细搭建、修整，用心构筑温暖的小家。

![Image](images/img_009.png)

噔噔噔～搭好啦

为全方位守护后续雏鸟安全，饲养员在巢穴下方搭建了双重防护体系。底层增厚铺上稻草、木丝等柔软垫料，既能保护成鸟与雏鸟的脚掌，也能缓冲坠落冲击力；同时在巢位下方绑扎防护安全网，双重兜底最大程度降低意外风险，即便有雏鸟不慎掉落，也能最大程度保障其安全，为后续人工介入育幼留存充足空间。

![Image](images/img_010.png)

巢址安稳落地，营养供给也同步升级。饲养员针对性调整了红鹮的日常食谱，大幅提升虾在食谱中的比例，同时搭配新鲜鱼泥，并且在鱼泥中添加钙质及多元营养粉剂，提高了红鹮对营养的吸收效率，让亲鸟拥有充沛体力安心孵蛋、照料幼鸟。

![Image](images/img_011.png)![Image](images/img_012.png)

**我****要飞！我要红！**

![Image](images/img_013.png)![Image](images/img_014.png)

安稳的巢穴、充足的营养，一切准备就绪，红鹮家族的新生故事，便在林间静静酝酿开启。

![Image](images/img_015.jpg)

各自筑好了巢，开始孵化

红鹮孵蛋全程由雌雄亲鸟共同完成，孵化周期大概在19至23天。夫妻俩分工默契，轮流值守巢穴。一只安卧巢中恒温孵蛋，另一只便细心修整巢穴、清理杂物；等到“换班”时刻，孵蛋的鸟儿便可以走出巢穴，踱步觅食、梳理羽毛，或在水畔沐浴休整，待体力恢复再换岗接力。

换班中

在孵化过程中，雄鸟还会衔些材料回来，将鸟巢进行扩大、修补。

![Image](images/img_016.gif)

一起修补

终于，某日清晨，细微的啄壳声从巢中传来，第一只雏鸟顶破了蛋壳，浑身裹着黑绒般的胎毛，与父母艳红的羽色截然不同。这暗沉的伪装恰是大自然给到的天然保护色，深色绒毛能完美融入阴影处，大大降低被天敌发现的概率。

![Image](images/img_017.gif)

作为典型的晚成鸟，刚破壳的红鹮雏鸟双眼未完全清亮，行动孱弱无力，绝大部分时间都蜷缩在亲鸟温暖的羽翼之下安睡，几乎不会做出大幅度活动，进一步降低自身暴露的风险。只有当外出觅食的亲鸟归巢，感受到熟悉的动静时，小脑袋才会缓缓探出，等待亲鸟喂食。

![Image](images/img_018.gif)

而美洲红鹮有着十分特殊的喂食方式。亲鸟不会直接将食物送入雏鸟口中，而是由雏鸟主动将细长的喙伸进亲鸟口腔内部，亲鸟再将提前摄入、经过初步消化的半流质食物反刍出来，供给雏鸟进食。经过一道消化工序的食糜温和易消化，能最大程度贴合雏鸟脆弱的肠胃，让幼鸟高效吸收成长所需营养。

![Image](images/img_019.png)

我要飞！

在亲鸟日复一日的守护与喂养下，雏鸟稳步发育，出壳一个月后，雏鸟羽翼逐渐发育完全，正式开启学飞之旅。红鹮学飞循序渐进，没有莽撞的高空冒险，全程稳步成长。一开始它们只会站在巢边反复扑扇翅膀，锻炼羽翼力量；之后慢慢尝试短距离跳跃，在周边树枝上来回练习起落；经过一周左右的反复练习，才敢真正离开巢穴，完成鸟生第一次低空飞行。

![Image](images/img_020.png)

和亲鸟一起觅食

初次离巢的雏鸟飞行技巧生疏，落地之后只能笨拙地在垫料上行走，完全不会自主觅食。它们会紧跟在亲鸟身后，在浅水岸边观察学习捕食泥鳅、采食鱼虾的技巧，经过几天的学习，慢慢掌握独立觅食的本领。

![Image](images/img_021.png)

一点点慢慢来

比起落地觅食，飞回高处巢穴要难得多，幼鸟现阶段还无法直接起飞归巢，这可怎么上去呢？只见，他们顺着带有坡度的树干，一边轻轻振翅，一边缓步跳跃，一点点慢慢回到自己的巢穴旁休憩。

![Image](images/img_022.png)

我是大宝宝了，但也想粘着爸爸妈妈

随着第一轮的幼雏的逐渐独立，亲鸟很快迎来了第二轮的育雏孵化。那些已经会自己找食物的幼崽，偶尔还会来到爸妈身边，不停地用喙去戳爸爸妈妈的嘴巴，想从它们的喙里“讨要”食物。这时候通常会被拒绝：飞走——但如果实在粘得紧，父母偶尔还是会给上一口。

快给我嘛！我还是个宝宝！

告别亲鸟照料只是成长的第一步。红鹮羽色由灰黑转为绯红，更是一场漫长而无声的蜕变，从灰黑到黑褐，再渐渐透出淡红，最终沉淀为鲜红，整个过程需要一年多的时间才能完成。

![Image](images/img_023.png)

我变红，是时间的问题！

当红色完完整整地覆满全身，它们彻底告别幼时不起眼的模样，长成独属于自己、热烈明艳的美洲红鹮。

而我们期待那一刻的到来！
