# Mora mora，慢慢来、慢慢来~

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)![Image](images/img_006.png)![Image](images/img_007.png)![Image](images/img_008.png)

在红山南门新区还未开放的这个春天

新生命们在这片土地上诞生

也是在这里

出生时仅仅不到100g的它

遇到了它的猴生危机

![Image](images/img_009.png)

**01 你们都要好好的~**

![Image](images/img_010.jpg)

4月初，生活在南门新区马达加斯加的环尾狐猴莉莉，诞下了两个新生命。环尾狐猴家庭通常一胎一崽，偶尔也会有双胞胎诞生。然而令人遗憾的是，莉莉的其中一只幼崽因为身体虚弱离开了我们...

饲养员给留下来的另一只幼崽取名coco，并针对这次莉莉诞生双胞胎的罕见情况，饲养员和兽医在莉莉生产后，一直密切监测着她和coco的身体指标和活动状态。

饲养员明显观察到，莉莉在面对美食时显得食欲不佳，活动量也明显减少，比起前往外运动场活动，她更喜欢守在巢箱里陪伴着coco。更令人担忧的是，coco手指的抓握能力跟同龄期的小猴对比也显得较弱，要反复调整好几次才能抓在母亲身上。

![Image](images/img_011.gif)

通过兽医的诊断，莉莉出现了产后缺钙的情况。

产后缺钙是许多哺乳动物在生产时都可能出现的危机，所以我们的饲养员在每一个动物生产前后都会为她们提供钙、蛋白质等营养的补充，以帮助她们顺利度过生产期。

但显然，这次莉莉孕育双胞胎的消耗超过了预期，针对这次突发情况，兽医团队立即采取治疗手段为莉莉补钙；饲养员重新调整喂食方案，通过不同的饮食搭配，希望莉莉能够有动力进食。

饲养员还为莉莉和幼崽coco在内室准备了松软的木丝垫料，防止幼崽coco会因为抓握不稳而坠落。

![Image](images/img_012.jpg)

产后缺钙多与哺乳期钙质通过乳汁大量流失有关，饲养员为了减轻莉莉的喂养负担，研究了国内外环尾狐猴育幼的案例手册，调配出接近母乳成分的代乳，并每天人工为幼崽coco补一次奶，同时借着喂奶的机会监测coco的体重。

![Image](images/img_013.png)

**02 慢慢来 慢慢来~**

遗憾的是，这场危机并没有轻松地度过。

在饲养员接下来一段时间对莉莉和幼崽coco身体健康的监测中，coco的体重一直呈现逐渐下降的趋势，莉莉的身体指标也并不乐观。

饲养员不得不做出了一个艰难的决定——人工育幼。他们将coco和莉莉分离出群体，对coco开始了人工育幼、对莉莉进行单独护理。

![Image](images/img_014.png)

刚分离出群体的coco体重不足100g，饲养员每隔1.5h-2h就需要为coco进行一次人工喂养，并在饭后用湿纸巾擦拭coco的肛门，帮助coco排便，观察排便的形态和量，进一步做健康判断。

![Image](images/img_015.jpg)

环尾狐猴幼崽coco的粪便

一开始，coco的体重增长比较缓慢，饲养员也会担心：这样是不是太慢了呀？要不要再多做一点什么？

通过使用不同营养成分的奶粉、添加额外的微量元素，饲养员尝试调整代乳中脂肪、蛋白质、乳糖等不同营养成分的比例，同时观察coco的粪便形态，想让coco的体重增长更快一点。

可是，coco的体重变化仍然不明显，并有几次粪便状态不理想。饲养员及时换回了coco适应稳定的代乳配方，看着coco每天蹦蹦跳跳的样子。**饲养员想：就算coco体重增长缓慢，但只要它身体健康、有活力，缓慢也是一种生命的成长节奏！Mora mora，慢慢来、慢慢来~**

![Image](images/img_016.gif)

另外一边，由于莉莉进食欲望不高，每天吃得都很少。饲养员为了能让莉莉多吃一点，调整了莉莉每一餐的水果蔬菜和树叶的比例，通过健康营养的搭配，鼓励莉莉进食。并每天通过拍照、称重记录莉莉每一餐的餐前餐后都吃了什么、吃了多少，进一步判断莉莉的进食情况。

同时，通过保定措施配合药物治疗，为莉莉的身体健康做更多的保障。

![Image](images/img_017.jpg)

莉莉的每一餐

![Image](images/img_018.png)

**03 一起拥抱太阳吧~**

![Image](images/img_019.jpg)

随着时间一天天地过去，莉莉逐渐恢复，已经能够在内场中自如地探索攀爬了。Coco也一天天地长大，体重从四月初的不足100克，增长到五月中旬的160克！看着她抱着煮熟的胡萝卜条一口一口津津有味地姿态，饲养员也倍感欣慰~

![Image](images/img_020.gif)

饲养员还给coco找到了一个秘密武器——咬胶，来帮助coco在成长初期中发育环尾狐猴标志性的“梳齿”，为日后独立进食坚硬的自然食物做好准备。

![Image](images/img_021.gif)

六月来临，莉莉康复，coco也长成了一个调皮好动的小家伙。饲养员开始尝试让这对历经磨难的母女隔网重聚。

![Image](images/img_022.gif)

一开始coco还会对莉莉感到陌生、对陌生的环境感到害怕，会小心翼翼地躲在毯子里观察周围；莉莉则是十分好奇，会主动上前打量这个小家伙。

等到八月，莉莉和coco的状态已经十分稳定了。天气也日日晴朗，饲养员认为时机已经成熟，决定让她们正式合笼！经过之前的接触，莉莉和coco已经十分熟悉了。

![Image](images/img_023.gif)

刚开始合笼，莉莉就主动和coco拉近了距离，但coco似乎不习惯这样突然的亲近，小心翼翼观察着莉莉的身影，偶尔还会被莉莉在树林中奔跑时的动静吓一跳。

渐渐地，coco习惯了莉莉这位大家长的存在，会观察莉莉的一举一动，学习她的样子尝试嚼嚼树叶，也会跟随莉莉的脚步去树枝上跳跃、感受树荫和自然。当然，也会和莉莉一起张开双臂，感受阳光的洗礼。

莉莉也会将coco抱在胸口，为她舔舐毛发，带领她一起探索这个新世界。而这些，都是人工育幼无法教给coco的。

![Image](images/img_024.gif)

如今，莉莉、coco和另外一只雌性狐猴生活在一起组成了一个新的小家庭，群体生活是环尾狐猴天性中不可或缺的部分。相信coco会在莉莉的带领下，学习到更多群体中生活的技能，延续她母辈们的美丽风采~
