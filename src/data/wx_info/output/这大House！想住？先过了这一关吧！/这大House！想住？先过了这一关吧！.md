# 这大House！想住？先过了这一关吧！

![Image](images/img_001.png)

2026年3月25日，黑猩猩一家从猩猩馆搬来了非洲区。为此，它们在经历了长达数月的“默契大考”后，成功交出了2小时速通搬家这种奇迹般的答卷（[这两个小时，全凭自愿！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650889462&idx=1&sn=c1dd5269a8282445945dd4ed04cd0f99&scene=21#wechat_redirect)）。但新的挑战接踵而至...

**离开熟悉的家园后，**

**面对未知的新家它们会如何开启新生活？**

![Image](images/img_002.jpg)

快跟上我们的镜头，一起去看看这场新家“变形记”吧～

**01**

![Image](images/img_003.png)

**这吃的怎么不一样啊！**

![Image](images/img_004.png)

黑猩猩属于杂食性动物，它们的食谱非常丰富。在黑猩猩的每日的菜单上，饲养员会精心准备营养均衡、科学搭配的食材，同时也会根据季节的变化来调整食物种类，提供丰富多样的选择。

![Image](images/img_005.jpg)

在吃猕猴桃的小铁豆

去年这时，黑猩猩一家就曾花样百出，只为吃到甜甜的椰子（[当他掏出“流星锤”...](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650865560&idx=1&sn=f54f5b1bf0651a431bf5db1c1d08f368&scene=21#wechat_redirect)）；在日常生活中，还能获得南瓜、木瓜、哈密瓜，以及丰容中的梨子、西瓜等限定美味。

但搬进新家的黑猩猩一家发现，以前琳琅满目的美味、刚来新家时还能见到的那些多汁小零嘴，在入住后怎么很快就变成稀有资源了？

![Image](images/img_006.jpg)

**那么？水果都去哪里了呢！**

这并不是水果消失了，而是过去吃得太好了！

在进入新家后，饲养员团队发现我们的黑猩猩们有点挑，对蔬菜树叶等食物的采食比例较低，通过与博格斯动物园的专家交流后，饲养团队决定开启循序渐进的食谱调整计划。第一步就是将水果减量，增加糖分更低更健康的多种蔬菜和树叶的比例。

很快我们发现黑猩猩们的采食时长、采食种类与粪便情况有了一些积极的转变，而水果与红枣等高能量高糖分的食物再出现时，仅作为训练奖励物，这给黑猩猩一家开启新环境适应性训练打好了基础~

**02**

![Image](images/img_007.png)

**叮叮叮！新课堂开课啦～**

![Image](images/img_008.png)

黑猩猩入住新家第一课：**先认门。**

后场对于毛孩子们而言，不仅是一个可供休息、生活的居所，也是日常行为训练和个体管理的重要空间，想让它们一下子能够足够信任并理解新家的结构可没那么简单。

所以，在到达新家后，为了让黑猩猩一家感到安全，它们熟悉的老饲养员会带着新饲养员们一起操作，当新饲养团队与动物建立起一定信任和合作关系后，再开始后场各个室内空间转移的训练。

这时，水果在训练中起到了关键作用——饲养员首先给予黑猩猩们足够的时间观察新环境与空间布局，包括所有关键闸门和通道的位置和开关方式。当黑猩猩们已经能够理解和感知空间的变化后，饲养员便会开始引导它们转移位置。当它们选择按照口令，到达饲养员指定的位置之后，立刻获得奖励。

![Image](images/img_009.gif)

在这个过程中，饲养员也观察和学习到这个群体内部的一些等级和个体差异——比如在年幼的这一辈中，小玉的孩子黑豆由于母亲地位更高，所获资源较多，体型偏大，体重略有一点超重，而幼小的弟弟铁豆则和母亲一样相对弱势，在群体取食中并不会因为年纪小被偏爱，反而不容易抢到足够食物，需要更多的进食机会。

![Image](images/img_010.jpg)

为此，饲养员团队对小玉、黑豆和小珊、铁豆实施了分区域定点的喂食策略。

在喂食时段，饲养员会同时在多个位置放置食物，通过引导将黑豆和铁豆分隔到后场不同的房间中，但不强行进行物理隔绝（关门），既保证了每只黑猩猩都能安心吃饱，黑猩猩们也不用因为被隔绝开而不安，在进食结束后，每只黑猩猩也能够有充分的自由活动空间。

![Image](images/img_011.jpg)

铁豆和妈妈一起在外场~

**03**

![Image](images/img_012.png)

**铃声到！猩也到！**

![Image](images/img_013.png)

非洲区这个家中，最核心变化莫过于空间更复杂、层次更丰富。让黑猩猩们明白，进入陌生环境、回到内舍小房间、甚至暂时关门等，都不是为了减少它们的空间选择，而是有好事发生的信号，这是它们和我们一起共同适应的第二课——在控制与自由中找个平衡。

开课之前先做点准备~ 此次搬家前，黑猩猩乌豆早已作为先行者率先探索了整个运动场，并且对新的环境表示了相当肯定。但对于一个黑猩猩群体来说，它们是高度社会性动物，可以通过合作来完成一些“个猩”完成不了的事。

![Image](images/img_014.jpg)

所以，饲养团队要先对室内运动场做一番改造——调整绳索摆荡的幅度，加固可能被挪动的木桩，保障新家、新生活的安全。

直至4月底的一天，后场通往室内运动场的那道门缓缓打开了。

黑猩猩一家正式解锁了新家的室内运动场。但是，黑猩猩一家对这个新空间既充满好奇，却也带着警惕——在探索运动场的初期，群体中总会留下一只成年的大家长守在门口，关注着闸门的动向。

![Image](images/img_015.jpg)

饲养员对此也表示很理解，毕竟当拥有了更多空间和选择，谁也不愿意轻易失去，动物们也一样。因此当它们表现出对于关门的抗拒时，先将门开着，给黑猩猩们一个可以自由选择的空间。来或不来，全凭‘猩’意～

为了让黑猩猩更安心地使用更大更复杂的新空间，并能够每天多次或在特殊情况发生时能回到内舍，方便饲养员对环境做更多变化。饲养员团队为它们配套了一个专属的召回铃声。这个声音选得很讲究，是一个能发出柔和、低频的声音的小铜锣，在作为引导的同时希望能够在训练时也能让它们保持这样柔和的心情。

![Image](images/img_016.jpg)

在新家增加的不止室内运动场的面积，还有整个空间高度的提升。饲养员就可以通过在室内运动场二层平台的观察窗敲响锣声引导黑猩猩到指定位置等待，等全部个体就位之后，由另一名饲养员在下方完成关门的操作，然后给予黑猩猩一些奖励，加深每天日常操作的稳定性与安全性。

![Image](images/img_017.gif)

定点的响应已经非常及时了~

如果某只个体不愿意配合，饲养员也绝不强求，而是给它留出选择空间。

如今，通过这样长期"定位—等待—关门—奖励"的正强化训练，黑猩猩一家已经能够与饲养员合作完成新家室内室外各种空间的随时转换，并让它们理解这样的转换都是以尊重它们选择意愿的前提下进行，希望这样它们也能在新家感受到更多对空间环境的控制，从而过的更平和放松。

而日常饲养员的操作也更加顺畅和安全，因此能有更多机会把时间放在做更多福利工作上。动物的自由度与环境的可控性暂时找到了个平衡。

![Image](images/img_018.jpg)

打包回上面咯~

黑猩猩是典型的树栖动物：攀爬、悬吊、高处瞭望，是刻在基因里的习惯。在新的场馆里错落有致的栖架、垂直分层的空间，正好满足了这种天性。

它们在习惯新家后，也会在高处一起理毛、传递食物、玩耍。饲养员在日常提供食物时，也不用刻意设置在高处，而是自然放置到场馆各处之后，自会有猩过来然后将食物带到高处取食。

![Image](images/img_019.jpg)

记得抬头看！

各位游客们在午饭时刻来到这里时，不要疑惑为什么天上会下起麻麻雨啦~ 你抬头看看或许能发现惊喜呢！

![Image](images/img_020.png)![Image](images/img_021.jpg)

黑猩猩一家在外场

![Image](images/img_022.png)

从3月25日的初来乍到，到如今在外运动场肆意奔跑，短短两个月，黑猩猩一家完成了一轮又一轮探索的生活。

目前，黑猩猩一家正在开始增加更多探索外场的机会，而未来也许更多新的课程也即将开启。黑猩猩在外场自然的氛围中又过着怎样的生活呢？让我们一起期待下一期的精彩吧！
