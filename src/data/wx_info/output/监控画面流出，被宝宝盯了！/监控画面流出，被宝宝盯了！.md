# 监控画面流出，被宝宝盯了！

j'x![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)

是谁家的小猴，

抱着监控不撒手？
小脑袋还凑那么近。

![Image](images/img_005.jpg)![Image](images/img_006.gif)![Image](images/img_007.jpg)

先留个悬念，

彩蛋放文末，我们慢慢往下看。

![Image](images/img_008.png)

上次说到（[重要的是：给新手一点时间~](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650874134&idx=1&sn=4ff2f0368a0f4204ef2fd5140e9ce8d1&scene=21#wechat_redirect)），第一次当妈妈的红背须僧面猴喜桃，第一天带崽就手忙脚乱：压住宝宝、挂错大腿……好在给彼此一点时间，第二天母子就默契满分。

![Image](images/img_009.jpg)

喜欢

时光飞逝，曾经那个需要小心呵护的喜欢一天天长大了。可谁能想到，当初那个乖巧宝宝喜欢，如今竟惨遭亲妈“嫌弃”？

“不想带！不想管！”

这究竟是当妈的变心了，

还是这娃实在太皮？

![Image](images/img_010.png)

**你折腾你的，我吃饱再说**

就在喜欢两个月大的时候，

这个小调皮已蠢蠢欲动！

只要妈妈喜桃专注享受美食时，稍不留神就会发现，喜欢开始“脱离”妈妈的背了，先是只敢在妈妈身边探头探脑，渐渐地敢离开妈妈背，独自趴上旁边的树枝。

![Image](images/img_011.png)

起初，喜桃被这大胆操作弄得左右为难：刚坐下吃一口，又站起来瞅瞅娃；确认安全后刚低头啃两口，又忍不住抬头瞄一眼。短短几分钟，反复起立坐下，眼睛在食物和娃之间来回切换，愣是没吃上几口。最终她还是败给了担忧，赶紧把喜欢拽下来，重新拢回怀里。

![Image](images/img_012.gif)

但后来，情况悄然改变。

一是：喜欢的攀爬越来越稳当；

二是：吃，实在太重要了！

喜桃开始学会“选择性忽略”，抬眼扫一眼喜欢的位置，确认摔不下来，便收回目光继续埋头苦吃；偶尔喜欢发出一些动静，她也就头往上看看，嘴却不停；再后来，干脆连头都懒得抬，只顾一猴库库猛啃。

![Image](images/img_013.gif)

喜桃：你自己玩去吧，别打扰妈妈吃饭了

就这样喜欢的探索欲和喜桃的保护欲，终究在食物面前达成某种默契：你折腾你的，我吃饱再说。

你以为这就“不闹腾”了？！

喜欢的调皮就这？

那你可小看喜欢了！

**妈妈不给我？肯定巨好吃！**

随着月龄增加，喜欢的食物也从妈妈的乳汁，逐渐过渡到了果实。

![Image](images/img_014.jpg)![Image](images/img_015.jpg)

起初它只是个“捡漏小能手”。尤其是大家一起吃食物时，喜欢就趴在她背上，伸着手去够那些从妈妈嘴边掉落的碎渣或是别的叔叔姨姨吃掉落的食物。偶尔够着一小块，捧在手里翻来覆去看半天，才试探着往嘴里塞。

![Image](images/img_016.png)

可很快，小家伙就不满足于捡漏了。

开始升级成了一个“抢食小能手”。只要妈妈手里捧着食物，喜欢就会立刻开启“硬抢”模式。它先是整个身子贴到妈妈背上，小脑袋从妈妈的肩头探出来，趁妈妈张嘴的瞬间，一只手直接伸了过去。

![Image](images/img_017.jpg)![Image](images/img_018.jpg)

喜桃发型已乱

如果妈妈护得紧，喜欢就会使出“小绝技”，用两只小手捂住妈妈的眼睛，让妈妈看不清东西，趁其不备，猛地伸出手去抢夺。它甚至会爬到妈妈的头上，整个身体倒挂下来，用尽全力去够妈妈手里的食物，小手在空中胡乱挥舞，不达目的誓不罢休。

![Image](images/img_019.jpg)![Image](images/img_020.jpg)

主打一个喜桃吃得越专注，

喜欢就抢得越厉害！

“妈妈不给我，

肯定巨好吃，我要吃！”

**在妈妈的余光里长大**

就连每天傍晚回内室时，贪吃的喜桃总是第一个往通道冲，急着去挑选自己爱吃的食物。而喜欢呢？

早就不知在哪个角落探索得正欢，

哪里跟得上妈妈“干饭”的步伐。

![Image](images/img_021.png)

独自探索到高处的喜欢

起初被甩在身后的喜欢还有些紧张，但也自有妙招。它站在通道入口的高处，随机锁定一位路过的雄性，找准时机，“蹭”地一下跳过去，稳稳挂在那猴背上。

等跟着“便车”进了内室，再轻巧地跳下来，继续独自玩耍。直到它玩累了、喜桃也吃完食物后，他俩才会一起回到巢箱，挨在一起沉沉睡去。

![Image](images/img_022.png)

就这样，日复一日，喜欢在探索中慢慢长大。如今七个月大的喜欢，独处的时间越来越多啦！

![Image](images/img_023.png)

一会在绳索间荡来荡去，一会在树冠层找个舒服的枝丫打盹，一会又蹦到妈妈面前，把小脑袋凑过去让喜桃帮它梳理毛发，没梳理两下又蹿没影了......就这样，整个环境都是它的游乐场，到处都留下它上蹿下跳的身影。

![Image](images/img_024.png)

妈妈喜桃呢？压根不管他在哪、跟谁玩，只顾自己吃吃喝喝。只有当她敏锐地察觉到外界有一丝不安，才会立刻放下手中的食物，飞快赶到喜欢身边。

![Image](images/img_025.png)

喜欢：妈妈你咋来了？

大概在喜桃眼里，放手也是一种爱。时光就这样不紧不慢地走着，喜欢也在妈妈的余光里慢慢长大～

![Image](images/img_026.png)

享受妈妈理毛的喜欢

等等，还没结束呢！

开头那个对摄像头“下手”的好奇宝宝，

现在第一视角来啦！
