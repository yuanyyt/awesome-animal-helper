# 虎山姐妹花怎么就分了家？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)

**虎山姐妹花——图图和奇妙**

**怎么刚过完8岁生日，这就分了家？**

![Image](images/img_004.jpg)![Image](images/img_005.png)

**好姐妹说散就散~**

![Image](images/img_006.png)![Image](images/img_007.png)

在红山虎山，三胞胎图图、奇妙和咖啡在6月15日刚刚过完8岁生日，在大家的印象中，姐妹花图图和奇妙总是形影不离。

在冬天，饲养员会在放干水的水池里铺满厚厚的落叶，奇妙和图图就会依偎在一起睡觉，偶尔互相蹭蹭脑袋，画面温馨。她们既是血脉相连的亲姐妹，也是一起彼此的玩伴~ 可今年年初，曾经亲密无间的姐妹，开始不再温馨同框。

![Image](images/img_008.jpg)

在虎馆外一的两块“荣耀石”上，图图常踞高处，奇妙则守在低处——这是她们默契的领地划分。但现在，偶尔图图从高处的石头下来，还会冲着低处“荣耀石”上正在休息的奇妙发出低吼，奇妙只好悻悻离开，另找休息的地方。

![Image](images/img_009.jpg)

对野外的虎而言，除了交配期和母虎两三年育幼期外，它们大多是独自生活。饲养员敏锐捕捉到的图图和奇妙这种微妙而紧张的关系变化，也许，是时候让她们分开去开启新生活~

经过评估，饲养团队做出了一个重要决定：让图图搬家到非展示区，进行新环境的脱敏训练和行为训练。

![Image](images/img_010.jpg)

相处的尾声~

为什么是图图呢？这个决定背后藏着更长远的考量——经过长期观察，饲养员发现图图的适应性更强，胆子更大，也是行为训练经验丰富的优等生。

这样优秀的图图到了新环境后也能够快速建立与新饲养员的信任，更好地完成将来与适龄雄虎大山见面的一系列适应性训练。图图和大山的故事又该如何？让我们慢慢期待吧～

![Image](images/img_011.jpg)

![Image](images/img_012.png)

**独居之后、进步飞速**

![Image](images/img_013.png)![Image](images/img_014.png)

图图离开后的日子，奇妙开始了她的独居生活。饲养员很快发现，奇妙其实也有胆大的一面，只是以前被图图的光芒掩盖了。为了帮助奇妙重建信心，饲养员立即为她“私虎订制”了新生活方案。

![Image](images/img_015.jpg)

虎的日常喂食分为高、中、低三个位置，用于不同目的的训练：力量训练时，大块肉类会放在低处，方便老虎撕扯、啃咬；取食训练时，装有食物的纸袋则会挂在高处，鼓励老虎跳跃、探索。

以前，因为两只虎在一起，丰容的食物位置往往是一个折中的“平均值”。现在，一切都以奇妙为中心，为了奇妙，再降低一点点难度～

这种精准的照顾，立竿见影。饲养员很快就发现，奇妙变了！

![Image](images/img_016.jpg)

她不再小心翼翼，而是开始在偌大的场馆里到处嗅探，留下自己的气味。她开始尝试爬上曾经不敢涉足的高处，眼神里多了几分从容。最明显的是，她的食欲变好了。食欲变好后，饲养员开始考虑，要不要再给奇妙多尝试一点环境丰容呢？

![Image](images/img_017.jpg)

在红山动物园的虎馆，有一条特殊的空中走廊——天猫通道。这是连接室内与外三运动场的重要通道，老虎们可以通过这条通道走到室外展区，也可以站在上面俯瞰整个园区。这对老虎来说是极佳的丰容设施，但对于奇妙来说，这条通道却是个大“难题”。

![Image](images/img_018.jpg)

有的虎不敢上，但有的虎已经睡上了~

为了让奇妙克服恐惧，饲养员们可是费了不少心思。首先，饲养团队更换了天猫通道地面上下坡的垫材，换成更防滑的木板，还在通道中铺了一层老虎们喜欢的长颈鹿用过的稻草，让虎能够更喜欢待在这里也更舒适。

![Image](images/img_019.png)

每次训练时，饲养员会把适量的食物分段悬挂在通道的不同位置，然后在天猫通道外，一步步引导奇妙向前走。

![Image](images/img_020.jpg)

刚开始的时候，奇妙在饲养员的目标棒加美食的引导下，能够小心翼翼地踏上通道，迈出试探的步伐。然而，就在通道后半段的一个转弯处——那里是一片开阔区域，饲养员无法再用目标棒引导——奇妙犹豫了片刻，果断地掉头，扭头就往回走。

![Image](images/img_021.gif)

好吧，学习这件事，还是慢慢来～ 给她一点适应的空间，期待她准备好的那一天。

![Image](images/img_022.png)

**各自为王，顶峰相见~**

![Image](images/img_023.png)![Image](images/img_024.png)

今年5月，也就是图图搬走两个月后，她完成了在非展示运动场的初步适应，再次回到大家的视线里。

![Image](images/img_025.jpg)

悠闲生活的妈妈丹丹~

奇妙和图图各自拥有了自己的领地和外出活动时间。饲养员也在持续观察虎与虎之间的关系，合理安排六只虎轮流使用虎馆的外场空间，让每只虎都能在安全的环境中享有专属的活动时间，用精心考量让每只虎都能获得尽可能多的福利。

![Image](images/img_026.jpg)

自由自在的大男孩咖啡~

饲养团队通过悉心观察，发现每只个体的需求，通过各种调整给它们最适合的生活环境。无论是让图图搬家，还是决定让姐妹俩分开，每一个决定都是饲养团队基于对动物行为的观察和科学评估。

![Image](images/img_027.jpg)

下次你来红山动物园，不妨去虎馆看看，去观察图图奇妙和她们伙伴的生活，进而了解虎在自然环境下的生存故事，这趟观虎之旅一定会收获满满~
