# 从“黏姐六宝”到“独立青柠”~

黏![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.png)![](images/img_005.png)![](images/img_006.jpg)

六宝青柠

还记得那只让饲养员心心念念、总盼着她能早日长到2公斤的小考拉吗？在饲养员精心的照料与温柔守候下，如今，六宝青柠不仅稳稳达成了目标，体重还在持续增长，每月稳步增加约200g，真正成为一只“重量级”小可爱啦！

那么，这段日子青柠究竟发生了哪些有趣的新变化？她的性格是否越发鲜明？与青柑、柠檬两位姐姐的相处日常，又萌生了哪些有爱互动？今天，让我们一起走进青柠从“黏姐宝宝”蜕变为“独立少女”的暖暖成长日记~

**成长六宝：干饭小能手**

那只曾因人工育幼而备受关注的小不点儿，转眼已迈入一个更加独立、更有性格的成长阶段。她的日常也增加了许多的“小心思”和“小剧场”。

对六宝青柠来说，成长过程中最直观的变化，莫过于体重的稳步攀升。如今，她已能像哥哥姐姐们一样，自己抓着小树杈站上称重台，姿势标准，神情专注。偶尔她也会闹点小情绪，需要饲养员轻轻提醒，才肯主动爬上小树杈。不过嘛，小小的公主有点小小的脾气，不也是可爱的成长印记吗？

![](images/img_007.jpg)

六宝青柠第一次剪指甲

第一次剪指甲，六宝表现得格外配合，安静地坐在饲养员的手臂上，在指甲被一点点修剪时，还好奇地低头嗅了嗅剪下的碎屑，仿佛在研究这“新奇玩意儿”是从哪儿来的。

和体重密切相关的，当然是每天的“桉树叶大餐”。小时候的六宝，最爱香柳桉和斑桉，如今她依然对喜欢的叶子情有独钟，还开发了新宠——窿橼桉。起初，饲养员总会贴心地把叶子修剪得方便六宝采食。

![](images/img_008.jpg)

六宝：姐姐来抢饭了怎么办！

可青柑姐姐太聪明，总是一眼识破“妹妹的叶子好像更香”，频频上演“抢食行动”。后来饲养员调整策略：先喂青柑，再喂六宝，这才让吃饭时间恢复平静。

![](images/img_009.jpg)

随着对场馆内的栖架渐渐熟悉后，六宝开始主动“觅食”。她会在不同栖架间挪来挪去，专挑自己爱的那几片。无奈她从小吃饭就慢条斯理，常常把自己面前的吃完，转头就发现别处已被姐姐们“清空”。好在六宝虽有自己的偏好，却不怎么挑食，是个让人省心的“干饭小能手”。

![](images/img_010.png)

对自己的体重变化一无所知

除了吃，六宝还有自己的“心头好”——外展区那棵细细长长的小桑树。以前体重轻，爬上去轻松自在；如今长大了，一爬树干就弯，吓得她手忙脚乱，却还能像踩高跷一样，一边抓一根树枝稳住身子。为了她的安全，饲养员悄悄修剪了桑树，但六宝对它的喜爱，却像从前一样执着。

**好学六宝：姐姐们的小尾巴**

六宝的学习能力，简直是与生俱来。她特别喜欢跟在姐姐们身后，像个小尾巴一样默默观察、悄悄模仿。

姐姐的跟屁虫~

场馆里的部分栖架对青柠的小短腿来说还有点小困难，她就认真看姐姐从哪里下地比较轻松；外展时，姐姐们在门口等待饲养员接她们回到内室，六宝虽不明白，却也会乖乖跟在队尾；就连姐姐在地上跑动，她也好奇地跟下去，一副“我也要学”的认真模样。不管什么，反正跟着姐姐就对了~

![](images/img_011.jpg)

把头埋进姐姐温暖的怀抱中~

在两位姐姐中，六宝尤其喜欢和年龄相仿的青柑腻在一起。两小只常常分开吃树叶，吃完却不约而同凑到一块儿睡觉。六宝体型小，有时会把头埋在青柑胸口，仿佛睡在姐姐怀里，画面温馨得像幅小画。

![](images/img_012.gif)

考拉姐妹pk赛~

不过，姐妹之间也少不了一些“小摩擦”。抢座位时，青柑常使出“屁击”绝招，用屁股轻轻把六宝顶到一边。六宝青柠也不甘示弱，偶尔学以致用，以同样方式“反击”，打不过就会立马跑开~而大姐柠檬则通常是“和平观察员”，偶尔被卷入“战场”，也只是默默让开位置给两小只继续打。

总的来说，在“座位争夺战”中，还是青柑姐姐胜率更高。六宝这位“好学小妹”，看来还得继续积累“实战经验”呀！

**独立六宝：有熊初长成~**

刚开始和姐姐在一起时，六宝是两个姐姐的“小跟班”，看到哪位姐姐睡醒了在就会屁颠屁颠跟过去，试探性地扒拉姐姐，偶尔抢个座位刷存在感。

![](images/img_013.jpg)

青柠比较喜欢独处的位置

现在，六宝也开始有自己喜欢的位置，静静地享受独处时光。

![](images/img_014.jpg)

监工6

随着成长，六宝的性格也越发鲜明：好奇心强，探索欲旺盛。称完体重后，她常独自爬到室内高处，专注地看饲养员干活，活脱脱一位“小监工”，粉丝们都亲切地称她为“监工6”。

![](images/img_015.jpg)

干饭6~

面对游客，六宝也显得格外大方。刚开始，六宝也像姐姐们一样，在进食和睡觉时把自己藏进茂密地桉树丛中。随着对周围的环境越来越熟悉，现在的六宝常常冒出头来，坦然进食、安然入睡。

![](images/img_016.jpg)![](images/img_017.jpg)

青柠专属睡姿~

夏天时，她还自创了新睡姿，把自己卡进栖架的缝隙里，舒展身体，睡得香甜又安稳。

三姐妹难得在同一栖架上休息

偶尔，三姐妹也会难得在同一栖架上休息：青柑和柠檬在一起，六宝青柠在栖架的后面，构成一幅温馨又诙谐的“三熊图”。

![](images/img_018.jpg)

从需要特别呵护的“2公斤小目标”，到如今体重稳健、性格初显的“独立少女”，六宝的每一步成长，都离不开饲养员的温柔守护，也离不开青柑、柠檬两位姐姐的陪伴与“磨练”。她或许还在学习如何更快地吃饭、如何在“座位大战”中取胜，但她已经在用自己的方式，慢慢长大，悄悄发光。
