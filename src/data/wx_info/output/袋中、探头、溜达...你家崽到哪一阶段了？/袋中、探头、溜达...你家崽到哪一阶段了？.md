# 袋中、探头、溜达...你家崽到哪一阶段了？

![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.png)![](images/img_005.png)![](images/img_006.png)

咦！快看那边，

那只赤大袋鼠的肚子圆滚滚的，

是怀了小宝宝吗？

![](images/img_007.jpg)

快瞧快瞧，它的育儿袋里有什么在动？哇！一个小脑袋突然冒了出来，正在好奇地东张西望呢！

![](images/img_008.jpg)

哎？那边怎么还有一只小袋鼠，正努力往妈妈的怀里钻！

![](images/img_009.jpg)

哦！这边还有一只，已经蹦蹦跳跳地在妈妈身边自己玩啦！

![](images/img_010.jpg)

哈哈，你没看错！在红山南门新区袋鼠角，我们的赤大袋鼠家族可真谓“袋”丁兴旺！因为赤大袋鼠是全年均可繁殖的，所以在这里，你可以同时看到处在不同成长阶段的小袋鼠呢。

![](images/img_011.jpg)

走，咱们一起去发现

这个大家庭里蕴藏的生命奇迹吧！

**蹒跚学跳，偶尔“迷路”**

那只正在低头享用美食的袋鼠妈妈，育儿袋口忽然冒出了一个小脑袋，难道这小家伙也想尝尝鲜吗？

![](images/img_012.jpg)

这多半是妈妈小红育儿袋中的幼崽（暂时还没取名，文中以“小红崽”代替）。大多数的时候，这个小家伙安静地蜷缩在温暖湿润的育儿袋里。

![](images/img_013.jpg)

但偶尔，当妈妈静止进食或休息时，它会悄悄探出脑袋，初步感受外部环境，还有尝尝妈妈咀嚼时散落的食物碎屑。

![](images/img_014.png)

不过，他的“美食体验”远不止于此，有时它会舔食一点泥土，有时则会主动舔舐妈妈的嘴角，或者捡食地面上被妈妈逆呕出来的半消化物。

![](images/img_015.jpg)

其实是通过接触这些含有微生物的物质，幼崽正在为自己建立健康的胃肠菌群，为将来植物性饮食做好生理准备。

![](images/img_016.gif)

而这个阶段通常发生在幼崽约180日龄时，此时我们能看到的小袋鼠已经不仅会探头张望，身上也渐渐覆盖了一层细软的绒毛，正从全身赤裸的状态，步入长毛阶段，同时也有了探索欲望。

![](images/img_017.jpg)![](images/img_018.jpg)

从全身赤裸的淡红色步入长毛阶段

而比小红崽年长约一个半月的妈妈芋泥的幼崽（暂时还没取名，文中以“芋泥崽”代替），则已经开始了更勇敢的探索。妈妈芋泥是个谨慎的守护者。只有在确认周围环境绝对安全时，才会允许宝宝离开育儿袋进行短暂的地面活动。

![](images/img_019.jpg)

稍长大的他，开始出袋浅浅活动了

芋泥崽小心翼翼地踏上草地，摇摇晃晃地跳上几步，用鼻子嗅闻新鲜事物。但这样的“冒险”往往只持续几秒到几分钟，一旦感到不安或接收到妈妈微妙的信号，它就会迅速返回那个温暖安全的移动摇篮。

![](images/img_020.jpg)

随着信心逐渐增强，芋泥崽开始尝试与其他袋鼠进行简单的互动。不过，年幼的它仍然很容易自己吓自己。在慌忙逃回妈妈怀抱时，偶尔会发生“认错门”的小插曲。

**断奶倒计时，新生命已就位**

而袋鼠妈妈大灰的孩子小灰，则向我们展示了更进一步的成长阶段。此时的他，已经是个可以长时间离开育儿袋活动的“小探险家”了。从大灰分娩算起，大约250天过去了，小灰如今大部分时间都在袋外自由活动。

![](images/img_021.jpg)

和大家一起跳跃

不过，独立探索并不意味着完全断奶。当感到饥饿时，小灰依然会熟练地将脑袋探进妈妈的育儿袋中吮吸乳汁。

![](images/img_022.gif)

当然，外界环境如有突然出现令它不安的动静时，小灰仍然会毫不犹豫地跳回妈妈那个熟悉又安全的“移动避风港”。

妈妈，贴贴～

但随着对外界日渐熟悉，身体愈发强壮，他返回袋中的次数明显越来越少，面对挑战的勇气则与日俱增。

现在的他，甚至找到了自己特别钟爱的休息处，离妈妈大灰休息的地方有一段明显的距离呢。

![](images/img_023.jpg)

他的探索欲也格外旺盛。活动场中那些其他袋鼠鲜少踏足的角落，常常能见到小灰独自探索的身影。松软的沙地是他最喜欢的“游乐场”之一。

![](images/img_024.jpg)

而小灰要完全告别母乳，真正走向独立，还需要一些日子。从出生算起，这个过程往往要持续300多天。

就在它仍然会偶尔回头

寻找母亲乳汁的同时，

一场关于新生命的奇妙接力，

可能已经在妈妈大灰体内悄然开始了。

**育儿也能“错峰”！**

当老大（如小灰）彻底出袋却尚未断奶时，大灰可能已经迎来了新的分娩。因为一只成年雌性可同时抚育三个不同阶段的后代：一个在袋外活动但仍需哺乳的“老大”，一个在育儿袋中成长的“老二”，以及一个尚在子宫内处于滞育状态的“老三”胚胎。

![](images/img_025.jpg)

这种“三重奏”的实现，源于一系列精妙的生理适应。袋鼠妈妈的孕期极短，仅三十余天。新生幼崽体型微小，体重不足1克，眼睛和后肢均未发育。

然而，他那相对强壮的前肢已足以完成一项至关重要的使命：从产道口自主爬行，穿越母体腹部的皮毛，最终抵达并钻入育儿袋。

![](images/img_026.jpg)

进入袋中后，幼崽会凭本能找到一个乳头并牢牢吸附。与此同时，为了满足不同阶段幼崽的营养需求，袋鼠妈妈的四个乳头能够分泌出成分各异的乳汁。

![](images/img_027.jpg)

这一切，都是对澳洲严酷干旱环境的演化回应。在野外，它们的社群结构极为灵活，随着水源和食物的分布而聚散无常。干旱时可暂停生育，甚至放弃袋中幼崽以保全自身；一旦雨水降临，便迅速重启繁殖。正是这种与严酷环境的精妙互动，塑造了它们令人惊叹的生命节奏。

![](images/img_028.jpg)
