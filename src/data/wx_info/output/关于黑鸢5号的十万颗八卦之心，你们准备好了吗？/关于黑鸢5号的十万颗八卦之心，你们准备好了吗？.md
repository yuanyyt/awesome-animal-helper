# 关于黑鸢5号的十万颗八卦之心，你们准备好了吗？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)![Image](images/img_006.png)![Image](images/img_007.png)![Image](images/img_008.jpg)

黑鸢5号

上次我们说到，黑鸢5号猛飞9天、狂飙3000公里，顺利抵达俄罗斯度夏。刚落地还没来得及倒时差，它就紧锣密鼓地忙活起来了！至于在忙什么，我们先卖个关子~

与此同时，黑鸢“小书包分队”的南京成员们，也陆续忙忙碌碌了起来！今天，就让我们一起来盘一盘，“小书包”分队最近都在忙什么大事，又有了哪些新进展吧～

**01**

**“小书包”分队是个什么队？**

先为新来的朋友们补个课：**“小书包”分队**是什么？黑鸢5号为什么叫黑鸢5号？

自2021年起至今，我们累计接收救助了共29只黑鸢。其中：

![Image](images/img_009.jpg)

长期生活在救护中心的黑鸢

**6只**因身体原因无法放归，长期生活在救护中心；它们已经成功组成了两对黑鸢家庭；

![Image](images/img_010.jpg)

去年出生的黑鸢宝宝

去年有一组黑鸢家庭顺利抚育出了一只小黑鸢，帮助我们积累了关于黑鸢繁殖的基础数据；今年，它们又进入了孵卵阶段，有望成功“续杯”；

![Image](images/img_011.gif)

康复黑鸢放归

**16只**康复后已经成功放归；

![Image](images/img_012.jpg)

正在康复中的黑鸢

**3只**黑鸢正在康复中，等待放归~

而在放归的16只黑鸢中，有12只黑鸢是戴着“小书包”（卫星定位器）放归的，为我们记录它们每天的飞行路线。

![Image](images/img_013.jpg)

黑鸢5号放归

其中，大家最为熟知的可能就是黑鸢5号啦~因为它是第5只戴着“小书包”放归的黑鸢，故被称为“黑鸢5号”。12只成员里只有黑鸢5号是迁徙种群，其余黑鸢成员目前来看都生活在我们身边~

那我们为什么要为放归的黑鸢戴上“小书包”呢？

在南京，黑鸢是最贴近城市生活的猛禽之一。长江边、居民小区上空、红山南门新区、虎馆头顶……它们的身影离我们并不遥远。

![Image](images/img_014.jpg)

黑鸢 ©Dwyane

2022年初，我们开始关注这群与人类毗邻而居的黑鸢。我们想知道：为什么南京还能保有相对健康的黑鸢种群？它们喜欢什么样的环境？活动的热点区域在哪里？我们又该如何更好地保护它们？

为了回答这些问题，我们通过卫星追踪和实地观察，一步步靠近了黑鸢们的生活。

**02**

**“小书包”队员们****最近都怎么样啦~**

为新朋友们补完课，我们再来看看几位“小书包”队员的近况吧~

先说说我们第一只戴上“小书包”的黑鸢1号吧，它是我们最早一只戴上“小书包”的元老级成员，这已经是它成功放归的第4年啦~

但由于“小书包”设备的更新迭代，2G网络关闭，黑鸢1号的卫星数据已于去年秋天停止回传。虽然我们现在已经接收不到黑鸢1号的生活轨迹，但我们知道它其实一直生活得还不错呢~

![Image](images/img_015.jpg)

黑鸢宝宝 ©汪新月

根据我们的实地观察，黑鸢家庭们会反复利用自己搭好的巢繁殖。比如去年它们在这里搭好了巢，成功繁殖；今年它们还会继续使用同一个巢里繁殖育雏。

去年春天，我们观察到了黑鸢1号成为了一位勤勤恳恳育雏中的爸爸。今年，我们又在同一巢中看到了已经成功破壳的黑鸢宝宝，这就说明黑鸢1号今年大概率还是在稳定育雏中~（温馨提示：如果大家偶遇到黑鸢正在育雏的巢，远观即可，不要靠近打扰它们育雏哦~也不要把巢穴的位置分享出去哦~）

再说说我们备受关注的黑鸢5号吧~大家一直比较关心的黑鸢5号的“个鸢问题”，今年终于有了答案~

![Image](images/img_016.jpg)

黑鸢5号 ©原野

是的，黑鸢5号做爸爸啦！

这是两个好消息，首先是我们期待已久的5号性别之谜终于揭开；其次是黑鸢5号已参与繁殖，正在勤恳“养家”中~屏幕前的十万颗八卦之心可以欢呼起来啦~

不过，5号作为我们每到春秋两季就惦念的老朋友，无论它是每天溜溜达达的独行侠，还是勤恳带娃的黑鸢爸爸，它都是我们心里最最牵挂的小鸟朋友~（得知朋友的八卦也是拉近感情的方式嘛~）

![Image](images/img_017.jpg)

黑鸢5号 ©原野

期待今年秋天与5号再次相见啦~

说完了远在俄罗斯的5号，再让我们把目光拉回南京吧~

今年南京的黑鸢们，似乎比往年更着急一些，进入繁殖季节的时间普遍提前了。其中最稳的，当属黑鸢6号。去年，6号成功抚育长大了两只小黑鸢，妥妥的“模范父母”（[被骑在头上猛打也得回家喂娃~](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650878675&idx=1&sn=aeb828c5767f2a5d80586f8ed84fdce0&scene=21#wechat_redirect)）。

![Image](images/img_018.jpg)

正在孵卵的黑鸢6号 ©陈冬銮

不过黑鸢6号去年搭的巢，在8月份塌掉了，今年它们又重整旗鼓，在同一棵树上重新筑了新巢，目前已经进入了孵卵阶段，真不愧是我们的“模范父母”组合呀！

再来看看其他几位“小书包”队员的情况：黑鸢7、8、9号成员是去年刚刚放归的新成员，从它们日常的行动轨迹来看，目前也都已经陆续进入了繁殖状态，祝它们今年也顺顺利利！

黑鸢10号对大家来说又是一个比较特别的存在啦~为什么说它特别呢？因为它是“小书包分队”里最常刷新在大家的镜头里的一只！

![Image](images/img_019.jpg)

正在捕鱼的黑鸢10号 ©一只呆河马

起初，我们的小红书网友@一只呆河马 在今年的1月23日于三汊河拍到了一只戴着小书包的黑鸢，经路线复核，是黑鸢10号；

![Image](images/img_020.jpg)

偶遇黑鸢10号 ©张希希

3月11日，我们的认养人@张希希 在三汊河拍到了一只戴着小书包的黑鸢，经路线复核，是黑鸢10号；

![Image](images/img_021.jpg)

在幕府山拍到的黑鸢10号 ©瑞雪

3月29日，我们的观鸟爱好者@瑞雪 在幕府山拍到了一只戴着小书包的黑鸢，经复核，是黑鸢10号；

根据卫星追踪数据，黑鸢10号的活动范围非常有代表性。我们之前提到过，三汊河似乎是城里的一波黑鸢“排队回巢”的地方。一到傍晚，三汊河上空就会一只接一只聚集起数只黑鸢。等凑够了一波黑鸢后，它们就会一起飞向老山过夜。10号代表的，可能就是我们经常能在三汊河口看见的黑鸢。

![Image](images/img_022.jpg)

加入了大部队的黑鸢10号 ©一只呆河马

黑鸢11、12号是今年刚刚放归了一个月的新成员，关于它们的故事还需要我们慢慢解锁~

注：黑鸢2、3、4号，分别在放归后的778天、46天、592天已故。

**03**

**4年后，**

**最初的问题有答案了吗？**

距离我们2022年初开始关注黑鸢，已经过去了4年。最初我们提出的3个问题，也有了一些初步的答案：

![Image](images/img_023.jpg)

我们救助放归的黑鸢，在野外活得怎么样？

![Image](images/img_024.png)

通过放归后的黑鸢能够存活的天数和存活率来看，我们的救助工作做的还是及格的，平均能在野外顺利生存两年左右。

南京为什么这么多黑鸢？

![Image](images/img_025.png)![Image](images/img_026.jpg)

根据我们这几年的观察，我们提出猜想：冬天的时候，在南京生活的黑鸢量是明显增加的，包括之前从青岛放归的一只戴着“小书包”的黑鸢，也来到了南京越冬。这说明南京是一个非常集中的黑鸢越冬地。

![Image](images/img_027.jpg)

黑鸢打架 ©王胤博

种群数量变多就会对黑鸢的整个种群带来一点点扰动。资源有限，竞争加剧，不够强壮的个体可能就会被自然筛掉，留下来的都是“精英鸢”。正因为有这样的机制，南京的黑鸢种群才能一直保持健康、保持竞争力。同时，这也从侧面说明南京的环境承载力足够好。我们有硕大的老山，有江边带树林的湿地，还有长满高大树木的江心岛屿，这些都为黑鸢提供了足够的资源和环境。

![Image](images/img_028.jpg)

黑鸢在南京的生活情况是什么样的？

![Image](images/img_029.png)

这个可说的就太多啦~

比如我们发现南京的黑鸢并不全是“本地鸢”。还有像黑鸢5号那样的迁徙族群（[飞了6个月，黑鸢5号回南京了！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650764404&idx=1&sn=a08fe44a21a5b9ba998b08f89f95df76&scene=21#wechat_redirect)）。

![Image](images/img_030.jpg)

黑鸢集群

比如老山似乎是大家的“集体宿舍”。但它们又各自有喜好的活动区域。有的喜欢往东飞，有的偏爱往西去。到了傍晚，又从四面八方飞回来，聚在老山过夜。我们理所当然的认为，对于黑鸢来说，似乎它们都愿意选择有山的地方（[以防有人没看过黑鸢“牵手”！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650862185&idx=1&sn=43ef9a6162f469f16ec01650ab07703d&scene=21#wechat_redirect)）。

但随着日积月累的观察，我们又发现了一些不同的地方。例如黑鸢也会选择在潜洲夜栖，那里没有山，但有高高的树，人为打扰也相对少一些。像这样的地方对于黑鸢来说也同样重要。

![Image](images/img_031.jpg)

黑鸢宝宝的“练飞幼儿园” ©凤子

再比如黑鸢之间也有自己的社区关系，也有属于自己的“爱恨情仇”；它们带娃期间也同样沧桑疲惫；黑鸢宝宝可能在亚成体的期间就会寻找自己的伴侣......更多关于黑鸢的精彩内容，往下拉查看【黑鸢的南京故事】合集哦~

当然这些行为还需要更多持续的观察和验证。但可以确定的是，黑鸢之间的社交行为和模式远比我们想象的复杂和丰富。越来越多的行为观察，让我们对南京这座城市的荒野潜力有了更多信心。

关于黑鸢我们还有很多很多想要了解的故事，未来的路，我们还想走得更久、更远。
