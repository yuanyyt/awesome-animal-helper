# 路边的小鸟要不要捡？有时候还真得捡！

![Image](images/img_001.gif)![Image](images/img_002.gif)![Image](images/img_003.gif)![Image](images/img_004.gif)![Image](images/img_005.png)![Image](images/img_006.jpg)

春风轻拂柳梢，春雨润泽泥土，城市的枝头瞬间热闹了起来~麻雀叽叽喳喳，乌鸫跳跃觅食，灰喜鹊成群结队……这些我们早已习以为常的城市“邻居”，正纷纷进入一年中最忙碌、也最充满生机的繁殖季。

伴随着一大波的新生命即将诞生，我们又要开始讨论这个问题啦：当我们在路边遇到一只落单的雏鸟，究竟该不该捡？

![Image](images/img_007.gif)

**遇到雏鸟要不要捡？**

![Image](images/img_008.gif)

“路边的小鸟不要捡”——这句话你一定听过。

而它之所以被广泛传播，是因为大多数人对鸟类的习性和成长阶段不太了解。如果看到一只小鸟就捡回家，反而可能把它从父母身边“拐走”，让它失去最好的生存机会。

![Image](images/img_009.jpg)

那什么时候该捡？什么时候不该？

我们从最理想的情况说起：如果你看到一只雏鸟，羽毛还没长全，尾巴短得像个小绒球，那它很可能还没到“出飞”的年龄。这时候它从巢里掉出来，最好的方式是把它放回巢里，而不是带回家。

但现实是，很多时候你找不到巢，又找不到亲鸟，或者巢太高、够不着，雏鸟又在地上待了很久了，身体发凉、精神萎靡，这时候怎么办？

![Image](images/img_010.jpg)

那就别犹豫了，该出手时就出手吧~我们不要盲目捡，也不要盲目不捡。先观察，再判断，最后行动。

![Image](images/img_011.gif)

**如何判断雏鸟需不需要帮助？**

![Image](images/img_012.gif)

判断一只小鸟是否需要帮助，关键看三点：年龄、状态、环境。这直接决定了它是应该被送回巢中，还是被留在原地观察，亦或是必须立即救助。

首先，要**判断雏鸟的发育阶段**是最重要的一步。

**1**

![Image](images/img_013.gif)

**未达出飞期的“真·雏鸟”**

鸟类在巢中来到出飞年龄才会从窝里逐渐来到巢的沿口或者巢附近的树枝上，没有达到这个成长阶段的幼鸟大多都是卧在窝中，这时候它们的腿脚还非常不利索，即便在乞食的时候可以高高的探起身子也可能只是半蹲或者短暂站起来一下。

![Image](images/img_014.jpg)

这个阶段的鸟儿如果出现在地面，绝大多数是从巢中直接掉落的“意外事故”。

根据我们的观察和经验，这样的鸟如果送回就要直接送回巢中，因为在这个阶段，它们并不具备在树枝上站稳的能力。

![Image](images/img_015.jpg)

但还有一种情况是，从巢中掉落的鸟有很大概率是不健康或者被同伴竞争淘汰或者资源不够被亲鸟淘汰等等原因，相当于送回去也不会有好结果甚至有可能更添乱，所以救助也是一个选择。当然，也要排除刮风下雨等极端天气导致的意外落巢。

**2**

![Image](images/img_016.gif)

**正在学飞的“准成鸟”**

这是最容易被人误解并“误救”的阶段。这个阶段的幼鸟已经开始生长尾羽，并且尝试着在巢附近的树枝尝试移动甚至短距离扑腾，这也是幼鸟成长的必经之路~

![Image](images/img_017.jpg)

这个阶段的幼鸟由于飞行技巧生疏，稍有不慎就会掉下来。如果赶上天气不佳，掉的就更多了。所以这种出飞大小的鸟是最容易被捡到的。

这个时候，只要幼鸟没有明显外伤，就不需要带走救助。我们可以找一个长树枝，化身“人形云梯”，让小鸟站在树枝顶端，然后缓慢平稳的把它送到高处树枝附近。

![Image](images/img_018.jpg)

当小鸟被我们操控的树枝举高，这时候既不会有大鸟来把它带走，小鸟自己也大概率不会轻举妄动，这个时候只需要精确控制树枝让小鸟的胸腹部慢慢顶住高处的树枝，然后再进一步缓慢移动人工树枝，压缩鸟与野生树枝之间的空间，这时候小鸟就会抬脚迈上野生树枝，人工树枝就完成了它的使命。这个时候人也可以所躲在一旁观察亲鸟有没有来照顾幼鸟了。

**3**

![Image](images/img_019.gif)

**还需判断幼鸟的身体状况**

除了年龄，身体健康状况也是判断是否应该救助的重要因素。比如一些落巢雏鸟被发现的时候，落巢时间已经比较长了，这时候可能已经出现了脱水或者失温的情况，送回高处可能也很难恢复，这时候需要人为救助才有更多的可能性活下来和最终回到野外。

![Image](images/img_020.jpg)

住院柜中的斑鸠

判断方法是你可以轻轻握住鸟，至少不能觉得凉，如果明显感觉到凉，那一定需要先保暖。另外可以观察口腔，大部分幼鸟口腔内红色，如果出现淡粉或者惨白，那一定需要救助，同时也要观察水合状态，正常应该水润光泽，不正常的是口腔粘液粘连或者眼神暗淡不水灵。

还有要关注的是龙骨突的状况，龙骨突如果不丰满，骨头突出甚至刀片状，则表明营养状况差，需要救助。

![Image](images/img_021.jpg)

乌鸫

体外寄生虫也值得关注，我们救助中发现乌鸫、灰喜鹊、椋鸟等鸟类容易出现螨虫类寄生虫，数量非常大，有寄生虫的幼鸟几乎全部为不健康个体。

除了以上说到的问题，外伤也是在落巢幼鸟中非常常见的问题，是否有骨折，外伤需要关注，体表淤血也应该关注，包括身体姿态是否正常，是否有跛行或者任何非正常姿态都应该关注，是否有神经症状也要留意。至于内科问题很难通过观察了解，但也至少可以看看呼吸状况是否平稳正常。

![Image](images/img_022.jpg)

当然，落巢幼鸟在被人类围观状态下因为应激表现呼吸急促也是正常情况。所有行为的观察都应该在鸟类近自然状态下完成才能更好地评估真实情况。

![Image](images/img_023.gif)

**当雏鸟来到救护中心，**

**还有机会回到野外吗？**

![Image](images/img_024.gif)

基于我们多年的救助经验与科学跟踪数据来看，对于很多物种而言，只要方法得当，它们完全有机会重新成为自然界中独立的一员。而对于鸟类而言，走向独立的阶段通常发生在它们学会自主进食之后。

首先，在幼鸟在学会自己吃饭之后，只要把很多只鸟放在一起，同时更换大一些的笼舍，这样就可以拉开人和鸟的距离，减少直接接触。

![Image](images/img_025.jpg)

红隼学校

一旦度过了这个关键期，它们对人类的好奇心和依赖感会迅速消退，取而代之的是对陌生人的警惕和对自然的向往。

这个我们在所有救助的幼鸟身上，甚至其它哺乳动物身上都亲测有效。就像人类的青春期一样，野生动物在成长过程中也会有这样去成为一个更独立自主的完整自我的过程。（[人工育幼长大的獐子还能回到野外吗？](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650865615&idx=1&sn=55a4352eecadba128f70dd7ca119fb06&scene=21#wechat_redirect)）

![Image](images/img_026.jpg)

戴着“小书包”的鸬鹚

关于生存能力，我们也开展过一些放归之后的跟踪研究。我们曾对完全在人工笼舍内出生、由亲鸟抚养长大的白颈鸦和普通鸬鹚进行了长达两年以上的野外跟踪监测。

![Image](images/img_027.png)

放归野外的白颈鸦

尤其是白颈鸦，亲鸟救助于非法养鸟，其成长过程是被从野外掏窝由人养大，也因此形成了严重的行为偏差，导致无法直接放归野外。我们曾尝试过将它们放归，但失败了最终又救助回来（[为了重回野外，它们只能生了个孩子](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650748295&idx=1&sn=4a9a85e5f7160696f49a66158d27e283&scene=21#wechat_redirect)）。

即便是这样情况的一对亲鸟，它们在笼舍内繁殖养育的幼鸟，在回到野外之后竟然能行为正常且有生存能力，生命的伟大真的让我们赞叹。

![Image](images/img_028.gif)

**善意需要温度，也需要边界**

![Image](images/img_029.gif)

近年来，我们真切地感受到了公众意识和救助水准的显著提升。

印象最深的是前年发生的故事：一位市民送来一只猛禽雏鸟。这位市民在交接时条理清晰地告诉我们：这是他在树下观察了整整两个小时，确认周围没有亲鸟盘旋，也没有听到亲鸟的叫声，判断它可能真的被遗弃或受伤，才带过来求助的。

这份冷静与专业让我们倍感钦佩和欣慰，随即接收了这只猛禽雏鸟。然而在当天下午，这位市民又匆匆赶回救助中心，说在附近的树上发现了鸟巢和亲鸟！既然找到了家，能不能把它送回去？

最终我们当然是把鸟送了回去，毕竟我们再努力，也不如亲鸟养得好。

![Image](images/img_030.jpg)

野生动物救助的案例千差万别，从小小的绣眼鸟到大型的猛禽，从中毒、外伤到营养不良，每一种情况都需要不同的应对策略。

![Image](images/img_031.jpg)

所以，想由个人完成高质量救助的门槛极高。既需要掌握物种识别、急救处理、营养配比、行为训练等专业知识，又需要隔离病房、恒温箱、专用笼舍、化验设备等高昂的投入。更何况还有许多雏鸟需要每隔一小时喂食一次，且需持续数周甚至数月。

![Image](images/img_032.jpg)

对于个人而言，试图凭一己之力完成全程救助，往往消耗巨大且效果难料，甚至可能因操作不当导致二次伤害。因此，在遇到受伤或陷入困境的野生动物时，最合理的选择往往是：做好保温、避光、减少惊扰，然后尽快将其安全转交给专业的野生动物救护中心。

当我们学会在恰当的时机伸出援手，也在恰当的时机选择放手，生命才能真正回归它本该属于的地方。
