# 在红山，最懂拥抱的居然是他们！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)

**嗨****·****抱一抱**

![Image](images/img_006.png)![Image](images/img_007.png)![Image](images/img_008.jpg)

当寒风裹着凉意掠过红山的枝桠，

总有一些温柔瞬间，

在不经意间戳中你我的心。

![Image](images/img_009.jpg)

大春家

在红山，居住在唐家河与亚洲灵长区的三组川金丝猴家族“大春一家”“六娃一家”和“重阳一家”，用他们延续了千万年的生存与情感密码，演绎着关于“温暖”的种种故事。这一次，我们想从他们之间的**拥抱**说起——

![Image](images/img_010.jpg)

六娃家

若说冬日里最具氛围感的拥抱，莫过于他们为应对季节而来的“团抱”。川金丝猴的故乡本就位于高海拔山林，应对低温，是他们与生俱来的智慧。入冬之后，彼此依偎的频率便会悄然升高。

![Image](images/img_011.jpg)

重阳家

在红山，饲养员早已为他们备好避风的室内空间、充足的营养食物等保暖措施，但他们依旧会在觅食完后，三三两两依偎或一家聚在栖架、巢箱里、平台或是树干上，紧紧贴在一起，从一小团渐渐汇成一个个圆融的“金球”。

![Image](images/img_012.jpg)![Image](images/img_013.jpg)

在雨雪天气里，

他们用这样的团抱方式保存体温。

这是一种刻在基因里的默契，是演化千年的生存智慧，更是一种无声却深情的社交语言。

![Image](images/img_014.png)![Image](images/img_015.png)

毕竟拥抱，从来不止是暖身。

还有别的含义呢？

*Hug*

拥抱 / **是他们**

**最丰富的**语言

**“吵完架，抱一个就好了”**

再和睦的家族也难免有磕绊。或许是为了一口鲜嫩的食物，或许是淘气的幼猴闯了祸，又或许是谁不小心占了谁心爱的树叉…雌猴之间有时也会发生争执。

![Image](images/img_016.jpg)

打打闹闹，感情牢靠！

即便气氛一度紧张，他们也极少真正动手。往往在情绪稍缓的片刻，总会有一方主动迈出和解的第一步，缓缓靠近，然后紧紧抱住对方。

![Image](images/img_017.jpg)

拥抱是族群里的“情感创可贴”

（下次给大家展示）

被拥抱的一方，也总会“借坡下驴”，回应对方，彼此交颈相拥。顷刻间，所有的不快便烟消云散，自家猴哪有隔夜仇！

**“好兄弟，我们抱一抱”**

而幼猴们的拥抱，

藏着最纯粹的欢喜与默契。

他们整日在枝间追逐嬉戏，拥抱却从未缺席：久别重逢时，扑进彼此怀里撒欢；闹了不愉快后，主动凑上前轻抱致歉；

![Image](images/img_018.jpg)

忘突友谊

找到新奇玩意儿、心情大好时，也会相拥着分享喜悦；若是同伴受了惊吓、情绪低落，便静静陪着，用小小的身子紧紧贴着对方。

![Image](images/img_019.jpg)

尖叫的芒果核

在一次次肢体互动里，建立友谊、懂得包容，慢慢学会如何在家族中相处，为未来融入群体打下基础。

**“妈妈，快给我的专属抱抱！”**

母爱拥抱，

是川金丝猴家族最动人的风景。

无论是在栖架上行走、枝干间攀爬，还是蹲坐在岩石上休憩，幼猴总被妈妈护在温暖的怀抱里，小小的身子紧紧贴着母亲，安全感拉满。

![Image](images/img_020.jpg)

和同伴玩累的小猴，也会各自去找妈妈，回到妈妈的怀抱里充电。妈妈们则会轻轻梳理幼猴的毛发，把最柔软的呵护都藏在拥抱里，饿了便俯身哺乳。

![Image](images/img_021.jpg)

这份时刻相伴的拥抱，是母爱最直接的表达，也是幼猴健康成长的底气。

**“阿姨们的爱，也是集体温暖”**

在川金丝猴家族里，除了母爱，

“阿姨抱”也是最特别的社会性温暖。

新生幼猴总会引来家族其他雌猴的格外关注，他们会主动凑上前抱抱幼崽、轻轻抚摸，甚至出现抢婴、护婴的小剧场。

![Image](images/img_022.jpg)

这份特别的热情，既能让母猴有更多时间觅食补充营养、保证乳汁供应，也能让幼猴在群体的呵护下更好地适应家族生活。

![Image](images/img_023.jpg)

而未成年雌猴和雄猴也会主动参与育婴，在抱持、照料幼崽的过程中，慢慢学会照顾后代的技能，为自己未来成为母亲或父亲做好准备，让这份温柔的爱在家族中代代相传。

**“爸爸的抱抱，超温暖！”**

雄猴的拥抱，

是家族稳固的温柔基石。

在川金丝猴家族中，雄猴的拥抱行为在家庭成员间尤为频繁。作为大家长，他们从不是威严的旁观者，而是会用拥抱强化与幼崽的亲子联结。

![Image](images/img_024.jpg)

六娃与他的家庭成员们

幼崽们常常主动凑到父亲身边撒娇，用小身子蹭着父亲的毛发，而雄猴也会轻轻环住幼崽，用温热的身躯给予回应，或是“爸爸巴士”即刻发车。

![Image](images/img_025.jpg)

大春与他的家庭成员们

而他的配偶雌猴们也时常主动与他进行肢体接触，或是依偎相伴，或是轻抱示好。

在一次次与家族成员的温情触碰中，巩固着整个家庭单元的凝聚力，让每一个家族成员都能在这份包容的温暖中，找到属于自己的归属感。

![Image](images/img_026.jpg)

重阳与他的家庭成员们

这些多样的拥抱，

拼凑出川金丝猴丰富的

情感世界与复杂的社会性。

他们用最直接的肢体语言，诠释着和解、陪伴、守护与互助的意义，也让我们看见，温暖从不是我们的专属，而是所有生命共通的本能。

![Image](images/img_027.jpg)

今天，恰是腊八。

俗语说“过了腊八就是年”，

这个传统节日，

本就寓意着团聚与温暖。

当你读完这篇文字，如果心里也泛起一阵暖意，不如，放下手机，给你身旁的家人、爱人、朋友，一个轻轻的拥抱吧。

![Image](images/img_028.jpg)

像川金丝猴那样，无需多言，让温度在怀抱间传递。让这个腊八，因一个拥抱而更加幸福、圆满。

天气虽冷，

红山总有温暖故事在发生
