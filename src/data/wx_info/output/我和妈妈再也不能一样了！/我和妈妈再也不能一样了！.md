# 我和妈妈再也不能一样了！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.jpg)

黑、黑、黄，还有一只“黑黄混搭”！

不少游客看到这一幕，

都会忍不住发出疑问：

“这真的是一家猿吗？？”

![Image](images/img_004.jpg)

不可以质疑的！

这就是**白颊长臂猿**三叮、怜怜和他们两个孩子组成的一家猿！而那只毛色特殊的幼崽朝朝，是正处于白颊长臂猿成长过程中必经的毛色转换阶段。

随着生长发育的推进，他将完成这场神奇的毛色蜕变，最终拥有与其性别相匹配的标志性毛色。

![Image](images/img_005.jpg)

那么这一独特的毛色变化过程

究竟是怎样的呢？

![Image](images/img_006.png)

**变，猜猜我何时变黑！**

刚出生时，白颊长臂猿朝朝（[有爱度biu升~](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650844320&idx=1&sn=5066b7ce54f799b7dc5dd3ece6710141&scene=21#wechat_redirect)）全身披着乳白或乳黄色的毛发，和妈妈三叮的毛色十分相似。在三叮的怀里，朝朝的毛发与她的毛发相互映衬，仿佛形成了绝佳的保护色。

![Image](images/img_007.jpg)

当朝朝成长到约九个月大时，毛色迎来了第一次转变。此时，其实无论雄性还是雌性白颊长臂猿，毛发都会启动“变色程序”，会从乳黄过渡到浅棕，再到深褐，最终呈现出近乎纯黑的浓密毛发。朝朝目前正处于这个变黑进程中，身上斑驳交错的黑黄色毛发，正是蜕变进行时的独特印记。

![Image](images/img_008.jpg)

就在毛色变深的同时，幼崽的脸颊两侧开始长出细细的白色绒毛，这些绒毛会逐渐变得浓密，形成白颊长臂猿标志性的“白脸颊”。这个阶段的幼猿，无论雄性还是雌性，外形上都和成年雄性高度相似，黑色毛发搭配标志性的白脸颊。

![Image](images/img_009.jpg)

朝朝的哥哥豆包就是如此，三岁的他和爸爸怜怜依偎在一起，就像一个缩小版的“复制粘贴”。

![Image](images/img_010.jpg)

那何时能像现在

区分妈妈三叮和爸爸怜怜般，

从毛色区分雌雄呢？

**这还需要一个过程！**

这种“雌雄难辨”的外观状态，在动物园中会持续到6岁左右，而在野外自然环境中则会延长至7-8岁，这个阶段恰好是白颊长臂猿接近性成熟的关键时期。

此时，真正的性别分化会通过毛色的差异鲜明呈现。雌性个体的毛色会在这个过程中启动一场“反向蜕变”，原本浓密的黑色毛发会逐渐变浅，从深褐过渡到浅棕，最终变为温暖明亮的金黄色，同时头顶会保留一块清晰规整的梯形暗褐色冠斑。

![Image](images/img_011.jpg)

而雄性个体则会终身保持深色毛发。

![Image](images/img_012.jpg)

儿时的变黑，竟不可逆！

![Image](images/img_013.png)

**和哥哥的打闹提上日程**

随着月龄增长，朝朝的变化不仅体现在毛色上，活跃度也大幅提升，不再满足于安静依偎在母亲三叮怀里，时常在怀中扭动身体，跃跃欲试地想要探索周围环境。

![Image](images/img_014.jpg)

豆包对刚出生的朝朝产生好奇

哥哥豆包则始终保持着好奇闹腾的天性，从朝朝出生起，总爱趁三叮不注意时，悄悄凑到弟弟身边，用纤细的手指轻轻勾一下朝朝的毛发，或是凑上前去嗅探、触碰，逗弄这个小小的家庭成员。

在哥哥的带动下，朝朝也会边依偎在妈妈怀里喝奶，边伸出小手去够豆包，主动回应哥哥的互动，试图和他一起玩闹。

![Image](images/img_015.jpg)

眼神自动跟随哥哥豆包

从小就被哥哥吸引的朝朝

不过，豆包有时会因为玩闹过于投入而没轻没重，三叮会立刻带着朝朝转移到栖架的另一端。即便被妈妈强行分开，两个小家伙之间也透着依依不舍，朝朝会在妈妈怀里伸着小手，朝着豆包的方向不断张望，期待下一次玩耍的机会。

![Image](images/img_016.jpg)

随着朝朝逐渐长大，三叮也开始放宽限制，允许豆包更长时间地带着弟弟活动。每当三叮躺下休憩时，精力充沛的朝朝总会在喝完奶后，独自爬到栖架或绳索上练习攀爬、臂荡。

而豆包总会及时赶到弟弟身边，陪着他一起玩耍，无形中分担了三叮的照看压力，让三叮能安心休息片刻。

![Image](images/img_017.jpg)

在与哥哥的频繁互动中，朝朝的攀爬、臂荡等生存技能得到了充分锻炼，动作变得越发灵活协调。如今，和哥哥豆包在栖架间追逐打闹，早已成为朝朝每日的家常便饭。

![Image](images/img_018.jpg)![Image](images/img_019.jpg)![Image](images/img_020.jpg)![Image](images/img_021.jpg)

两小皮猿“战斗力”十足

![Image](images/img_022.png)

**胆****肥了，敢抢吃的了！**

栖架旁突然传来一阵轻微的骚动，

三叮龇着牙，发出警告！

是谁惹她发火了？

![Image](images/img_023.jpg)

就是他！

让我们猜猜：家庭地位最低的爸爸怜怜？向来让妻，首先排除；怀里紧紧护着的小儿子朝朝？更是被小心呵护，绝无可能。

答案显而易见，

肯定是“挑事大王”豆包！

准是这只三岁的小猿

又来抢妈妈的食物了！

![Image](images/img_024.jpg)

豆包

随着豆包逐渐长大，曾经对他谦让的三叮变了。面对大儿子豆包的抢夺，三叮不再像从前那样纵容，而是会立刻龇牙警告，毫不留情地将他赶走。

![Image](images/img_025.jpg)

提防着豆包的三叮

在食物面前，这位妈妈展现出了绝对的“原则性”：不管是谁的孩子，好吃的都不能让！

![Image](images/img_026.jpg)

不过，三叮这份护食又爱吃的天性，反倒给朝朝带来了意外的好处。进食时，三叮专注享受美食的模样，总能勾起小朝朝的食欲。因此，朝朝开始尝试辅食的时间，比同龄的长臂猿幼崽要早得多。

![Image](images/img_027.jpg)

还处于保护期的朝朝试图尝尝

他常常在妈妈怀里“捡漏”，分享一点掉落的食物碎屑；有时还会低着头，认真舔舐妈妈手掌上残留的食物痕迹，不放过任何一点美味。

![Image](images/img_028.jpg)![Image](images/img_029.jpg)

尝到了

进食时的“六亲不认”只是暂时的，一旦吃饱喝足，这个小家庭便会迅速恢复往日的温馨和谐。午后的阳光透过树叶洒进展区，一家四口会依偎在一起，互相梳理毛发，或是安静地拥抱休憩。

![Image](images/img_030.jpg)

到了夜晚，他们更是分工有序：自从朝朝出生后，爸爸怜怜就一直带着豆包在单独的巢箱里休息，尽可能为三叮腾出更多时间，让她能专心照顾年幼的朝朝。这看似简单的日常互动中，满是他们一家的温情与默契。
