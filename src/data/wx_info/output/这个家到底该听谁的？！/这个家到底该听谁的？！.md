# 这个家到底该听谁的？！

![Image](images/img_001.png)

**报！好消息！**

在红山本土物种保育区，亚洲小爪水獭版纳和茶茶这对亲密伴侣，又一次迎来了家庭的新成员。

![Image](images/img_002.jpg)

第二次当爸妈的他们，

虽褪去了初次育幼的手忙脚乱，

却在“育儿理念”上频频出现小分歧！

![Image](images/img_003.jpg)

冬去春来，版纳和茶茶依旧形影不离，版纳的肚子也慢慢鼓了起来。饲养员早已紧锣密鼓地为他们布置好生产和育儿空间：在室内和室外都准备了两个巢箱，且在这两个区域都铺设了充足垫料，让他们可以自由选择想待在哪儿，也方便饲养员在他们使用一个巢箱时，及时清理另一个，始终保持巢箱干爽洁净。

![Image](images/img_004.png)

天气好的时候，阳光照下来，两个巢箱顶上正好一獭趴一个。不过大多数时候，他们还是更喜欢挤在一起，挨着晒太阳。

![Image](images/img_005.png)![Image](images/img_006.png)

**新生命降临  “选家”分歧初现**

整个孕期，版纳依旧灵动敏捷，身手与平时别无二致，而茶茶也一如既往，捕到食物就往版纳身边送。向来喜食的版纳对食物来者不拒，直到1月30日临近生产这天，她对食物突然没了兴致，凑上去闻了闻就走开了。

她像是在琢磨什么，在室内和外场之间来来回回地走，随后开始把室内的干草衔到外场的巢箱里，一趟一趟地絮窝。看来这一次生产，她选了室外。

![Image](images/img_007.jpg)

妈妈版纳

当日中午，小水獭们顺利降生，浑身覆盖着淡色毛发，眼睛紧闭。

作为经验丰富的爸妈，版纳和茶茶有着明确的育幼分工：妈妈版纳专注抚育孩子，日常会就地取材，衔来饲养员散放在场地内的干草，或是撕下场内干枯芭蕉根部的外皮，衔进巢箱重新整理铺垫，时刻保持巢箱干燥；

![Image](images/img_008.gif)

爸爸茶茶则重点负责巡视领地、提供食物、守卫家庭以及转移幼崽（划重点），闲时便在场地外围不停巡视，并用气味标记自己的领地。

![Image](images/img_009.jpg)

就连生产当天，刚生产完的版纳也没有丝毫停歇，一趟又一趟往返于巢箱内外，用嘴衔着干草，仔细地在巢箱里絮了一层又一层；另一边，茶茶则在两个巢箱中后方的树枝窝里独自絮窝，夫妻俩絮窝的地方截然不同。

![Image](images/img_010.jpg)

茶茶：树枝窝可不是白搭的，

根据天气选择咱家住哪房

也正因如此，每当天气在变化，两獭来回运崽的画面时常出现，有时能看到茶茶把小崽运到自己筑的树枝窝里；版纳发现后，又会把小崽，叼回自己的巢箱，一场围绕“选家”的育儿分歧，就此拉开序幕。

![Image](images/img_011.jpg)

搬家！

为平衡他们的自然行为与保护幼崽的安全，饲养员将溪流的水位调低了一些。同时，在版纳带崽的这段日子，饲养员还把食物集中放在一个位置，一来方便版纳取食，二来也便于观察他们的进食情况。

![Image](images/img_012.jpg)

每当版纳要去觅食时，看护幼崽的工作就交到了茶茶手上；有时茶茶也想觅食，便会叼着小崽转移到版纳身边，绝不让幼崽脱离视线。而在版纳哺育小崽时，茶茶总会守在妻儿旁边，时刻保持戒备、守护左右。

![Image](images/img_013.png)

找妈妈～

![Image](images/img_014.png)

**新房又双叒叕被否了！**

就这样在3月10日，一次茶茶和版纳日常转运幼崽的过程中，小崽们陆续睁眼了。

![Image](images/img_015.jpg)

一双懵懂的小眼睛，

打量着这个搬来搬去的家。

可你以为就在巢箱与树枝窝中间的“拉扯”吗？“自由探索派”的茶茶又发现了“新房”！

![Image](images/img_016.jpg)

茶茶已不满足他的树枝窝，巡视领地时，在溪流区的下游找到了一处蔷薇下的石洞穴区域，自此对他情有独钟，时不时朝里面衔草絮窝。

![Image](images/img_017.jpg)

当他在里面絮好窝后，即便版纳反复“否决”，茶茶也总趁着版纳休息或不注意的时候，叼起小崽就往自己心仪的“自建房”里运输，从高处下来，路过沙地、石头堆、木桩，一趟又一趟，不厌其烦。

其实茶茶这么执着，是有他的道理的。他会根据当时的温度做决定：天热的时候，蔷薇下的石洞穴那儿阴凉，他就想带着小崽们去那儿凉快凉快；等到了晚上气温降下来，他又会把小崽们带回巢箱睡。

![Image](images/img_018.jpg)

“安全至上派”的版纳可不管！每当她发现幼崽又不见了，警觉地跑到茶茶的“自建房”那，把小崽一个个叼回自己认定的“安全屋”（巢箱）。

![Image](images/img_019.gif)

一个不少的带到了“自建房”

这样的“运崽拉锯战”，几乎每天都在上演，只因两只水獭中意的“家”，从来都不一样，一个考虑气温，一个考虑安全。

![Image](images/img_020.gif)

又带到“自建房”这了

不过，这频繁的“搬家”看似混乱，

却意外成为幼崽们的“成长训练营”。

在父母的拖拽、推动中，小崽们逐渐学会攀爬与跟随。他们会循着声音，跟随着父母，从这个“家”搬到那个“家”。

![Image](images/img_021.jpg)

如今，有些调皮又活跃的小家伙，已经能在爸爸茶茶的一声招呼下，趁着版纳没注意的功夫，就跟着茶茶在场地里奔跑、追逐了，偶尔两只小崽还会凑到一起，你推我一下、我拱你一下，像是在闹着玩似的“决斗”一番。

![Image](images/img_022.jpg)![Image](images/img_023.png)

**游泳课，谁说了算？**

随着小水獭们渐渐长大，游泳技能的学习要提上日程了。和第一次育幼一样，饲养员准备了水位较低、适宜幼崽活动的水盆，当作他们学游泳的辅助安全的“教具”。

![Image](images/img_024.jpg)

先来看看“游泳教具”如何？

茶茶很快发现了这个熟悉的“教具”，立刻叼着小崽们放入水盆，让他们感受水的触感。可版纳很快赶来，对着他们不停叫唤。见状，茶茶赶紧将小崽们一一叼出水盆。

看来在“什么时候学游泳”这件事上，两只獭又一次出现分歧，版纳的谨慎，或许是觉得小崽们还没到适合学游泳的时机。

![Image](images/img_025.gif)

快出来！

不过，茶茶有自己的节奏。他带着小崽们一次次搬家、一次次经过水源，小家伙们跟着爸爸，一步步接触到了水。版纳拗不过茶茶这番“循序渐进”的教学法，最终也默许了。

![Image](images/img_026.gif)

学游泳，一点点慢慢来

一家子浩浩荡荡地下了水，小崽们在浅水区扑腾着，玩得不亦乐乎。等玩了一会，版纳和茶茶再把他们带上岸，一起做沙浴，在沙地里滚一滚、蹭一蹭，把身上的水分排干。

![Image](images/img_027.png)![Image](images/img_028.jpg)

现在每当阳光正好、温度适宜，版纳和茶茶就会带着小崽们走出巢箱，在沙地上晒太阳，一起在场地里探索。小崽们翘着小小的尾巴，跟在爸爸妈妈身后，学着茶茶的样子在场地里标记。

![Image](images/img_029.gif)

快跟上

觅食时，版纳和茶茶会用“哈”的呼唤声叫小崽们来到身边，将食物放在它们面前，小崽们也从一开始只闻不动嘴，变成了如今抢着吃食物呢。

![Image](images/img_030.png)

这就是茶茶一家育幼小崽的故事，

一场围绕“搬来搬去”的家

展开的育儿拉扯与成长。

欢迎来红山本土物种保育区

观察他们一家的溜娃日记～

![Image](images/img_031.jpg)

悄悄预告一下，下次我们就来解锁另一对新手水獭爸妈的故事，看看他们带“独生子”的日常，又会藏着哪些惊喜呢？
