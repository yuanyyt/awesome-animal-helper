# 入住“大猩猩豪宅”一年后是什么感受？

他们![Image](images/img_001.png)![Image](images/img_002.png)

大猩猩和细尾獴都已经成为舍友一年啦～新来的朋友没看错，就是那个魁梧的大块头和机警灵活的小家伙。

让我们来复习一下“友好睦邻”守则（**[大猩猩身边的小身影还会 “顺菜” ？](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650881875&idx=1&sn=6d36396dc708ba01a606718c70e10e33&scene=21#wechat_redirect)**），然后看看这一年以来，他们都有哪些有趣的故事吧～

![Image](images/img_003.jpg)![Image](images/img_004.jpg)![Image](images/img_005.png)

**“挖”出一个新天地**

![Image](images/img_006.png)![Image](images/img_007.png)

细尾獴可是出了名的“挖掘大师”。年初那会儿，四只细尾獴——阿曼尼、莫西、小米、潇潇——刚搬进大猩猩馆时，就趁着大猩猩不在的契机把内场的角角落落进行了地毯式搜索。

![Image](images/img_008.jpg)

角角落落都不放过~

为了满足他们这种天性，饲养员在室内也给他们留了专属卧室以及四通八达的管道方便细尾獴探索，柔软的沙子方便他们建筑自己的地下巢穴；洞穴卧室外的安全地带也不容放过，专门铺设了高高的沙堆，把食物散落在上面，让他们自己去挖掘。

![Image](images/img_009.jpg)

一点点扩展自己的探索范围~

如果你来到大猩猩馆，你能看见四只小家伙在门口刨沙的动作快得像装了马达，前爪翻飞，带起的沙子溅得老高，挖到食物的瞬间，猛地抬头扫视四周，确认安全后快速嚼动，警惕又高效地完成进食。

享受过美食之后，他们连大猩猩的“床”都不放过！冬天，大猩猩常常会用稻草搭一个窝，精挑细选地调整窝的位置和造型，直到自己满意为止，最后成品软乎乎的，像个巨型鸟巢。

![Image](images/img_010.jpg)

老大搭的窝又大又圆~

等大猩猩离开后，探索欲强烈的细尾獴们路过时总要上去踩两脚，甚至干脆躺平打个滚——大概是想体验下“大高个的床垫”到底是什么感觉～

![Image](images/img_011.jpg)

小獴也能睡大“床”~

当然，这种“蹭床”是有前提的。在非洲区，经常观猩（观察大猩猩）的小伙伴们知道，我们有一份观猩指南，记录着大猩猩的作息和生活习惯。比如，下午13:30到14:20大猩猩会在内场做行为训练。

细尾獴有时就会利用这个时间差，在外场执行“错峰”探索，将自己探索的领域扩展、再扩展~

![Image](images/img_012.jpg)

看一看~ 到了独享的时间了

还有，当大猩猩退回内室，或者集体转移到外场晒太阳时，留在内场的细尾獴也是相当胆大。这时候你或许能看到一只细尾獴蹲在高处石头上，脖子伸得老高，眼睛扫视全场，剩下三只就在塑石缝里、栖架旁觅食、休息，甚至在大猩猩的食物边策划一场“捡漏”行动。

![Image](images/img_013.jpg)

家獴们！一起分头行动~

等大猩猩出现的信号响起时，他们就会凭借灵活的身形借助塑石下的通道躲藏，再伺机继续在内场中探索。

![Image](images/img_014.png)

**给你一个眼神**

**你自己看着来吧**

![Image](images/img_015.png)![Image](images/img_016.png)

如果说物理空间的共享是前提条件，那么细尾獴对大猩猩情绪的精准拿捏，就是这段和谐关系的灵魂。

细尾獴是哺乳动物里社会性极复杂的物种。在这个因各种原因聚在一起的临时小团体里，每只獴都有自己的生存策略。

![Image](images/img_017.jpg)

大猩猩香椿头是四只大猩猩的头领兼守护者，他总在显眼处观察四周的动静，守护这四个大猩猩组成的小家。细尾獴们则似乎早就摸透了这群大块头的脾气。只要老大在的地方，他们就绝不轻易靠近，只在安全距离外打量。要是赶上老大想活动筋骨，稍微追了两步，细尾獴就立刻集体后撤，溜了溜了~

![Image](images/img_018.jpg)![Image](images/img_019.jpg)

**全体目光看齐！**

相比之下，和另外三只大猩猩弟弟的相处就松弛多了，甚至冬天敢和大猩猩马兰头和小蒜头并排坐在窗前看雪，这种同框共处的场景别提有多和谐了。

在这里，他们不仅读懂了同类的警戒信号，更精准拿捏了大猩猩的“脸色”。这种和大猩猩互相的“拉扯”也极大丰富了细尾獴的生活。对于细尾獴来说，警惕是它们的天性，在环境中有适当的环节激发它们保持警惕的自然行为，比如站岗等，也能够锻炼它们的各种能力，有一定的益处~

![Image](images/img_020.gif)

在冬天，他们就经常在内场的窗户前往外望，一副“世界那么大，我想去看看”的架势。尽管有时候饲养员会将通往外场的门常开，让大猩猩和细尾獴自由选择。

![Image](images/img_021.jpg)

随着冬去春来，气温回暖，大猩猩和细尾獴在外场待的时间也越来越长。最明显的就是大猩猩会在外场上栖架躺一躺，感受一下阳光和风~ 那细尾獴呢？

“挖掘大师”细尾獴可不是白叫的，如果说内场的刨沙是环境丰容，那外场的挖掘就是天性释放。这一年以来，细尾獴在大猩猩外场栖架下方的土坡里、灌木丛的根部，挖了好几个地下巢穴。

![Image](images/img_022.jpg)![Image](images/img_023.jpg)

大猩猩外场出口

![Image](images/img_024.jpg)![Image](images/img_025.jpg)![Image](images/img_026.jpg)

大猩猩三层栖架下

![Image](images/img_027.jpg)

别看数量多还挺复杂，但四只细尾獴仅在白天外出时花上几天就能造好一个洞穴。其余时间就可以修缮洞穴、在场地中探索、给下一个洞穴选址。而这些洞穴虽然洞口不大，里面却四通八达，既能藏身，又能调节温度，位置还都是有遮挡可以避雨的地方。

有了外场的“度假屋”，细尾獴更是赖在外面不想回家。午后，他们趴在平台阴影里，吹着风，观察大猩猩在栖架上打盹，偶尔从土里刨出些小虫子当零食。

![Image](images/img_028.jpg)

嘿！你也要来晒晒太阳吗？

如果哪天你没有看到细尾獴，别着急——他们多半正在外场某个新挖的洞穴里避暑呢~

![Image](images/img_029.png)

**别担心！退路都留好了**

![Image](images/img_030.png)![Image](images/img_031.png)

面对越来越“野”的细尾獴，饲养员并没有着急干预，看似淡定，但也留了不少后手。

首先是召回训练。虽然细尾獴现在能自由进出，但饲养员仍每天在喂食时用哨声引导他们回到内室——这不仅是喂食的信号，更是关键时刻的保障，确保在极端天气或突发状况时，小家伙们能第一时间回到安全的室内。

![Image](images/img_032.jpg)

期待（星星眼）~

其次是外场安全。偶尔他们想在外场过夜，饲养员会把通往内室的门留条缝，再检查一遍外场有没有安全隐患，确保这些小家伙想回家时路是通的，在外场也能过得舒适。

![Image](images/img_033.jpg)

回家的门常打开~

这种“放手但不放任”的态度，核心在于尊重动物自由选择的权利，而饲养团队则是通过保留通道、定期丰容，最大限度地保留了他们的天性，让他们在这个空间里，都能活出自己该有的样子。

大猩猩依然每天打打闹闹，晒晒太阳、理理毛；细尾獴则依然在挖洞、放哨、机警地生活。他们共享同一片场地，偶尔隔空对视，短暂观察后便继续各过各的，这何尝不是一种默契。

![Image](images/img_034.jpg)

偷偷观察中~

这些大猩猩和细尾獴的故事还在继续。接下来，他们又会造出什么新花样？总之，记得常来看看～ 毕竟，在大猩猩馆的每一个角落，都可能藏着一个正在发生的新故事。
