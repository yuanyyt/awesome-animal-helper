# 除了老虎，还有谁的屁股“摸”不得？

![Image](images/img_001.png)![Image](images/img_002.png)

**你是不是也会好奇，敏感警觉的小麂们如何进行日常的健康检查？又如何稳定地走入和走出航空箱？这些都需要靠饲养员和小麂们日复一日相处攒下的信任感。这份信任，是小麂可以安心搬家的 “定心丸”，也是我们能开展健康监测的基础之一。**

![Image](images/img_003.png)![Image](images/img_004.jpg)![Image](images/img_005.png)

**安心搬家第一步**

![Image](images/img_006.png)

让帮小麂适应航空箱，是为日后可能的搬家提前做好铺垫。我们要让这个临时空间，从陌生的 “小房子” 变成它们愿意安心停留的所在。没有勉强，只需呼唤引导，小麂便会主动走入航空箱中，并从容地待在其中，走出时也没惊慌，而是按照它们自己的节奏慢慢走出。整个过程舒缓自在，最大限度减少了它们的应激。

这是彼此默契的见证，让小麂在安心的氛围中接纳航空箱，明白这是通往新环境的安全载体。这份从容，是后续转运工作的“底气”，让去它们去新家的路是稳稳的安全感~

出还是从从容容~

![Image](images/img_007.png)

肛温检测要慢慢来

![Image](images/img_008.png)

这样深厚的信任关系，让我们得以更温和、更稳妥地开展小麂健康监测。在这份信任的基础上，我们开展了体温监测，用客观数据为它们的健康保驾护航。

![Image](images/img_009.gif)

好奇小麂

和人一样，小麂也会出现发热、不适等状况，尤其在气温偏低的冬季，及时捕捉体温异常，就能更早发现健康隐患。在没有进行肛温检测行为训练之前，我们只能通过食欲、粪便以及精神状态判断，比如小麂发烧时背部是有点弓着的，还会发抖。

![Image](images/img_010.jpg)

小麂观察中

天性敏感又谨慎的小麂，想顺顺利利完成体温测量可没那么简单。

俗话说 “老虎的屁股摸不得”，放在小麂身上同样适用，它们对身体后侧的触碰特别戒备，哪怕只是一点点细微动静，都会触发本能反应，立刻躲开甚至跑开。不仅测量没法顺利进行，还可能让小麂们意外受伤。从去年开始，我们就靠着彼此的信任打底，一步一步、慢慢地做适应引导。先从它们接受度最高的颈部区域进行轻柔抚触，让小麂在放松、安定的状态下保持平静，再慢慢将接触范围延伸至腹部、臀部区域，小麂们能接受一个区域的“解锁”，我们才会往下进一步~

![Image](images/img_011.jpg)

触碰适应中

等小麂完全适应身体接触后，我们再佩戴手套，轻柔完成肛温测量，全程通过持续的温和安抚让小麂保持稳定，结束后提供它们喜爱的食物作为正向激励。

目前，我们已经可以稳定为奶昔、蜜瓜、椰果三只小麂采集有效体温数据。你知道嘛，小麂幼崽的肛温会略高于成年个体哦~

![Image](images/img_012.png)

肛温检测成功

![Image](images/img_013.png)

**体重检测是日常~**

![Image](images/img_014.png)

从 2024 年开始，体重称量便成为小麂照料中的重要环节之一。这份数据不仅能反映小麂的成长状态，孕期照料、健康监测提供关键依据。尤其是对于怀孕的小麂，通过体重变化可判断营养是否充足，如果体重长期停滞不前，便需及时补充营养。

![Image](images/img_015.jpg)

顺利称上体重

称量工作的难点，主要集中在幼年小麂身上。它们比成体更加胆小谨慎，戒备心也更强。这需要我们逐步让小小麂们适应体重秤, 在它们对体重秤逐渐脱敏之后，也就可以在体重秤上安安稳稳，称重就可以顺利完成啦。

![Image](images/img_016.jpg)

小小麂探索中

无论是航空箱脱敏、体温监测、体重称量还是其他的日常行为训练，核心都离不开「信任」二字。我们顺着小麂的天性慢慢来，用耐心与它们一点点构筑信任，这样，才能更好地陪伴它们在这里自在安稳、岁岁安然。
