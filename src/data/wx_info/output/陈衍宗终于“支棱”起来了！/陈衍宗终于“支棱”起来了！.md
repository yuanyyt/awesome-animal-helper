# 陈衍宗终于“支棱”起来了！

![Image](images/img_001.png)

**欢迎重新认识一下今天的“男主角”**

——**陈衍宗**！

![Image](images/img_002.png)![Image](images/img_003.jpg)

在很长一段时间里，陈衍宗都生活在狼王史丹利的狼群中。作为一只与狼王年纪相仿的公狼，他在群体里一直处于“默默无闻”的状态，总是夹着尾巴，小心翼翼。

![Image](images/img_004.jpg)

但今年冬春交替之际，万物复苏，也是狼群发情的季节，机会终于来了！

陈衍宗能否抓住这次机会，

寻求到一个伴侣呢？

![Image](images/img_005.jpg)![Image](images/img_006.png)

***从“小透明”到“狼王”的逆袭之路***

为丰富种群血缘、优化社群结构，同时给予低位个体独立发展的空间，饲养员启动种群调整工作，将陈衍宗从原狼群分出，尝试为他搭建全新的小型社群单元。

**叮咚！小科普时间**

狼群的繁殖权与社群等级，依靠种内竞争自然确立。争斗是狼群梳理等级、确认秩序的本能行为，因此饲养员全程采取低干预模式，仅保障安全，不中途打断未分胜负的争斗。

贸然干预未分胜负的争斗，只会暂时压制矛盾，后续仍会反复爆发冲突。唯有让它们自然决出高下，才能彻底稳固新的社群秩序。

![Image](images/img_007.jpg)

“分配媳妇”还有这好事？

于是，饲养员将适龄正直发情期，且一直对陈衍宗表现出好感的母狼小冬、小秋（史丹利与佳佳之女），一同与陈衍宗合笼，给了他一片全新的小天地。

而长期在史丹利的狼群中被压制，刚获得“自由”的陈衍宗依旧呈现高度谨慎、避险畏缩的行为状态。即使进入全新环境，面对两位已经发情、主动示好的母狼，他依然不敢上前嗅闻。

![Image](images/img_008.png)

莫过来!!!

小冬和小秋非常主动，时不时从他身边经过，把尾巴侧到一边让他闻味道，甚至去拱他、追他，两只母狼还会一起围着他，拦住他的去路。（同款互动参考胡椒&天涯：上集：长公主落难。下集？你猜。）

![Image](images/img_009.jpg)

宗：不要过来！

可此时的陈衍宗依旧不敢动、不敢回应，只是佝偻着身子待在那儿，甚至会通过呲牙威慑、驱赶她们，终止她们再次近距离接触。或许是他怕此时被史丹利发现，突然冲出来再次欺压他，不敢贸然行动。

僵局在一场母狼的繁殖权竞争后被打破。

![Image](images/img_010.png)

咋打起来了

还是我魅力太大了

傍晚时段，小冬和小秋为了争夺繁殖权“开战”了。按照狼群常规习性，成年公狼一般不会介入母狼间的争斗，但本次争斗中，陈衍宗出现了罕见的介入行为，主动辅助处于下风的小冬对抗小秋。

十分钟的争斗角逐后，竞争结果落定：小秋以一敌二，依旧胜出小冬。

![Image](images/img_011.png)![Image](images/img_012.png)![Image](images/img_013.png)

**胜利者**

**小秋**

![Image](images/img_014.jpg)

然而，打斗结束后，陈衍宗并未与胜者小秋产生互动，也未立刻促成配对关系。反而三只个体各自分区活动，无任何近距离互动。

饲养员猜测：难道是陈衍宗之前帮助小冬，是他更倾向小冬？于是将获胜的小秋隔开，尝试让陈衍宗与小冬独处。

但失败后的小冬垂头丧气，提不起精气神，陈衍宗也没有任何表示。眼看衍宗兴致缺缺，适配尝试宣告无果。

![Image](images/img_015.png)

宗：没意思没感觉

为完整排查最优适配组合，不错失任何机会，饲养员再次调整分区，换小秋进入陈衍宗的活动区域。

这一次，种群适配呈现出截然不同的状态。门一打开，小冬主动退至缓冲区规避互动，而小秋径直进入活动区域。仅两分钟，陈衍宗和小秋顺利完成交配，正式确立配对关系。

但这并没有让陈衍宗卸下防备！

![Image](images/img_016.jpg)

***遇见你，真好！***

**欢迎进入陈衍宗的**

**“变形计”time！**

自从小秋的出现，陈衍宗整个“狼设”都变了！此话怎讲！？

以前他可是出了名的“不冒尖”，在群体的施压下，只能躲在洞穴、走路夹着尾巴，走两步就要回头张望，生怕史丹利突然冲过来收拾他。

![Image](images/img_017.png)

甚至在第一次跟小秋交配之后，他自己也不敢与小秋再来第二次。可架不住小秋主动！侧尾、拱他、追着不放，反复发出邀请信号。来来回回好几次，陈衍宗才终于再次与之交配。

从那以后，那根夹在两条后腿之间的尾巴，开始骄傲地向上翘起。他甚至能隔着墙跟史丹利互相叫啸。

![Image](images/img_018.jpg)

宗：尾巴一翘，就是这么自信了！

也正是在这个阶段，经历了“夺宗”之战，小秋的脸颊多少挂了点彩。陈衍宗也不忘对小秋展示自己的温柔，总会凑了过去，开始给她舔伤口。这一舔就停不下来，翻来覆去、认认真真。结果因为舔得太频繁、太用力，让小秋刚结痂的伤口愣是被他又给舔裂开了。（可比隔壁天涯给胡椒舔的认真！）

![Image](images/img_019.png)

小插曲：后来陈衍宗有几天没怎么舔了，伤口才好好愈合。

而在这段反反复复的舔舐和靠近中，两只狼的关系越走越近，几乎时时刻刻都要待在一起。

同时，在小秋的带领下，陈衍宗也学会了做标记。时不时看到他俩开始共同标记，这对狼王狼后，正式确立！

![Image](images/img_020.png)

狼后-小秋

![Image](images/img_021.png)

狼王-陈衍宗

---“小情头”---

甚至后期面对饲养员准备的食物，陈衍宗总是先把碎渣渣、小边角料的肉吃掉，然后省下那块最大的肉，叼着走到小秋面前，让小秋吃。

![Image](images/img_022.jpg)

宗：小秋，我来了，吃肉！

平时他也总围在小秋身边转悠，休息的时候就并排趴着，脑袋搭在对方背上，或者互相靠着舔毛，时不时互相用鼻子拨弄一下，或者拿脑袋蹭蹭对方。

![Image](images/img_023.jpg)![Image](images/img_024.jpg)

监控视角下的贴贴

这或许就是小秋的陪伴与双向的社群适配，让蛰伏已久的陈衍宗完成了正向重塑。如今他状态稳定、责任感突出，这便是狼群自然的磨合与陪伴的力量。

适配、陪伴、守护、共同成长，

是这对新搭档最亮眼的标签。

一切准备就绪，我们也满心期待：完成蜕变、学会守护同伴的狼王陈衍宗，在繁育周期中会展现出怎样的亲代行为？能否顺利解锁“狼爸”新身份，用心守护新生幼崽？

![Image](images/img_025.jpg)

后续我们将持续跟踪记录陈衍宗狼群，

静待属于他们的全新故事。
