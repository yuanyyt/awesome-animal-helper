# 这一关它们真不一定能过

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)

**“**

![Image](images/img_005.png)

春风拂过金陵城，枝头新绿间传来阵阵清脆鸟鸣。

![Image](images/img_006.gif)

在这万物复苏的季节，迁徙的候鸟正悄然开启生命中最壮丽的旅程。然而，在这段跨越千山万水的旅程中，当它们抵达城市上空时，那些无法被看见的玻璃幕墙与窗户，却成了它们旅途中最难的“一关”。

**01**

**为什么总在频频撞墙？**

对鸟来说，有天空的地方就意味着可以通行。

![Image](images/img_007.jpg)

对鸟而言，玻璃看起来不是障碍物 / blackred

白天，玻璃的透明性和反光特性，会映出蓝天、白云和树木的倒影，在鸟儿眼中就是一片可以穿越的风景。它们以高达每小时数十公里的速度，毫无防备地撞上那堵“不存在的墙”。

![Image](images/img_008.png)

迁徙鸟类被困在光柱中 / Rössler

夜晚，许多候鸟为躲避天敌和高温选择夜间迁徙，城市璀璨的灯光却让它们迷失方向，在玻璃迷宫般的楼宇间惊慌失措，四处碰壁，或因找不到落脚点而力竭身亡。

对于依赖视觉导航的鸟类来说，倒映在玻璃上的绿植、前方通透明亮的光景都无异于一个致命的“甜蜜陷阱”。鸟儿看不见玻璃，意识不到玻璃的存在。

这场最残酷的“鸟机验证”，对它们而言，成功率是零。

![Image](images/img_009.png)

绘制：幽灵螳（北京林业大学）

**02**

**鸟撞，一直在发生**

冰冷的玻璃，吞噬着温热的生命。

2025年9月，市民房女士在北京一座普通大厦下发现14只红胁绣眼鸟（国家二级保护动物）横七竖八躺在地上，其中12只再也无法醒来，元凶正是反射天空的玻璃幕墙。

![Image](images/img_010.png)

2025年秋季，观鸟志愿者仅一个早上就在南京明城大道桥面玻璃隔音墙旁发现4只撞死的小鸟。这里成为候鸟迁徙路上的“致命通道”。

这些不是冰冷的案例，而是一个个曾经翱翔的生命逝去的痕迹。

全国防鸟撞行动网络的公民科学调查，为我们勾勒出更清晰的图景。

![Image](images/img_011.jpg)

素材来源网络

截至2025年春季，超过6900名志愿者在186个城市完成的调查显示：在一次调查周期内就有307只鸟类死于鸟撞，其中不乏红喉歌鸲、鹰鸮等国家二级保护动物。数据显示，玻璃面积越大，鸟撞风险越高。

**03**

**从“看见”到“改变”**

面对这道“透明的墙”，我们并非无能为力。有效的“补丁程序”早已存在——那就是让玻璃“显形”！

![Image](images/img_012.png)

加拿大渥太华《鸟类安全设计指南》

在玻璃外侧粘贴防鸟撞贴纸，是目前国际公认的有效方案之一。其中，间距不超过5厘米×5厘米的规则点状或条纹矩阵图案，效果尤为显著。

这些在人类看来或许有些密集的图案，能够将大面积玻璃“分割”成鸟类视觉能识别的碎片，从而帮助鸟类识别危险，意识到“此路不通”。

![Image](images/img_013.png)

从上海常馨生境花园的社区实践，到深圳腾讯总部的玻璃大面积改造；从武汉光谷智慧园动员70人完成的144扇窗和12扇门的改造，到南京明城大道桥上千平方米隔音墙的贴纸安装。无数案例证明，简单的改变就能拯救无数生命。

![Image](images/img_017.png)

浙江农林大学

农林护羽行动——让天空有“界”活动

无论是抬头看看身边的玻璃窗，贴上小小的防撞贴纸，又或是在朋友圈里转发一条鸟类保护的科普，都是在为天空清扫一条安全的航道，让鸟儿的飞翔更加自由通畅。

个体的行动是星光，汇聚起来便能照亮鸟类的航路~
