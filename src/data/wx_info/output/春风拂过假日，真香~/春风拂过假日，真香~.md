# 春风拂过假日，真香~

![Image](images/img_001.png)![Image](images/img_002.png)

3月以惊蛰为始，春分居其中，临近清明结束。惊蛰至清明恰是春意正弄的“仲春”时节，万物复苏，春光烂漫，春天以肉眼可见的速度铺展着蓬勃生机。

枝桠间的嫩芽一日一个模样地舒展，不过旬日便已满树新荫；桃红樱粉，杏雨梨云，应接不暇……

此情此景，曾经苦苦背诵的课文竟跃然心上，“桃树、杏树、梨树，你不让我，我不让你，都开满了花赶趟儿。红的像火，粉的像霞，白的像雪。花里带着甜味儿；闭了眼，树上仿佛已经满是桃儿、杏儿、梨儿。”

我们常常忍不住问：**“好美、好香……这是什么花？”**

![Image](images/img_003.png)

3月降水频繁，雨量超过常年均值。

接连的阴雨天气让3月整体气温偏低，但春分（3月20日）过后迎来晴日回暖，公园、景区、朋友圈里都是春日限定的花花世界~

![Image](images/img_004.png)

3月气温曲线图

紫叶李是桃李樱梨海棠系列中最先盛开的春花，3月4日就记录到北门湖沿路的紫叶李进入了花期。

![Image](images/img_005.png)

紫叶李

紫叶李远观似樱花，但花瓣较小且薄而疏，花开没几日紫红色的叶子就长出来了，有点喧宾夺主的感觉，不过这下就不会被认错了。

园区除了紫叶李外还有花期较晚的白色李花。

![Image](images/img_006.jpg)

白色的李花

3月5日，惊蛰。尽管天气阴冷，但也记录到了生命复苏的讯息。

草丛中一只刚刚孵化的寰螽（huán zhōng）若虫十分应景（前胸背板侧缘上翘是识别特征之一）；

![Image](images/img_007.png)

寰螽 若虫

北门湖及非洲之歌的水塘中也记录到了大量中华蟾蜍的卵带。

![Image](images/img_008.jpg)

中华蟾蜍 卵带

早春野花中的紫堇家族悉数登场，紫堇是最早开放的，3月初已然是盛花季了。

它们的种子有油质体，可以吸引蚂蚁搬运，会出现在墙缝、屋顶、树洞等一些非常规的地方。

![Image](images/img_009.png)

紫堇

延胡索和刻叶紫堇在月初也陆续开放。

延胡索叶子类似竹叶，而刻叶紫堇叶片边缘有不规则的缺刻，花朵颜色较深且更密集。

![Image](images/img_010.png)

延胡索（左）

刻叶紫堇（右）

![Image](images/img_011.png)![Image](images/img_012.png)

园区其余两种紫堇：地锦苗和夏天无的花期略晚，集中在3月中下旬。

地锦苗又称“尖距紫堇”，花瓣后部长长的距是紫堇属植物花朵的典型特征，地锦苗花朵的距特别尖；

![Image](images/img_013.png)

地锦苗

夏天无的名字很好地说明了紫堇属植物的生存策略：赶在早春开花结果，在炎热的夏季到来时地上植株枯萎，将营养积攒在地下根部，静待下一个春天的到来。

![Image](images/img_014.png)

夏天无

**Ps:紫堇属植物全株有毒，千万别误食！**

3月12日，气温回升，园区的早樱盛开。

樱花的主要辨识特征在于花瓣顶端的缺刻以及枝干上的“唇状”的突起斑纹。

![Image](images/img_015.jpg)

樱花树干特征

早樱过后，杏花、梨花、桃花也相继加入：

其中梨花主要为白色，紫红色的花药在白色花瓣的映衬下格外醒目；杏花的颜色白里透红，花萼后翻是杏花辨识的重要依据；桃花颜色更红，花朵与狭长的燕尾状绿叶同时出现，看上去也不难辨识！

什么？还是分不清？那只能帮你到这里了！

3月14日，本土物种保育区记录到赤腹松鼠收集巢材，意味着它们也进入了繁殖季；灯蛾幼虫此时大量集中发生，它们主要在夜晚活动，取食早春植物的叶片。

![Image](images/img_023.jpg)

赤腹松鼠收集巢材 ©志愿者柳月月

3月15日过后，阴雨绵绵，润物无声。

3月20日，春分节气，昼夜均分，是仲春最核心时段，也是春意最浓的时节。

此时，晚樱开得正好，粉若烟霞。

![Image](images/img_024.png)

晚樱

春天竟是如此热烈，不经意间周围的一切都像是拉满了饱和度，是那么的生动和鲜活。

![Image](images/img_050.png)

春风又绿江南岸

3月23日，气温持续攀升，本土物种保育区黑眉锦蛇开始活动；黄缘闭壳龟也结束蛰伏，开始活跃。

![Image](images/img_051.jpg)

本土区黑眉锦蛇 ©志愿者沙沙

3月25日，北门湖的黑水鸡步入筑巢准备繁殖的阶段；

![Image](images/img_052.png)

黑水鸡筑巢

3月27日，虎馆附近山林率先记录到小黑日宁蝉的叫声；

它们是南京地区最先出现的蝉，依稀的蝉鸣，夏天还会远吗？

![Image](images/img_053.jpg)

3月28日，园区胡蜂选址筑巢如期而至；

3月30日，园区越冬的北红尾鸲已迁徙离开，这回秋裤是真的可以脱了。

当然，像灰背鸫、斑鸫、红胁蓝尾鸲等冬候鸟月底仍有记录，推测也有可能是在更南方越冬的个体途径至此，鸟类的春季迁徙已然拉开序幕，春季候鸟监测提上日程。

3月31日，冷暖气流交汇带来大范围降雨，春雨潇潇，落英满地。但枝叶渐盛，正是一番“绿肥红瘦”的景致。

3月还有“世界气象日”、“地球一小时”、“国际零废弃日”。

*3月23日世界气象日当天，世界气象组织发布的《2025年全球气候状况》报告指出，地球能量失衡达到自1960年有观测记录以来的最高水平。地球能量平衡状况衡量的是能量进出地球系统的速率。在气候稳定情况下，每年来自太阳辐射的能量与从地球逸出的能量大致相等，然而，温室气体浓度不断上升打破了这种平衡。报告指出，留存地球的过剩能量中，仅1%储存在大气层，造成大气层变暖。大约5%的过剩能量储存在大陆陆地中。超过91%的过剩热量储存在海洋中。而海洋温度的升高对全球天气系统带来了一系列的负面后果和连锁反应。*

这些数据听起来遥远，但其实和我们身边每一朵紫堇、每一声蝉鸣息息相关。

春天用它的方式提醒我们：记录美好，也别忘了追问变化。愿你走出门去，看得见“红的像火，粉的像霞”，也听得懂这热闹背后的自然密码。
