# 哎呀，你俩热心过了头！

![Image](images/img_001.png)

还记得那个[52.4g超重宝宝，惊险开局！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650890390&idx=1&sn=ef1e09d6ffa5dccb605b26f876fa2f76&scene=21#wechat_redirect)的赤掌𤟠宝宝——“很高兴”吗？在饲养员精心的人工育幼下，他不仅顺利掌握了攀爬、跳跃和自主觅食等生存技能，也迎来了成长的下一关——**回归群体！**

![Image](images/img_002.jpg)

**坚定的眼神！我可以的！**

由于小家伙的生母刚经历剖腹产，尚在产后恢复期，无法立刻承担起抚育的重任。饲养员在综合评估并排除了孕期家庭后，最终将目光锁定在了刚诞下双胞胎满月的赤掌𤟠(xū)“二一”一家。

他能顺利加入这个新家庭吗？

![Image](images/img_003.png)

**初次见面，请多关照！**

![Image](images/img_004.png)![Image](images/img_005.png)

作为群居动物的赤掌𤟠，当他从人工育幼环境中长大再回到同类群体，每一步都需要慢慢来。

![Image](images/img_006.jpg)

家里要来新宝宝啦～

当很高兴能够独自安稳地在小屋里过夜后，饲养员便正式开启了日间合群适应模式。为了给他足够的安全感，饲养员每天白天会让他抱着熟悉的猩猩玩偶待在转运笼里，并将笼子放置在二一家族的活动区域内；而到了夜晚，则依旧将他带回育幼室单独休憩。

初入陌生群体环境，他胆怯地趴在玩偶上，只敢时不时探出小脑袋，偷偷打量外面那些和自己长得像、却行动敏捷的新伙伴们。而二一家族对这个突然出现的猩猩玩偶反而充满了戒备，纷纷跳跃掠过，不敢靠近。

![Image](images/img_007.png)

在安全距离里，互相试探

经过两天白天的隔笼适应，大家发现彼此并没有敌意，二一一家甚至开始大胆地跳到转运笼上活动。见时机成熟，饲养员打开了转运笼的门，让他可以互相进出活动。在此期间，他们之间相处和谐，没有发生任何攻击行为。

![Image](images/img_008.jpg)

到了4月19日，饲养员把很高兴的家从转运笼升级成了空间更大的小屋。不过晚上还是让他单独入睡，毕竟适应新环境不能太心急。

白天，饲养员依旧将小屋放到二一家的活动空间，并同样打开门。这一次，二一家的成员们胆子大了起来，直接进入了他的小屋。

![Image](images/img_009.jpg)

他屋里有好吃的

不过很快发现，他们感兴趣的似乎不是小屋里的很高兴，而是饲养员给他在小屋里放置的辅食。“呲溜——”凑近、拿上、跳开、吃，一气呵成。没有攻击，没有冲突，倒像是很高兴给新邻居们送上了“见面礼”。

![Image](images/img_010.jpg)

在这个过程中，很高兴也逐渐壮起了胆子，跳出小屋，开始在大环境里尝试攀爬。这很快引起了二一的前一胎孩子“一五”的兴趣，他围着很高兴转悠、并凑上前与他互动。看到这样自然的破冰，饲养员决定尝试下一步：让兴兴留在二一家过夜，不再回育幼室。

我换名字啦——兴兴！！！



![Image](images/img_011.jpg)

随着相处的深入，看着很高兴逐渐融入二一的大家庭，饲养员也为他改名。将“很高兴”改为“兴兴”，加上赤掌𤟠妈妈“二一”的双胞胎幼崽“向向”和“荣荣”，合在一起便是“兴兴向荣”。希望他们能够茁壮成长，这个小家庭依旧能和睦共处。

![Image](images/img_012.png)![Image](images/img_013.png)

**很高兴遇见你，**

**我的跨界爸妈～**

![Image](images/img_014.png)![Image](images/img_015.png)

在兴兴与二一一家逐步相处的期间，还有一个别样的小插曲。其实二一家平日里和一对尚未繁育的松鼠猴共同生活，分别是雌猴长尾与雄猴三藏。

![Image](images/img_016.jpg)

要来新伙伴啦～

面对新成员的到来，松鼠猴夫妇对他同样充满好奇。他们没事就来小屋前转悠打量一番，偶尔还伸出爪子轻轻碰一碰小屋的栅栏。

![Image](images/img_017.jpg)

松鼠猴长尾：来了一个小宝宝～

直到，兴兴开始在大环境里四处探索时，长尾的兴趣彻底被点燃了。兴兴走到哪，长尾就跟到哪，几乎寸步不离。兴兴攀上一根细枝，长尾就在旁边的枝上蹲着；兴兴跳到另一处栖架，长尾也紧跟着换位置。

你去哪、我去哪

三藏呢，则常常待在兴兴的附近，像一个“移动的警戒哨”，不抢他的食物，也不干涉他的活动，只是时不时地扫视周围。

![Image](images/img_018.jpg)

跟上他、守护他

在他们的关心下，兴兴甚至想爬上“长尾”的背让她背着走，奈何松鼠猴光滑的毛发让他根本抓不住；“长尾”也想把他抱入怀里，可两个物种体型和抱姿的差异，让他们凑在一起时显得有些手足无措。

![Image](images/img_019.jpg)

就连后期，每当饲养员准备给兴兴喂奶，这对“跨界爸妈”都会立刻发出警报声，像护犊子一样驱赶饲养员。

![Image](images/img_020.jpg)

不可靠近！

虽然这份爱跨越了物种，十分感动，但为了避免兴兴过度依赖松鼠猴而无法学习同类的自然社交行为，饲养员在经过权衡后，只能将他们暂时分开，让兴兴回到真正属于自己的那一课。

![Image](images/img_021.png)

**融入集体，学会爱与被爱**

![Image](images/img_022.png)![Image](images/img_023.png)

离开了松鼠猴“跨界爸爸妈妈”的关爱，

兴兴和二一一家的关系

有没有更进一步呢？

答案是肯定的。

![Image](images/img_024.png)

起初，兴兴在大家庭里还是有些小心谨慎。在自己去喝水的时候，他被比自己体型还小的幼崽路过吓了一跳，轻轻跳开，然后观察了一会才又回来继续喝。但慢慢地，他的好奇心占了上风。

![Image](images/img_025.jpg)

越发胆大了

有一次，他看到背着两只幼崽的爸爸“炭心”从身边经过，忍不住凑近了，仰头看着炭心和背上的向向和荣荣。此时，两小只也在高处低头打量他。终于，兴兴率先“破局”，举起小手轻轻摸了摸他们，然后快速跑开。这惹得二一家的小崽们兴趣大发，赶紧下背追过去互动了。

![Image](images/img_026.png)

还在爸爸背上的小崽

渐渐适应群体生活的兴兴，不再整日依赖专属小屋与安抚猩猩玩偶寻求安全感，对外界自然环境与族群同伴充满探索欲。饲养员见状顺势撤走专属小屋和猩猩玩偶，慢慢帮他淡化对人工安抚物品的依赖，全心全意投身族群集体生活，全身心接纳同类陪伴。

![Image](images/img_027.jpg)

兴兴：再见啦～伴我长大的猩猩玩偶

随着向向和荣荣的日渐长大，妈妈二一开始主动给兴兴理毛，梳理彼此的感情；甚至后来，当饲养员靠近准备给兴兴喂奶时，二一都会下意识地将兴兴护在身后。小小的他趴在那里，享受着家庭成员的接纳与宠爱。

![Image](images/img_028.jpg)

大胆地探索跳跃

如今的夜晚，兴兴会自信地跟着群体一起跑向内室，和大群紧紧抱在一起睡觉。在群体的耳濡目染下，他发出的声音也不再像在育幼室时那样单一，而是变得更加丰富多元。

和群体一起生活

他也开始学着像大猴子们一样为家人理毛，虽然动作还略显生涩，但在大家的包容与陪伴下，相信他很快就能熟练掌握这项重要的社交技能。

![Image](images/img_029.gif)

理毛还不熟练，浅浅意思一下

期待未来他能跟着这群亲密的“家猴”，解锁更多属于赤掌𤟠的自然天性，在这个温暖的大家庭里健康、快乐地长大！
