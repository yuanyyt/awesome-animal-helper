# 这两个小时，全凭自愿！

![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.png)

在南门新区“非洲之歌”落成后，黑猩猩乌豆率先来到这片崭新的土地进行适应，和黑山羊开启了热闹的小日子（[当黑猩猩遇到黑山羊](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650886447&idx=1&sn=dad15019d9cdca2583ec50ce7f5f48b2&scene=21#wechat_redirect)）。新家体验官乌豆亲测：这里真不错！小伙伴们快把搬家提上日程吧！

对于我们来说，搬家或许只是打包行李、换个住所；但对于黑猩猩一家来说，这是一次离开熟悉领地、踏入未知世界的巨大挑战。

![](images/img_005.png)

黑猩猩天生高敏、谨慎，力气又大，稍有陌生刺激就会情绪躁动。如果采用常规的麻醉转移，不仅存在健康风险，还可能引发强烈的应激反应。为了尽量避免麻醉带来的风险，饲养员决定走一条更难的路：不麻醉、不强制，靠日常训练和信任，让黑猩猩自己走进转运笼，住进新家。

为此，饲养员团队与黑猩猩一家展开了一场长达数月的“默契大考”。

**未雨绸缪，**

**只为那一刻的安心!**

搬家这件事，从决定到执行，

饲养员分两头同步推进。

旧家这边，饲养员每天都抽出时间，带着黑猩猩一家进行行为训练，包括串笼引导、和谐取食、通道适应等，让他们逐步熟悉通道及转运笼。新家那边，另一组饲养员同步排查场馆安全隐患，检查新笼舍的门锁、通道衔接，确保搬家当天硬件就绪。

![](images/img_006.jpg)

开始准备咯～

而在所有准备工作中，转运笼的设计也是关键的一环。笼子的尺寸既要能通过老场馆的门，又要能顺利进入新家的通道；整体重量得控制在饲养员可抬动的范围内；结构还必须足够安全，毕竟黑猩猩力气很大，一旦受惊或不适，会剧烈晃动甚至破坏笼体。没有现成适配的转运笼可用，饲养员便根据大猩猩转运笼的样式自行仿制修改。

![](images/img_007.png)

要适应老场馆，方便进出的转运笼

聪明的黑猩猩们堪称行为训练的优等生。转运笼就绪后，有了日常训练打下的底子，他们很快就进入了状态。回顾从内室到通道，尝试新的从通道到转运笼的行为训练。但通道区域和操作空间都比较小，只能允许一位饲养员进入操作，难以做到每只黑猩猩对应一位饲养员单独引导。这就带来了两个相互交织的难题。

![](images/img_008.jpg)

第一个难题是如何让多只个体稳定待在其中并和谐取食。只有当所有个体（不论强势还是弱势）全部在场且保持相对平静时，饲养员才给予食物。用这种方式，黑猩猩一家逐渐学会了在同一小空间内共同取食。

![](images/img_009.jpg)

我们肯定可以！

第二个难题是防止手脚抵门。从内室到通道，再到转运笼，每一次门的关闭，都需要黑猩猩们的高度配合。任何一只黑猩猩将手或脚抵在门关闭的位置，都会导致门无法合上。这就要求饲养员与黑猩猩之间建立起高度默契，引导所有个体稳稳坐住、稳住情绪，不伸手、不伸脚、不突然起身。

![](images/img_010.jpg)

就这样一步一步适应、引导，一点一点往转运笼集合。在训练过程中，小童从一开始并非最先接受转运笼的，但在饲养员的引导下，他逐渐成为转运笼中最为稳定的个体，也让饲养员对非麻醉转运的计划逐步增加了信心。

![](images/img_011.jpg)

真棒！小童

所有这一切，都得益于日常积累的信任训练。没有强制，没有惩罚，只有反复的引导、食物奖励和稳定的操作节奏。饲养员用时间换默契，用耐心换稳定。

就这样，一边训练，

一边调整，一边等待。

第一次搬家，即将开始。

**1月14日，**

**出师未捷，但没关系！**

1月14日，第一次搬家。

当天清晨，饲养员像往常一样打扫笼舍、准备食材，尽量不让黑猩猩察觉到异样。随后，他们像平时行为训练那样唤名、引导黑猩猩从隔壁房间进入串笼通道。

![](images/img_012.jpg)

起初，黑猩猩们比较配合，陆续进入通道。然而，一辆运输卡车的行驶声越来越近。这是与日常不同的声音。黑猩猩的听觉极为敏锐，一家五口瞬间警觉。小童首先离开通道，返回外场观察外面情况。黑豆和铁豆跟随小童离开，但年幼个体还在父母之间来回徘徊，没有完全进入通道。

![](images/img_013.jpg)

和平时不一样耶！

饲养员发现后，立即让卡车驶离黑猩猩视野范围。卡车移开后，黑猩猩们又陆续回到通道中稳定下来。

然而，真正的考验在进笼后。当饲养员将通道与转运笼之间那扇50多斤重的门落下时，声响和震动让原本还算稳定的黑猩猩一家再次躁动起来。

第一次搬家不得不就此中断。

重整旗鼓，

信任是唯一的桥梁！

失败没有让饲养员气馁，反而让他们更懂黑猩猩的心。饲养员立刻对第一次搬家全面复盘，重新设计、手工制作了全新的转运笼，让它更贴合饲养员操作与动物行为习惯。

在笼体中间增设可视可操作窗口，方便随时观察状态、温柔引导，对安全性与便捷性进行升级；把原笼网+木板结构，换成不锈钢板+不锈钢柱，更坚固耐用，既保护饲养员搬运安全，也给黑猩猩更安心的封闭小空间；内室到串笼用平推门，省力安静；串笼到转运笼的两道上下闭合门，加装插杆抵门机关，大幅减轻操作力度，同时减少关门震动与声响，最大程度降低刺激。

![](images/img_014.jpg)

转运笼2.0上线

装备升级，训练也同步加码。饲养员重点强化转运笼进出与门体起落声音脱敏，一遍又一遍，让他们慢慢不再对门的开合过度敏感。

但第一次失败让他们变得更谨慎了，串笼时常常只有四只聚在里面，总有一只在外面默默守护、不肯进来。我们从不催促、不强迫，始终保持平稳镇静。

![](images/img_015.jpg)

在饲养员的引导下，

他们稳定的坐在了转运笼里。

就这样，每天坚持训练，用温柔唤名、食物奖励慢慢铺垫，一点点重建他们对串笼流程的信任与耐受。默契，在日复一日的陪伴里悄悄回归。

当所有细节打磨到位，

当他们的状态重新稳定，

我们知道，是时候再出发了。

3月25日，

两小时的“奇迹”！

3月25日，第二次搬家。

当天早晨，饲养员依旧照常给黑猩猩和红猩猩准备食物、打扫房间。为了不让黑猩猩察觉异样，运输车辆改换了方向驶来，完全避开他们的视线。

起初饲养员还担心，逐一运输、搬运会惊扰到后面的黑猩猩个体，稳定性难以保证。可后来发生的事，超出了所有人的预期和默契。

![](images/img_016.jpg)

刚开始，在食物的奖励下，小珊和铁豆率先进入转运笼，小童紧随其后。门虽然能关上，但三只黑猩猩的体重加起来，饲养员根本无法抬动，也存在一定的安全隐患。于是安全起见，饲养员决定将小童先串出来，让小珊和铁豆第一批出发。

小珊虽有些紧张，全程紧紧抱着铁豆，但眼神中是对饲养员百分百的信任；铁豆虽然懵懂，但也紧紧依偎着妈妈。

![](images/img_017.jpg)

转运笼刚回来，原本以为还需要再次引导小童，谁知这位爸爸1秒进入转运笼，毫不犹豫！他要去追随他的二夫人小珊和小儿子铁豆啦。

![](images/img_018.jpg)

轮到黑豆时，看到阿姨小珊和爸爸小童的离开，在通道里的他开始焦虑地寻找妈妈小玉。直到看到小玉的身影，他才冷静下来，配合进入笼子。

![](images/img_019.png)

逐一进入新家

就在家庭成员逐一离开的过程中，小玉并没有跟随其他个体进入通道排队。她不断往返于外场、内室和通道之间，观察着整个群体的动向，守护着这个家。

当黑豆顺利抵达新家后，饲养员本以为小玉今天可能不太愿意进笼。但他们仍然尝试继续唤名、给予食物奖励，鼓励小玉进入转运笼。在谨慎与信任之间，小玉最终选择了信任饲养员，她主动走进了转运笼。

![](images/img_020.jpg)

两小时！全员安全抵达新家。

没有强制，没有麻醉。

一切，由动物决定。

![](images/img_021.jpg)
