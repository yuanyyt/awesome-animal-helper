# 我会但不用，谁叫爸妈“宠”我！

![Image](images/img_001.png)

**上回说到**

亚洲小爪水獭韩信（雌）在生产时闹了一场“厕所产崽”的乌龙，好在有惊无险。而这对毫无经验的新手搭档，在育幼上的表现倒是出人意料的优秀。（[糟糕！小水獭竟被生在了“厕所”里！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650889739&idx=1&sn=02e3d6ecaaed3ffdf7acba172b695256&scene=21#wechat_redirect)）

![Image](images/img_002.jpg)

不过，吃饱睡暖只是岸上的事。对一只小水獭来说，还有一门必修课等着它——游泳！这一次，“游泳教练”会是谁？是妈妈韩信，还是爸爸澜沧？

![Image](images/img_003.gif)

故事，从饲养员放下的第一个浅水盆开始。

![Image](images/img_004.png)

**谁才是真正的“游泳教练”？**

为了帮助小水獭平稳开启游泳学习，饲养员先是在室内场地里放了一个浅的小型水盆。

韩信很快发现了这个新物件，立刻将小崽衔到水盆中，而澜沧则表现出明显的谨慎，多次试图将小崽衔离水盆，最终还是没能拗过韩信的坚持，幼崽还是站在了浅水盆里，慢慢接触水环境、感受水波的触感。

适应了几天后，饲养员把水盆换成了稍长一些的型号。这个深度幼崽依然能踩到底，但已经可以浅浅地游上几下了，让它在安全范围内慢慢熟悉游泳的感觉。

![Image](images/img_005.png)

一周后，饲养员又更换了一个更大尺寸的水盆，依旧是韩信率先将小崽衔入水中。为了保障小崽的安全，饲养员特意在大水盆中倒扣了一个小水盆，供小崽体力不支时踩踏，同时根据小崽的游泳熟练程度，逐步调整水盆内的水位。

![Image](images/img_006.png)

不得不说，小水獭的学习能力十分突出，游泳本就是亚洲小爪水獭的本能，只需克服胆怯，便能快速适应，没多久就游得有模有样了。

![Image](images/img_007.png)

小宝，别怕，你可以的！

等到小崽在深水盆中游泳已十分自如后，饲养员便将韩信一家转移到了带有水池的活动区域。水池内放置了大量倒木和树枝，既方便水獭们攀爬下水，也丰富了水下环境，为他们提供了更广阔的活动空间。

在韩信和澜沧的自然引导下，仅仅不到一周时间，小崽就已能在水池中灵活穿梭、上下自如，完全适应了水池环境。

![Image](images/img_008.png)

这个眼神给的妙！

![Image](images/img_009.png)

**捕食技能GET，使用次数：0**

游泳技能熟练后，韩信一家便搬到了外场深水展区生活。刚到外场时，小崽表现得十分谨慎，始终紧紧跟随在韩信和澜沧身后，在场地内来回活动，慢慢巡视、熟悉新环境。

![Image](images/img_010.png)

冲！和爸妈探索新环境啦！

等小崽大致熟悉环境后，韩信和澜沧便径直奔向水池，一跃跳入水中，很快就消失在水面上。

![Image](images/img_011.png)

留在岸边的小崽见状，不敢贸然下水，只能在岸边来回跑动，同时发出叫声，寻找韩信和澜沧的踪迹。

![Image](images/img_012.png)

妈妈！爸爸！你们在哪里？

过了一会儿，韩信和澜沧从水中上岸，安抚岸边的小崽，随后慢慢引导它靠近水边，沿着枝干走到水池边缘的台面上，之后再次跳入水中，时不时探出头望向岸边的小崽，鼓励它尝试下水。

![Image](images/img_013.png)![Image](images/img_014.png)

韩信：爸爸妈妈来啦

就这样反复引导几次后，小崽渐渐克服了胆怯，先是小心翼翼地将头部探入水中，感受水，随后慢慢尝试在岸边浅水区短距离游动，再到后来，在韩信和澜沧的带领下和推动下，能够进入深水区短途游动，最后彻底适应，能跟随韩信和澜沧的速度，在水中自由畅游。

所以大家时常看到韩信和澜沧在岸边平台上合力把小崽“踹”下水的画面。可别误会，那不是严厉的教学现场，而是人家一家三口的日常嬉闹。小崽不是不会游，就是故意的…

![Image](images/img_015.png)![Image](images/img_016.png)

小水獭能有什么小心思？

只不过是游累了歇会罢了

掌握游泳技能后，小崽的学习重点自然而然转向了捕食。饲养员将食物放入水中，韩信和澜沧立刻纵身跳入水中，熟练展开捕食动作，小崽也紧紧跟在身后，有模有样地模仿着爸妈的姿态尝试捕食，凭借超强的学习能力，很快就掌握了捕食技巧。

![Image](images/img_017.png)

小崽吃

不过呀，这小家伙虽然已经掌握了捕食技能，但在离群独立之前，并不会真的自己动手。每次它都待在岸边，等着下水的爸爸妈妈把捕获到的食物送上来给它，毕竟这样能更快地吃到。

这样一来，也让韩信和澜沧的捕食工作量大幅增加了![Image](images/img_018.png)。以往他俩捕到食物后，只需找一根伸出水面的树枝，就能安心进食；如今捕到食物后，必须先上岸将食物喂给小崽，再重新跳入水中为自己捕食，捕食活动量直接翻倍。

![Image](images/img_019.gif)

有一种爱，叫爸妈的双份投喂

就这样在爸妈的双份投喂与照料下，小崽成长速度十分迅速，日渐健壮。

![Image](images/img_020.gif)

我也是过上“饭来张口”的生活了！

如今，这一家三口依旧在外场深水展区自在生活，时而一同潜入水中畅游嬉戏，溅起阵阵水花；时而并肩趴在岸边休憩觅食，时而凑在一起打闹互动，时而...

![Image](images/img_021.png)

澜沧：快跟上～

（从前至后：澜沧、韩信、小崽）

韩信还常常会衔来一些小石子和甲壳，放到小崽面前，任由小崽用爪子拨来拨去、摆弄上好一阵，这些不起眼的小东西，已成小崽专属的“天然玩具”呢。

![Image](images/img_022.png)

这是妈妈给我的“小玩具”
