# 谁是“大块头”？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)

谁是袋鼠家族里的“体型天花板”，

也是澳大利亚的“标志性代表”？

![Image](images/img_006.png)

图片来源于网络

它？《独行月球》里的“刚子”？

![Image](images/img_007.jpg)

它的原型**赤大袋鼠**

妥妥的当之无愧的双重担当～

赤大袋鼠不仅稳稳占据咱园内三种袋鼠（灰大袋鼠、赤大袋鼠、岩大袋鼠）中的体型首位，也是世界上体型最大的袋鼠，更是澳洲的“国家符号” 之一，其身影常镌刻在澳洲国徽之上，成为跨越国界的自然名片。

![Image](images/img_008.jpg)

赤大袋鼠

![Image](images/img_009.jpg)

岩大袋鼠

![Image](images/img_010.jpg)

灰大袋鼠

今天就带大家一起走进

红山南门新区的袋鼠角，

一起认识这群新朋友吧~

![Image](images/img_011.png)

**沙漠中的“赤色行者”**

![Image](images/img_012.png)

作为实至名归的“体型冠军”，

赤大袋鼠的“大块头”绝非虚名！

成年雄性堪称“袋鼠界的壮汉标杆”：成年雄性的身高一般可达1.4至1.6米；体重通常在70至90公斤之间，部分超大个体甚至能突破100公斤，整体轮廓显得尤为敦实。

![Image](images/img_013.jpg)

雄性与雌性之间的体型差异

相比之下，雌性体型明显纤巧，体重约30至50公斤，与雄性形成鲜明的体型反差，构成种群内的典型特征之一。

![Image](images/img_014.jpg)

他们的毛色具有鲜明的种群辨识度，脸颊两侧的白纹尤为醒目，且雌雄个体存在显著差异：雄性多呈现出鲜艳的赤褐色；雌性则偏浅褐色或灰色，腹部为白色。

![Image](images/img_015.jpg)

别看他们体型庞大，

适应环境的本事可一点不含糊。

作为天生的“沙漠奔跑者”，赤大袋鼠的后肢肌肉发达，爆发力十足，粗大的尾巴不仅能在奔跑时辅助保持平衡，在休息时还能像“第三条腿”一样支撑身体，让他们稳稳坐立。

![Image](images/img_016.jpg)

在红山外场的沙地上，常常可以看到他们常独自或成对放松躺卧的身影。夏季炎热时，他们会先用前爪拨开表层灼热的沙子，然后卧在下方相对凉爽的沙层中休息。

![Image](images/img_017.gif)

随着季节转换，赤大袋鼠的“作息表”会悄悄切换。冬季来临，他们白天的活动和采食频率与时长均显著增加，一方面为抵御寒冷储备能量，另一方面也充分利用此时较为温和的阳光“充电”。

![Image](images/img_018.jpg)

晒着冬日暖阳，躺在金黄的落叶上

待暖阳将身体烘得舒展通透后，他们便会陆续起身觅食。饲养员会特意将食物分散放置在不同区域，采用多样的丰容方式：有的高高挂起，有的插入土中，有的放入丰容球，还有的塞进消防水带编织的装置中...

![Image](images/img_019.jpg)

这种方式既鼓励他们自主探索、锻炼自然行为能力，也有助于减少因集中取食可能引发的竞争。

![Image](images/img_020.jpg)

当然，在共同觅食时，个体之间仍会出现一些轻微的“推挤”互动，如为了获取同伴站位附近的食物，他们可能会轻轻推搡对方，示意其让位呢。

![Image](images/img_021.jpg)

让我一下

偶尔能观察到雄性与雌性的短暂互动：雄性大红靠近以鼻部对小红进行嗅闻，结果小红侧身想避让，但大红不让，就发生了他俩互相用前肢轻轻扒动对方，片刻后便各自移开。

**从“废”到“食”**

![Image](images/img_023.png)

这些适应行为，

与他们的原生环境密不可分。

赤大袋鼠是少有的仅生活在澳大利亚内陆地区的袋鼠。那里类热、干燥、荒凉，而他们不仅拥有极致的节水和耐热能力，还可以在看似枯黄一片的荒原上，寻找到尽可能多的鲜嫩短草，从而有效地获取营养。

![Image](images/img_024.jpg)

真好恰逢冬季悄然降临，干羊草、干燕麦草等干草正式成为赤大袋鼠的主食，为他们提供了过冬所需的充足能量与膳食纤维。只是草木褪去葱茏，大地渐染枯黄，在这样万物萧瑟的季节里，如何让赤大袋鼠依旧能尝到一口鲜嫩青绿呢？

![Image](images/img_025.jpg)

直接在外场种植黑麦草？

显然行不通！

赤大袋鼠如同高效的“黑麦草收割机”，外场刚冒尖的草芽，转眼就会被他们觅食干净，根本来不及生长。

![Image](images/img_026.jpg)

不过饲养员自有妙招！继大猩猩农田后，他们专门开辟了“袋鼠农田”，有的用种植袋培育，有的在专用土地上，精心栽种黑麦草、荠菜等植物，只为让他们冬季也能吃到新鲜草料。

![Image](images/img_027.jpg)

农田

![Image](images/img_028.jpg)

种植袋

种植用的土壤藏着“循环密码”：饲养员将袋鼠们的生活垫料和粪便全部收集起来，进行科学堆肥处理。经过一段时间的发酵与转化，这些有机废弃物摇身一变，成为富含养分的腐殖土，重新回归土地滋养新一季的作物。

![Image](images/img_029.jpg)

堆肥中

得益于肥沃的腐殖土，黑麦草长得飞快，饲养员会定期将长高的新鲜黑麦草割了用丰容的形式给他们食用或直接将种植袋端去外场，等他们吃得差不多了，再把种植袋收回，让草继续生长。如此循环往复，让赤大袋鼠整个冬天都能吃到鲜嫩多汁的青草。

![Image](images/img_030.jpg)

除了饮食上的精心调配，饲养员还修剪场馆内的树枝，让更多阳光穿透枝叶，洒在外场的休息区，让他们更能充足的晒到太阳；剪下的树枝也不浪费，会挂在园区里供袋鼠采食；而经过修剪的树木，来年春天会生长得更加茂密，到了夏季，便能为袋鼠遮挡烈日，形成天然凉棚，真正实现“冬能晒阳、夏能乘凉”。

![Image](images/img_031.jpg)

躲在阴凉地儿

在这样细致入微的照料下，

赤大袋鼠家族迎来了新的惊喜。

不少袋鼠妈妈的育儿袋里，已经能看到小袋鼠探出的脑袋！其他母袋鼠还会凑上前嗅一嗅、蹭一蹭在妈妈袋里的他们。
