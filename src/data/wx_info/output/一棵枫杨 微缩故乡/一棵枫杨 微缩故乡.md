# 一棵枫杨 微缩故乡

![Image](images/img_001.png)![Image](images/img_002.png)

在红山唐家河的小熊猫展区，一棵巨大的枫杨树以其如盖的树冠成为了来往行人的视觉焦点。它静静伫立在这片土地上，已陪伴红山走过了无数岁月。

这棵枫杨树，在红山新区规划设计之时，总设计师就认定——这里一定要养小熊猫。当小熊猫入住后，饲养员也在这棵树下，为小熊猫和它们的唐家河故乡写下最温柔有力的注解——“一棵枫杨，微缩故乡”

![Image](images/img_003.png)![Image](images/img_004.png)![Image](images/img_005.png)

**#01**

**看红山唐家河**

从栈道步入唐家河小熊猫外场，第一眼带来的震撼，便是那“无界”的沉浸感。视线所及之处，几乎看不到传统的围栏或笼网。取而代之的是自然起伏的山地、错落有致的树木和在林中蜿蜒的栈道。

![Image](images/img_006.jpg)

▲唐家河栈道左侧

在二层栈道的游客视野之中，唯有枫杨高大粗壮的树干和向远方蔓延的枝叶。

如果仔细瞧一瞧，或许能发现在错落分布的枝干之上，正有一只小熊猫在酣睡。这就是自然最动人的时刻，蔚蓝的天空与摇曳的树影；沐浴在自然光下的、毛色火红的小熊猫。

![Image](images/img_007.jpg)

向下望去，便能看尽整个小熊猫外场的全貌。展区地面被精心塑造成具有高低起伏的自然形态，一棵倒伏的大树搭成一座桥梁，连接着地面和高大的枫杨。周围是丛生的竹子、灌木与高草形成了的天然视觉屏障，游客们可以瞧见一抹火红的色彩在树影中一闪而过。

![Image](images/img_008.jpg)

当你位于场馆外侧的时候，目光追随着小熊猫的身影，可以看见展区内高大的树木和栈道后方原生的茂密林地自然衔接，模糊了内外界限。让人不由自主地将视线从展区延伸至远方真实的树林中，仿佛置身唐家河的密林深处。

![Image](images/img_009.jpg)

▲唐家河栈道出口主干道

这种借助植物群落与平行而上的视觉空间所构建的“有形无界”的栖息环境，不仅保障了小熊猫可以在更自然的环境中生活，也为我们营造了沉浸式的自然观察体验。

![Image](images/img_010.jpg)

**#02***.winter*

**成为了一棵小熊猫树**

这棵枫杨在小熊猫来到之前，它是一棵鲜活生长的树。而小熊猫来到之后，它有了新的灵魂。

它粗壮、稳健，树皮沟壑纵横，为小熊猫的爪子提供了绝佳的抓握感。当小熊猫熟练地攀上树干，用身体摩擦树皮，或静静趴伏于枝丫时，它所展现的自然本能，正是我们在此最希望看到的画面。

![Image](images/img_011.png)![Image](images/img_012.jpg)![Image](images/img_013.jpg)

对于树栖的小熊猫而言，枫杨高大的树冠也为小熊猫提供了更多栖息的可能。

树木提供了丰富的垂直分层空间，树冠如盖，枝杈层层向上延展。小熊猫可以随心所欲地选择不同高度的位置——有的偏爱高处的树杈，有的则喜欢低处粗壮的枝干。

![Image](images/img_014.png)

▷放大找找图中有几只小熊猫呢？

它们不同的选择，也使得我们从不同角度观察时，每一次都能收获不一样的惊喜。

![Image](images/img_015.jpg)

▷正面看

![Image](images/img_016.jpg)

 侧面看◁

以枫杨为核心，饲养员和园林还编织了一张立体地活动网络，支持小熊猫展现多样自然行为。

由倒伏的树干和两棵白玉兰搭建而成的回形栖架，是小熊猫们重要的生活区域之一。这些纵横交错的木质栖架将枫杨与地面活动区连结起来，让小熊猫在树下也能够有更丰富的活动空间选择。

![Image](images/img_017.png)

▲小熊猫栖架平台

饲养员也会将竹叶放在高处，分散布置在栖架各节点与植被之间，增加了觅食难度的同时，也能够让它们有更多探索的机会。

我们的视线也随着栖架上的小熊猫而抬高，从前方的树丛自然延伸至背景的林带。减少了生硬的过渡，让小熊猫所处的整个画面更加自然。

![Image](images/img_018.png)

▲小熊猫在栖架上采食竹叶

展区地面顺应原有地形，形成了缓坡、小丘与平缓处相交替的自然格局。地面植被丰富，包含乔木、竹丛、灌草等多种类型，既为小熊猫提供了多样的体验，也为其在地面活动时创造了更多可供躲避的空间。

![Image](images/img_019.jpg)

小熊猫们可以选择在地面活动，来躲避游客的视线；也可以选择在树上观察下方的行人和周遭发生的动静。

![Image](images/img_020.jpg)

**#03***.winter*

**从树到一片共享森林**

这棵枫杨树不仅仅属于小熊猫，更是一个充满活力的微型生态系统。

细心观察，你会发现树上有各种鸟类停留的痕迹，它们与小熊猫共享着这片立体空间。

![Image](images/img_021.png)

▲枫杨树上留下来的鸟巢

夏日，一串串碧绿的叶片在枫杨枝头随风摇曳，宛如天然的风铃，那便是枫杨的果序。

![Image](images/img_022.jpg)

等到秋天，枫杨的翅果乘着秋风旋转飘落，成了黑尾蜡嘴雀嘴下的美食。

![Image](images/img_023.jpg)

冬日，树叶落尽。在树枝上，可以瞧见嘴里叼着今日口粮的银喉长尾山雀在这里驻足，寻找一个安稳的“小餐桌”。

![Image](images/img_024.png)

这棵枫杨树够大够高，即使珠颈斑鸠跳起求偶舞，也有充裕的施展空间。

![Image](images/img_025.gif)

在许多人眼中，动物园或许只是观察动物的场所。但在红山每一处设计背后，都藏着一份更深邃的思考。这棵枫杨，不仅是精心挑选的、与小熊猫在四川唐家河自然栖息地中息息相关的自然连接。

一棵树的存在，不仅是为了生长，而是为了自然生命的“记得”。而这样自然的设计我们还有很多很多....

![Image](images/img_026.jpg)

这棵枫杨，是一个无声却极具力量的引导者。它引导游客抬头观察：看小熊猫如何使用这棵树，它攀爬的动作何其灵巧自然。它引导游客去放眼思考：如何通过这棵树联想唐家河，联想我们身边的自然。

![Image](images/img_027.jpg)

唐家河展区是一扇窗，这种“生境化”展示，不仅让它们能表达自然行为，保有身心健康。而由此带来的，是来到这里的人获得被自然治愈的身心愉悦，而这份情感自然会延伸至对动物野外家园的关注与守护。

![Image](images/img_028.png)![Image](images/img_029.jpg)

当阳光穿过枫杨枝叶，在小熊猫身上洒下斑驳光影。
