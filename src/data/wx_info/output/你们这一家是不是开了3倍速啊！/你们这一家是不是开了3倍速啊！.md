# 你们这一家是不是开了3倍速啊！

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.jpg)

在红山南门新区非洲之歌中，赤猴一家的时间仿佛被悄悄拨快了。在悄然之间，这一家又多了一只在树梢间一闪而过的赤色身影。可这才过去短短5个月呀！

别怀疑，她们这一家的故事，正以一种“倍速”的方式，在每一天的日照推移中上演着~

**01. 小小的毛球 大大的胆子**

故事还得从去年年底说起。那时，妈妈常乐的怀里多了一只小小的毛球。那是新崽乐佩初到世界的模样~

![Image](images/img_005.gif)

小时候的乐佩在母亲怀中

刚出生的它用四只细细的小爪子，本能地、牢牢地攥住妈妈常乐腹部的毛发。吮吸母乳、睡觉、被妈妈带着在树间移动，是那段时间的全部日常。

![Image](images/img_006.jpg)

常乐给小时候的乐佩梳理毛发

饲养员们也对这个新生命格外关注，尤其在寒冬将至时，更是时刻留意。

在一次突如其来的降温天，妈妈常乐紧紧抱着乐佩，和爸爸常喜依偎在一起。饲养员注意到，乐佩头深深地向后倒栽着，角度夸张到有些让人担心。

![Image](images/img_007.gif)

“ 倒头就睡 ”

饲养员不禁捏了一把汗，但妈妈常乐却显得从容，平静地、有一搭没一搭地和其他家庭成员互动。

经过饲养员的仔细观察，才发现原来小家伙只是睡得太沉了，睡得没了睡相~

![Image](images/img_008.gif)

换个位置继续睡~

大约在一月龄，乐佩的变化开始加速。妈妈常乐开始有意地在低矮的树枝上停留，用身体语言示范着攀爬的要领，监督乐佩锻炼攀爬的本领。可小家伙的注意力却总有些“跑偏”~

![Image](images/img_009.gif)

身后有什么如此吸引小猴？

它对那些摇摇晃晃的小树枝格外着迷，在枝丫间试探、摇摆，就是不急着去追随妈妈的身影。

偶尔，妈妈会发出焦急的呼唤，却也拉不回乐佩那颗跃跃欲试的好奇心。总要过好一会儿，乐佩才跌跌撞撞地跟上妈妈的步伐。

![Image](images/img_010.jpg)

**02. 成长加速度！**

成长的按钮一旦按下，节奏便快得令人目不暇接。很快，乐佩就不满足于只当妈妈的“随身挂件”了，开始独自探索整个场地，胆子也越来越大。

![Image](images/img_011.gif)

给你们炫耀一下倒挂金钩~

在一次家庭理毛时光中，妈妈常乐正在为她梳理毛发，而比她年长一点的乐仔靠近彼此也想获得妈妈的关注。

![Image](images/img_012.gif)

乐仔在一旁试图吸引注意力

这个时候，乐佩从容地结束了互动，转身去摆弄起附近的小树枝，自己玩自己的，独自探索。就那样自然地接受了妈妈的注意力被分走，与乐仔共享这份家的温暖。

![Image](images/img_013.gif)

爱，是可以和家人一起分享的~

它独立的身影，在一次又一次的独自探索中，悄然成长起来。

真正的“成长加速键”，是家中又一只幼崽的诞生，新生儿自然成为了家庭的重心——这是赤猴家族的生存法则。而乐佩和家庭的关系，也随之悄然重构~

![Image](images/img_014.jpg)

新崽在母亲常乐的怀中

面对家庭成员的关爱转移，它没有表现出任何失落或焦虑，反而自然而然地，花了更多时间与家族中的另一位年长的母亲常笑，以及常笑家性格温和的孩子笑仔待在一起。它和笑仔在树杈间追逐嬉戏，锻炼着体能，也练习着社交技巧。

![Image](images/img_015.jpg)

新的“朋友圈”

在和同龄伙伴的互动中，乐佩那个自信，甚至有点强势的一面逐渐清晰，常常在玩耍中占据主导地位。它正以惊人的速度学习、适应着赤猴世界里那些复杂而微妙的社交规则，也开展着属于自己的“朋友圈”~

**03. 跑的快！长的也快！**

从开放非洲之歌到现在的转眼间，当初那个曾在妈妈怀里歪头大睡的小毛球，早已从容应对独立自主的生活。

![Image](images/img_016.jpg)

如果你在“非洲之歌”赤猴一家抬头看，很容易就能捕捉到一些灵巧腾跃的赤色闪电，那其中就有乐佩的身影。它攀爬、跳跃的身影自信而流畅，探索的范围早已覆盖了整个家园的每一个角落~

![Image](images/img_017.jpg)

此刻，另一只紧紧抓着妈妈、对新世界满是谨慎审视的新崽。如今3个月大的它，也正在走着乐佩曾走过的路。

![Image](images/img_018.gif)

新崽：尝尝妈妈吃的什么~

正一点点尝试妈妈尝过的食物，在妈妈的视线范围内练习攀爬、奔跑的本领，也会主动去找乐佩和乐仔玩耍，和这些同龄的家庭成员一起成长。

![Image](images/img_019.gif)

新崽和乐佩的贴贴乐~

说到底，这“倍速”成长的秘密，是写在赤猴这个物种的基因里的密码。在非洲稀树草原的故乡，幼崽必须尽快掌握移动、觅食和社交的本领。

作为世界上跑的最快的灵长类动物，越早成为树梢间的“闪电”，就意味着越高的生存几率。而幼崽的快速独立，也能让妈妈更快地恢复体能，为种群的壮大做好下一步准备。

乐佩那“风驰电掣”般的成长，是赤猴这个物种写在基因里的生存智慧~

![Image](images/img_020.jpg)

它们用最快的速度，完成从依赖到自主的蜕变，去拥抱广阔而充满挑战的世界。

下次你来“非洲之歌”展区，不妨多停留一会儿。看看树梢间、山林间的那些身影。在红山，每一天我们都在见证并记录着这些自然的奇迹~
