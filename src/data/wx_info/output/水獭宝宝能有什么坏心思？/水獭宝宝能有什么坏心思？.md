# 水獭宝宝能有什么坏心思？

**哎哎哎！**

是谁在破坏植物！

快把它的“罪行”拍下！

**咔 嚓 ～**

![Image](images/img_001.jpg)![Image](images/img_002.png)

亚洲小爪水獭

照片留存！

夏日的热浪裹挟着水汽漫过红山本土物种保育区，几株芭蕉在晨光中舒展着宽大的叶片，青翠欲滴。若细看，会发现其中几株根部套着白色塑料筒。

![Image](images/img_003.jpg)![Image](images/img_004.jpg)

这是饲养员们与獭们的“极限拉扯”——

![Image](images/img_005.png)

**谁在动芭蕉？是獭！**

![Image](images/img_006.png)![Image](images/img_007.png)

每年冬季，芭蕉叶逐渐枯黄，为避免倒伏风险，饲养员们会在冬季将芭蕉锯至半高，保留健壮的根茎。待春回大地，被“修剪”的芭蕉中的新芽从切口处争先恐后地钻出，抽出的叶片比往年更为繁茂。但这份生机，也恰巧成了水獭家族“选材”的目标。

![Image](images/img_008.jpg)

亚洲小爪水獭有持续絮窝的行为习惯，饲养员常年在它们居住的区域放置稻草、干枯树枝等巢材，供其自由挑选铺垫巢穴。

然而随着气温升高后，水獭又开始喜欢上新鲜的植物茎叶。韩信一家子总要在入睡前更新“床垫”。它们会撕扯芭蕉根部的嫩皮，拖回巢箱铺成软垫。新抽的小芭蕉常因此遭殃，嫩芽刚冒头就被它们“征用”了。

![Image](images/img_009.jpg)

选材

为兼顾植被存活与水獭行为需求，饲养员挑选几株长势、位置俱佳的芭蕉，套上白色筒状保护套，待枝干粗壮稳固后再拆除。

同时，也会在长有植物的地方、阴凉处放置一些獐子采食剩余的新鲜枝条，扩充水獭可选的絮窝材料，也转移它们对其他植物的“喜爱”。

![Image](images/img_010.jpg)

但獭有自己的主意！它们会随着气温不同时段的变化，跟着光照角度不断挪地方，哪儿阴凉就往哪儿歇。只是每换一处，它们就得就近扯些新鲜材料铺在身下，然后一家才安心趴下休息。

![Image](images/img_011.jpg)

獭能有什么坏心思

![Image](images/img_012.png)

**澜沧家的“澜沧江”！**

![Image](images/img_013.png)![Image](images/img_014.png)

等短暂休整过后，

澜沧、韩信带着幼崽

开启一轮新的活动。

夏季气温升高，环境里的绿植需要高频浇灌养护。饲养员布置喷淋管线的时候，除了给植物补水，也考虑到水獭对湿润沙土和泥地的偏好（[水獭：翻新大作战，我也要参与！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650857974&idx=1&sn=ec625194fcb05b286d20141f17ca6ffd&scene=21#wechat_redirect)），额外加装了一支朝向沙滩的喷头。

![Image](images/img_015.jpg)

又有新乐子啦～

喷淋一开，叶片上挂满水珠，折射着阳光。另一边，水落在沙滩上，慢慢聚出一片浅浅的水域。这倒是非常合水獭们的意，爸爸澜沧率先踩进去，妈妈韩信和小崽也跟着凑过来，一家子在这儿打滚、踩水，身上糊了一层泥。

![Image](images/img_016.jpg)

这么喜欢，

那就浅浅命名“澜沧江”吧。

平时进食的时候，它们也习惯身体半截泡在水里，大半截露在水面上。于是饲养员隔三差五往“澜沧江”里撒些螃蟹、泥鳅，供它们自主搜寻捕猎。

![Image](images/img_017.png)

一家三口玩嗨了

说到捕食，以前都是（[我会但不用，谁叫爸妈“宠”我！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650890125&idx=1&sn=152f33948510d50f79e277b882508655&scene=21#wechat_redirect)），爸爸澜沧在水里叼了鱼上岸递过去，刚吃完妈妈韩信又叼来一条送到跟前。现在可不一样了，在爸爸澜沧这儿，觉得小獭已经具备了自主觅食的能力，不再主动给予，幼崽想要进食，就得自行下水捕猎。

![Image](images/img_018.jpg)

不过妈妈韩信那儿，或许是觉得小獭还没长大，有时候自己都没吃上几条，一趟一趟地来回叼了食物送到小崽跟前，生怕自家娃饿着。可她大概没注意到，她家崽已经比隔壁版纳茶茶家的小崽们壮实了一圈。![Image](images/img_019.png)

![Image](images/img_020.jpg)

如今小水獭的游泳、捕猎、奔跑完全能跟上爸爸妈妈的行动节奏了。

![Image](images/img_021.jpg)

时常能看到一家三口一块儿出动。“噗通——”奔向水里游一阵，在水中追逐、捕食，各抓各的，然后一起从水里探出脑袋，叼着各自捕获的食物。

![Image](images/img_022.jpg)

吃完之后，一家三口又整整齐齐地、一个接一个地奔回岸上的沙滩，在沙地上打几个滚，让两层毛发里重新灌进空气，好让身体快点干。等身上干爽了，再一起回到巢箱或者找个阴凉地儿，安安心心地歇着。

![Image](images/img_023.jpg)

芭蕉还在长，

“澜沧江”的水声也还在响着，

韩信一家新的乐子也还在开发。

至于下一处是什么，

敬请期待...
