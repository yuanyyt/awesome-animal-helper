# 知道你很担心，但先给他一些空间~

不要![](images/img_001.png)![](images/img_002.png)![](images/img_003.png)![](images/img_004.png)![](images/img_005.png)![](images/img_006.png)![](images/img_007.png)![](images/img_008.png)

红山的猴山，

生活着70多只猕猴成员，

他们是一个大家庭。

![](images/img_009.jpg)

他们集体生活的群像，总在不经意间吸引着我们驻足观察，这里的每时每刻，都在发生着不一样的事情，有的在岩石间跳跃，有的在互相理毛，他们在栖架间翻筋斗，他们在山间追逐，还有几只则待在竹筏上，随水波轻轻晃动...

![](images/img_010.gif)

他们乘着竹筏游走在水流的缓冲地带，四处张望，上下检索，这种不确定的状态牵动着游客的思绪：

“他们从哪里来？他们想去哪里？

“他们是否拥有去岸上生活的自由？”

![](images/img_011.png)

**有强有弱，动态稳定**

猕猴是高度社会化的动物，他们的社群结构复杂而有序。在这个群体中，有着清晰的位序关系。猴王是社群的支配者，享有食物、休息地等多方面的优先权。而且猴王常翘着尾巴行走，那是地位的象征，其他猴儿则大多垂尾而行。

![](images/img_012.jpg)

猴王

猴王身边通常有几位得力的“副手”。他们各司其职：有的负责调解冲突，维护和谐；有的则善于处理与猴王的关系，懂得保持恰当距离。这一结构帮助整个群体在多数时间保持稳定。

![](images/img_013.png)

猴王与家庭成员们

但稳定并非永恒。每年秋季至来年春季的发情期期间，猴群内部常会爆发不同程度的争斗。这是年轻雄猴挑战猴王的自然阶段，也是社群更新的关键时期。

![](images/img_014.jpg)

在这场“王位”角逐中，胜者成为新首领，败者则可能离开群体，或选择服从、留在群中。目前猴山的猴王依然强壮，群体结构总体平稳，但暗中的实力变化始终在默默进行。

![](images/img_015.gif)

但也正是这样严谨的社群序位，让部分弱势猕猴选择避开核心群体的竞争，转而在水边开辟“新家园”，形成了大家眼中“水上活动的猕猴群体”，也是大家口中常说的“漕帮”（[猴山的故事就是一部武侠小说](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650732591&idx=1&sn=9b9719387693a98a52333ace2025736b&scene=21#wechat_redirect)）。

依托竹筏、水域的生活

**弱势者的水陆两栖**

“水上活动的猕猴群体”基本都掌握了一套水陆两栖模式：他们并非与岸隔绝，反而懂得“错峰出行”。当主群猴儿不在附近时，他们便会自由去岸上，活动、觅食、玩耍丰容设施，从容享受陆地上的时光，也借此巧妙避免冲突。

![](images/img_016.png)

饲养员们则“暗中观察”，必要时伸出“援”手。关系紧张时，饲养员会专门在水面及远离主山的岸边放置食物，保障他们的营养供给。因为日常还会进行竹筏技能锻炼，他们的身体素质也略胜一筹，“锻炼痕迹”肉眼可见。

![](images/img_017.gif)

只要猴王不再旁边，尾巴高高翘的漕帮成员

不同冲突时期的“双栖生活”给群体带来了稳定，漕帮生活的“游刃有余”也吸引了不少主群里的猴儿的好奇，也想体验体验。他们会趁“漕帮”成员不在时，跃上竹筏，随波漂荡，惬意享受水面上的宁静。这些竹筏，早已不仅是交通工具，更成了整座猴山共享的“水上玩具”，猴多筏少，抢手的时候不免引发一场争夺。

争夺中也实现了一种合作，他们有时轮番交替使用，自由往返两地。

**知道你很担心，但请先给予一些空间**

当然，无论生活在岸上还是水中，作为同一个社群的成员，摩擦与冲突依然在所难免。隔三差五，争执与打斗又起了...

饲养员观察到，猴儿的冲突很日常，有的是猴王争霸的激烈较量，有的是序位竞争的小摩擦，有的是在争夺交配权，实力较量是他们解决问题的一种方式，但这些打斗都有分寸，不会置对方于死地。

![](images/img_018.jpg)

有猴儿因为打斗受伤了，饲养员也都看在眼里，饲养员会先评估他们的伤势，小伤不用管，重伤需要持续关注。

猴群有着特殊的社群关系和结构，一旦让个体长时间离群（进行治疗），群体几乎很难再接受个体回归，个体只能接受“落单”的命运，这对群居动物而言，是十分残酷的福利剥夺。

所以，在猴儿受伤的情况下，饲养员始终遵循“尽量少干预”的原则，若伤势较轻，通常不会将其带离群体单独医治，以保持其与社群的正常联系。若伤势较重，则会及时介入、妥善处理并进行治疗，并及时将个体送回群体。群居动物的基本福利，就是和同伴生活在一起。

![](images/img_019.jpg)回归的过程通常不是一蹴而就，这时，竹筏区域也成了他们的缓冲地带和心灵加油站。他们将在自认为安全的环境里，一边养精蓄锐，一边与熟悉的同伴逐步重建联结，在群体的自然节奏中完成身心恢复。这就是大家有时会看到个别“带伤”、“带药（紫药水）”的猴儿在竹筏、水台在“风中凌乱”的原因。很多游客心疼、担忧，但请给他们一点时间，短暂的窘迫，是在等待群体的自然接纳。这就是猴群残酷又弹性的相处模式，知道大家很担心，也希望大家与我们一起：理解，尊重，祝福~![](images/img_020.gif)

好伙伴一起理毛

当然，回归后也可能再次发生冲突，群体就是在这样的动态平衡中不断调整。今日的和解，或许明日又因新挑战而波动。

去岸上吃个水果

除了自然的猴群内部冲突，投喂和逗弄也是打破这份平衡的隐形推手。这不仅会扰乱猴群原有的食物分配秩序，引发不必要的争斗，对于那些习惯自由穿梭于水岸之间的“漕帮”猕猴而言，更会干扰他们的自然行为模式。我们提醒，为了他们的健康、安全与自然天性，请勿投喂！
![](images/img_021.png)猴群中的打斗是自然的社会行为，是他们沟通、竞争与调节关系的方式，我们所能做的，是尊重他们的自然规律，让这个复杂而有序的猴群社会，按照自己的节奏运转下去。下次面对猴群的争斗，不知道你是否能有新的解读呢？
