# 杜杜：青团这小子，对你好吗？

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)

**是回忆录！更是埋下的伏笔！**

![Image](images/img_005.png)

大家还记得这两张区分白面僧面猴性别的对比图吗？

![Image](images/img_006.jpg)

两年前，花生那张稚嫩的小脸依偎在妈妈背上的样子，仿佛还在眼前。（[杜杜：我的心里除了花花还有...](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650828804&idx=1&sn=1b9fbeaaaa1ab8dc5c3318c308fdd179&scene=21#wechat_redirect)）然而，成长的脚步总是悄然无声，转眼间，曾经的她也到了该“离家”独立的时候了。

而她与他的相遇，

也变得一切有迹可循！

**长大啦，出发吧！**

![Image](images/img_007.png)

随着花生一天天长大，家庭也迎来了新成员。妈妈花花再次孕育，弟弟瓜子的降生，悄然改变了家庭互动的节奏。

![Image](images/img_008.png)

严父杜杜

爸爸杜杜对花生的态度，也从曾经的全然包容，逐渐转为一种看似“冰冷”的疏离他开始不再允许花生一同与他们取食。

这并非简单的排斥，而在许多灵长类家庭中，这正是父母引导亚成年子女走向独立的自然方式。

![Image](images/img_009.png)

为了确保花生在过渡期能获得足够营养，饲养员将食物分散放置在多个点位。这也让花生仍有机会靠近妈妈，观察和学习育幼的点点滴滴。然而，随着弟弟日渐活泼，家庭的重心无可避免地转移了。连一向包容她的妈妈花花，对花生的耐心似乎也在消减。

![Image](images/img_010.png)

瓜子：是在说我吗？

这一切清晰的信号都在说明：在父母的心里，花生已经完成了在原生家庭的学习阶段，是时候去开拓自己的天地了。

动物世界的“离群”时刻，深植于家族的本能与文化中。有的父母会明确“劝离”，有的则允许子女长久停留，但子女会主动疏离。而花生的情况属于前者，父母用行为告诉她，你已长大，足以独立。

![Image](images/img_011.png)

青团

巧的是，生活在别处的青团，也经历了相似的告别。两个年纪相仿、境遇相似的小家伙，仿佛被缘分一前一后走到了独立的同一个路口。

![Image](images/img_012.png)

比花生大两个月的青团

既然都要迈向成年，何不让这段转变的路途多一个同伴？让青团与花生汇合，让他们相互陪伴、彼此学习。

这会是怎样一段崭新的旅程？

两个陌生的少年，

将如何从相遇走向相熟？

请随我们一同观察。

**嘿，你也一个猴吗？**

![Image](images/img_013.png)

两个少年即将相遇，但在此之前，他们都需要先学会独立面对新的生活。

**青团的初来乍到**

11月18日，青团独自来到了红山。面对全然陌生的环境，他既谨慎又好奇。最初的几天，他连从饲养员手中接食物都不敢，只肯等人走远后，才迅速取走平台上留下的食物。

![Image](images/img_014.png)

但信任的建立，往往就藏在这些无声的日常里。饲养员日复一日地定点出现，动作舒缓，声音平静，手中的食物成为一种温和的邀请。

终于有一天，青团没有后退，从饲养员手中接过了食物。那一刻，不仅是食物完成了传递，一段基于安全感的联结也悄然建立。

![Image](images/img_015.png)

当他对室内环境渐渐熟悉，饲养员便开启了通往非展示外场的通道。随后几天，饲养员通过在定点训练，引导他在室内与户外之间自然往返，帮助他逐渐熟悉整个环境。

**花生：我长大了**

就在青团逐渐适应的时候，

隔壁的空间也已准备就绪。

11月23日，花生离开了父母和熟悉的家庭，迎来了她的独立。起初，没了爸爸妈妈的身影和声音陪伴，她有些分离焦虑。而另一边的父母杜杜和花花并未表现出不安，家庭日常如常进行。

![Image](images/img_016.png)

这或许正是动物父母一种深层的信任：他们相信孩子已经具备了独立的能力。

但很快花生就被隔壁偶尔传来的轻微动静吸引了注意。对面的青团也同样如此，他俩开始花更多时间在靠近隔网的地方活动，聆听、张望对面的彼此。花生的焦虑也随之烟消云散了。

![Image](images/img_017.png)

嘿，你也一个猴吗？

这时，饲养员没有急于让他们汇合。让青团和花生轮换空间，交替进入对方生活的区域，熟悉彼此留下的气味，让它们在安全距离内先“认识”对方。几天里，饲养员密切观察着他们的情绪和行为。

![Image](images/img_018.png)

当他们双方都表现的平稳而放松后，11月28日，饲养员打开了隔在他们中间的那扇门。

**搭个伴，一起长大吧！**

![Image](images/img_019.png)

随着隔门的缓缓打开，

一场无声的试探悄然开始。

首先行动的是青团，他最先踏入了花生的空间，甚至十分自然地拿起了花生的食物。花生则瞬间跳开，退到远处，睁大眼睛警惕地观察着这位“大胆”的访客，审视着对方的一举一动。

![Image](images/img_020.png)

然而，紧张的气氛并未持续。没过多久，好奇心似乎战胜了谨慎。花生开始一点点挪近，最终，两个小家伙肩并肩地吃了起来。他们偶尔会轻轻争抢对方手中的食物呢。

![Image](images/img_021.png)

餐后，青团回到了自己的区域。这个良好的开端，饲养员便开始将他们的“会面时间”从最初的2小时，有计划地逐步延长。

![Image](images/img_022.png)

在接下来的几天里，他们维持着一种礼貌而和谐的共处模式。同场活动，各自进食，互不打扰。

![Image](images/img_023.png)

直到第四天，突破出现了！他们开始互相靠近，并为对方梳理毛发。动作虽然还带着些许试探性的停顿和观察，但这无疑是一个重要的社交信号。

![Image](images/img_024.jpg)

在靠近一点点

这种试探对年龄相仿的新伙伴来说至关重要。轻微的追逐、暂时的驱赶，都是他们摸索彼此边界、建立相处规则的方式。

随着一天的活动结束，该返回内室时，熟悉环境的花生通常表现得更加从容果断，会率先听从饲养员的指令进去。

![Image](images/img_025.png)

而青团往往会在一旁观察一下，再跟着这位“小向导”分别回到自己的空间。一个微妙的伙伴关系，正在日常的细节中悄然萌芽。

随着彼此关系的不断升温，12月9日，饲养员开始让青团和花生第一次一起过夜。

![Image](images/img_026.png)

那一晚，起初他们还保持着小小的距离，各自睡在独立的巢箱里，但渐渐地，青团表现出更多的主动，他挪向花生所在的巢箱，一点点缩短间隔。没过多久，两个小家伙的身影终于依偎进了同一个巢箱，在静谧的夜色里安然入睡。

![Image](images/img_027.png)

白天，他们的互动也越来越轻松自然。互相理毛成了日常，青团甚至会把头凑近花生，想让花生分享手中的食物给他呢。

![Image](images/img_028.png)

拿到了花生分享的食物

信任，在悄悄生长。

**一起出发！成长继续...**

![Image](images/img_029.png)

然而，成长的下一步总是充满新挑战。1月9日，他们迎来了另一个时刻：与大家见面啦！

在前往新环境的路上，熟悉地形的花生在通道上一溜烟跑在前面，而不熟悉的青团却显得有些迟疑，跟了一会儿，脚步就渐渐慢了下来。

![Image](images/img_030.png)

等等你

而已经跑远的花生，发现青团没有跟上，立刻主动折返，跑到他跟前，当他的“领路猴”。就这样在饲养员的看护、引导和花生的陪伴下，青团终于顺利到达目的地的通道口。

![Image](images/img_031.gif)

面对开阔的新空间，花生一如既往地大胆，毫不犹豫地跃入其中探索起来。而青团则守在通道口，仔细地张望、观察，直到看见花生在其中自在活动的样子，才渐渐放松下来，轻盈一跳，加入了这场探索。

![Image](images/img_032.png)

如今，这两个小家伙已正式入住冈瓦纳展区，成为彼此生活中不可或缺的伙伴。如果你来看他们，可能会见到他们坐在高处互相理毛，也可能看见他们一前一后轻盈穿梭于栖架之间。

![Image](images/img_033.png)

从初识到相依，这段悄然生长的陪伴故事，正翻开崭新的一页。而接下来的篇章，不仅属于他们，也期待有你一同见证。

快来红山冈瓦纳室内展厅，
亲眼捕捉这对小猴的温暖瞬间吧～
