# 不一样的妈，但有一样的爱

![Image](images/img_001.png)![Image](images/img_002.png)![Image](images/img_003.png)![Image](images/img_004.png)

![Image](images/img_005.png)

还记得这篇文中（[人生，就是要充满power！](https://mp.weixin.qq.com/s?__biz=MjM5NDk1NDg5NA==&mid=2650856088&idx=1&sn=4d3422292e0f620956061568dd06bcad&scene=21#wechat_redirect)）的环尾狐猴一家嘛？经过群体重组，雌性“星星”、两个亚成体雄性“菀菀（wǎn）”和“眉眉”迎来了他们的新室友雄性“楚巴卡”和雌性“杜鹃”。

![Image](images/img_006.jpg)

日子一天天过去，这五只环尾狐猴渐渐褪去陌生，融合成一个稳定又温馨的小群落：他们一起在阳光下舒展身体，一起互相梳理毛发、增进情谊，一起穿梭在林间觅食嬉戏…

就在这份暖意正浓时，2026年开年，这个小家庭传来了双重喜讯！

![Image](images/img_007.jpg)

狐猴一家

经历130多天的孕期，两位雌性相继分娩。1月27日，新手妈妈杜鹃率先诞下幼崽杜仲；时隔半个多月，2月14日，经验丰富的星星也顺利生下了幼崽星辰。

**两位妈妈，两种节奏**

因育幼经验的不同，两位妈妈的表现也截然不同，一位跌跌撞撞、手忙脚乱，一位行云流水、从容不迫。

第一次当妈妈的杜鹃，这份初得幼崽的喜悦里，却藏着满满的慌乱。生产结束后，她便长时间蜷缩在巢箱深处，不肯轻易露面。饲养员也无法看清幼崽的具体情况，但生怕贸然打扰会惊扰到这对母子，只能耐下心来，给她足够的时间适应新身份。

![Image](images/img_008.jpg)

直到饲养员通过串笼的方式，引导整个环尾狐猴群体前往外场觅食，巢箱里安静了许久，杜鹃才终于鼓起勇气，颤颤巍巍地抱紧幼崽，从巢箱口小心翼翼地探出头来。但她出来的动作比平时慢很多，当其他环尾狐猴已经散落在取食点各处了，她才刚迈出两三步。

![Image](images/img_009.jpg)![Image](images/img_010.jpg)

等等，怎么都走了

更棘手的是抱崽的姿势。在环尾狐猴的正常育幼习惯中，母亲通常将幼崽抱在腹侧部，既能保证幼崽稳定地衔住乳头，又不会干扰母亲跳跃和攀爬时的平衡。

但杜鹃似乎还没找到窍门。她一个劲地用手把杜仲往身体中央扒拉，可杜仲总是滑到她的腿面上。杜鹃走几步，低头看看，杜仲往下坠了；她赶紧停下来，蹲坐下来，用整个身体把杜仲圈住，等一会儿再站起来，重新试着调整。

![Image](images/img_011.png)

抱着崽挑战丰容

虽然抱崽的动作生涩，杜鹃的母性行为却并不欠缺。她走一小段，坐下来，护住幼崽，舔一舔它的脸，再站起来走一小段，不厌其烦地重复着这套动作，直到她来到群体身边。之后的几天，杜鹃也逐渐掌握了如何抱崽。

![Image](images/img_012.jpg)

从容的星星

和杜鹃的手忙脚乱形成鲜明对比的，是熟手妈妈星星。对于已经不是第一次当妈妈的星星来说，全程松弛又娴熟，丝毫没有新手的慌乱。生下星辰后，星星依旧保持着自己的生活节奏，带着星辰在枝干间攀爬、跳跃。

![Image](images/img_013.jpg)![Image](images/img_014.jpg)

进食时，也会找一个安全的地方坐下，一边低头享用食物，一边轻轻梳理一下幼崽的毛发；休息时，她就蜷起身子，将星辰揽在怀里，让幼崽依偎在自己身边。可稍不留神，胆大亚成体狐猴菀菀竟公然抢夺星星的食物![Image](images/img_015.png)

![Image](images/img_016.png)![Image](images/img_017.png)

你为我做主！这对吗？

虽带娃方式不同，

但母爱是一样的！

**两个幼崽，一起长大**

幼崽的生长节奏，也在妈妈们日复一日的攀爬、跳跃与守护中，悄悄向前推进。

![Image](images/img_018.jpg)

爸爸楚巴卡路过

环尾狐猴本就是昼行性动物，白天活跃觅食，主要以树叶、花朵和果实为食。大约一个半月时，杜仲和星辰开始不再单纯依赖母乳，反而对妈妈口中的食物生出强烈好奇。

![Image](images/img_019.jpg)

让俺尝尝

每当星星、杜鹃低头啃食树叶、果实，两只幼崽就会凑到母亲嘴边，用小小的手试探着抢夺食物，或是轻轻舔舐母亲嘴角残留的残渣。不过此时，辅食还只是成长路上的点缀，幼崽所需的大部分营养依旧来自母乳。

![Image](images/img_020.jpg)

待到两个月大时，他们从妈妈的腹侧，慢慢转移到了母亲的背上。小家伙们稳稳地骑在妈妈的背上，随着母亲在树干间灵活攀爬、轻盈跳跃，视野变得愈发开阔，也开始主动伸出手，探索身边的环境。

就像星星觅食时，星辰会乖乖坐在她的背上，小脑袋不停地四处张望，时不时伸出爪子触碰身边的树叶，或是轻轻啃咬鲜嫩的枝丫，一点点尝试辅食的滋味。

“妈妈吃妈妈的，我吃我的”

渐渐地，两只幼崽不再满足于只在妈妈背上探索，开始勇敢地跳下妈妈的背，在妈妈周边的枝干上活动。

他们偶尔会在枝干间碰面，凑在一起轻轻触碰、互相嗅闻，随即跳开去寻找妈妈。随着胆量越来越大，他们停留在妈妈背上的时间越来越短，独自在枝干上探索的时间越来越长。

![Image](images/img_021.png)

他们会独自在附近的枝干上停留，会试探着跳到更远的落脚点，没把握时，就先用前肢去够前面的树枝，身体在摇摆中小心翼翼地寻找平衡。
