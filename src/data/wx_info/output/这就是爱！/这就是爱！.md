# 这就是爱！

爱是什么呢？我们一起来找找答案吧~

**与红山同行 第三期** 的故事

来自一篇被上万人看过的小红书

![Image](images/img_007.png)

江苏新闻相关报道

如今，那只曾经疲惫的小恐龙，带着全新的身份回到了这里——她成为了红山志愿者队伍中的一员，在红山的猩猩馆守护着猩猩们。

![Image](images/img_008.png)

鼓起勇气和百兽之王合影

这个性格外向，喜欢美食和短剧的地道南京姑娘——***跑岔气的小恐龙***，从被爱照亮，到成为光的一部分，她走了整整200个日夜。

-------------------------

![Image](images/img_009.png)![Image](images/img_010.png)

这座山，也是我的避风港

曾经有很长一段时间，我对红山的印象还固执地停留在十几年前。如果不是我的闺蜜，这种印象或许至今都不会改变。

那是一个清晨，工作像一张越收越紧的网，我卡在网中央，快要喘不过气。严重的内耗，让我每天回家都想崩溃大哭。白天要笑、要说话、要完成所有该做的事，到了晚上，那些被压抑的情绪像潮水一样涌回来。

闺蜜首先发现了我的不对劲，她并没有讲什么“你要振作”的大道理。那些道理我自己都明白，但情绪还是找不到出口。她只是在一个周末清晨，硬是把我从家里拖了出来，拉着我就走，给我办了一张年卡，陪我在十几年后再次走进红山。

![Image](images/img_011.jpg)

一开始，我对动物园并没有什么特别的感情，我想“这不就是看动物的地方吗？”。但是，谁能想到呢？就这那一次游园，我便一发不可收拾。

![Image](images/img_012.jpg)

之后，红山成了我每周雷打不动的“避风港”。只要休息，我一定在早上七点半就早早出现在排队的队伍中，连排队都让我雀跃不已。清晨的园中还没有那么多人，空气里是沉淀了一夜的草木香，阳光斜斜地打在树梢上。我不再追赶时间，不再焦急烦恼，只是慢悠悠地在园中散步。

![Image](images/img_013.png)

很多时候，我就坐在猩猩馆旁的长椅上发呆。看小黑、乐乐在树上静坐，我会想，它们会不会和我一样在思考呢？看小熊猫在树枝上小憩，看长颈鹿慢条斯理地卷起树叶。那种纯粹的、旺盛的生命力，成了我那段灰暗日子里唯一的彩色。

![Image](images/img_014.jpg)

我也慢慢开始了解那些动物朋友们，它们的名字、习性、故事。其中，我特别喜欢一只叫毛阿妹的红猩猩。她安静的时候像是在思考，活跃的时候又会做出让人捧腹的动作。我常常站在玻璃前看她，一看就是半个小时。

虽然每周只有这么一天，但就是这一天，支撑着我熬过了剩下的六天。

![Image](images/img_015.png)

来自四面八方的爱

今年生日前，我做了件特别“出格”的事——工作十年，我第一次为自己请了假，我想去红山过生日。我想把这一天完完整整地留给这个治愈了我的地方。

我把这个愿望发在了小红书上，我想，只是作为我的日常分享。可我没想到的是，这个愿望被整个世界温柔地回应了。

几千条陌生人的祝福，从网络的各个角落涌向我。那些“生日快乐”“要天天开心”，像暖流冲刷过我的心。

![Image](images/img_016.png)![Image](images/img_017.png)![Image](images/img_018.png)![Image](images/img_019.png)![Image](images/img_020.png)

来自五湖西海的祝福

我一遍一遍地向她们道谢，一遍一遍地回复着这些温暖的话语。在祝福与温暖中，我准备好了第二天去动物园的行程。

而最让我惊喜的是，万千网友的祝福也让红山动物园看见了我。生日那天，红山北门的大屏幕上，也为我亮起了一行生日祝福。

![Image](images/img_021.png)

虽然我从南门离开后才发现，但这份有回应的感动，也足够让我泪流满面。

在我人生最低谷的时候，是这座城市、这个动物园、这些素未谋面的陌生人，给了我一点光亮。虽然那光亮不大，但在这片黑暗里，足够让我看见前方，继续前行。

我想，我是不是也能做点什么？

![Image](images/img_022.png)

从被爱，到传播爱

机会来了！三月份，我在红山的公众号看到了志愿者招募的信息。几乎没有犹豫，我就报了名。

面试前一晚，我紧张得像个等待审判的孩子，辗转反侧，几乎一夜未眠。第二天清晨灌下两杯黑咖啡，心跳如擂鼓。

走进房间，说了什么，如何走出来，记忆全是模糊的。只记得离开时，心里还是有点失落的。“肯定不行了，明年再战吧。”，我只能这么安慰自己。

没想到的是，某一天，手机屏幕亮起：“恭喜你，面试通过。”我盯着那行字，在房间里又哭又笑。那种久违的、被肯定、被需要的感觉，让我觉得自己好像又活过来了。

第一次参加志愿者培训，彻底改变了我对动物园的认知。从前我只看到“动物”，现在，我看见了“生命”。红山教会我的，是关于生命尊重的一课。

![Image](images/img_023.jpg)

救助中心陈月龙老师 在为志愿者讲述雨蛙的故事

现在，我最幸福的事，就是在猩猩馆做志愿者，守护毛阿妹，守护红毛猩猩。我会给来访的游客讲红毛猩猩的故事，讲它们的习性，分享它们在红山的趣事。

![Image](images/img_024.jpg)

毛阿妹的“伸”出“猩”手

我也会劝阻不文明行为，呼吁大家保护动物的生存环境。我很喜欢红山的理念，很开心有机会为红山出一份力。

回头望去，是闺蜜不由分说拉我前行的手，是几千个陌生人汇聚成的星星点点的祝福之河，是北门大屏幕上为我亮起的那道祝福，也是毛阿妹、瑞妮，是红山的毛孩子们带来的治愈感。

![Image](images/img_025.jpg)

爱从来不是静止的。它是一颗被小心埋下的种子，在某个不起眼的时刻落入泥土，然后慢慢发芽。为了回馈这些爱，我也从“被红山治愈的游客”到“守护红山的志愿者”。

我感受到了爱，所以也想把爱分享给你们。欢迎来到红山，一起感受这里关于生命、关于爱的意义。

感谢这一路温暖的双向奔赴，也感谢小恐龙愿意把收获的爱分享出来。这份感动，我们会一直传递下去。
