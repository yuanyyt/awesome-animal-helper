# 你看我有几分“象”从前~

![Image](images/img_001.gif)

让犀牛的泥池变成一片生机盎然的湿地，**需要多久呢？**

2025年4月，随着南门新区的建设进入尾声，原本暂住在红山大象馆旁的南白犀一家也正式迁入了非洲草原的新家。犀牛离开了，却留下一道棘手的难题——**犀牛外运动场那片泥池，该何去何从？**

这块地可不太好伺候，地势低洼，排水不畅，一下雨就泥泞，天一晴就板结。要将这块泥地“改头换面”再利用可不是一件容易的事。

饲养团队经过多次勘察和讨论。最终决定：既然地势无法改变，那就顺势而为！利用犀牛留下来的肥沃泥土，将这里改造成大象和野生动物朋友共享的“生态湿地”。

![Image](images/img_002.png)

**就地取材，给泥泞大“整容”**

![Image](images/img_003.png)![Image](images/img_004.png)

**改造①**

为了最大限度地运用场地现有条件，减少改造的复杂程度。饲养团队用生石灰在原有地面上画出轮廓线，将场地划分为三个功能区。

![Image](images/img_005.gif)

地势高的干燥部分一部分做高地，铺设红土，为大象提供矿物质摄取点；另一部分铺设细沙供大象沙浴护肤；低洼的部分留作湿地核心，蓄水养植物。

划分好功能区之后，最重要的就是——将整块地翻土，打破犀牛常年踩踏形成的硬质泥壳，让土壤重新呼吸。

**改造②**

要让湿地活起来，水也是关键一环。所以，改造的第二点就是让水“愿意留下来”。

饲养团队沿着低洼处一圈圈地垒土，修筑田埂，把低洼区围成一个可以蓄水的盆地。而湿地又和大象馆的沟渠连通，这样既能够保留住雨水，又能将多余的水流向沟渠中。

![Image](images/img_006.gif)

在旱季来临时，场馆原有的设施——大象喷淋也在这片湿地中成为了湿地的“补水点”。在象来时，它是象的解暑设施，象不来时，它就是湿地的补水来源之一。

![Image](images/img_007.jpg)

这些利用既减轻了人工补水的复杂度，又能够灵活将从前“排水不畅”的缺陷，顺势变为“能存住水”的优势，最大程度地重新利用整个外场的资源。

**改造③**

原有泥地里的犀牛泥对植物来说可是好东西！犀牛在这里生活期间使用过的泥土是最好的天然肥料。

![Image](images/img_008.gif)

饲养团队将土地翻整过后，经查阅资料，团队筛选了兼具耐污能力强、根系发达能固土、大象也能采食的荸荠、茭白以及一些野菜，将它们一个个埋进泥泞中，其他部分则撒下黑麦草等植物的种子。

![Image](images/img_009.jpg)

为确保这片水域既是“食堂”又是“乐园”，饲养团队通过反复调试水位，确保水深既能淹没植物根茎，又能够让大象在其中自由活动，给它们一个更加自然的近水环境。

![Image](images/img_010.png)

**从“泥地”到生态模板**

![Image](images/img_011.png)![Image](images/img_012.png)

2025年夏末，这片湿地的裸露土面被黑麦草的嫩绿快速占领，而麦哥也作为这片湿地首位大型访客来到这里，他几乎立刻就爱上了这片“新”的区域。

新鲜的黑麦草嫩叶被那根灵巧的象鼻一卷一拔一甩，就成了户外活动间隙的美味加餐。

![Image](images/img_013.gif)

随着水质稳定，生命开始在此汇聚。饲养团队将两只草龟和一只池鳖放归在其中，仔细观察，池鳖白天大半截身子埋在湿沙里，只露个鼻孔，沙面上剩个逗号形的小气孔。

![Image](images/img_014.gif)

原住民黄鳝则利用了场地陡坡缝隙作为隐蔽所，成为这片湿地底层的沉默居民。

![Image](images/img_015.jpg)

那么水源也有了、植物也有了，在夏日生态的复苏下，泽陆蛙和黑斑蛙也在在此安家，在夜晚时分传出阵阵蛙鸣。

这片场地不再只是“犀牛的泥坑”，也不再只是“大象的旧址”——它是一个正在生长的小型湿地。大象是其中最大的使用者，但不是唯一的居住者。

![Image](images/img_016.jpg)

你能发现哪些野生动物朋友？

为了让植物喘口气，饲养团队也对大象在外场的使用做了弹性管理。只在每天的清晨让象来到这里自由活动，大象可以在这里自由采食、踏进淤泥中。

这样既让象能够享受这里，也让这片空间能够有充足的时间生长。

![Image](images/img_017.jpg)

一个个脚印中蓄满了水

又能够成为其他野生朋友的池塘

大象踩出的不规则凹坑也留在了这片湿地中，脚掌带起的泥浆在坑缘堆出天然堤坝，旁边就是刚刚冒头的植物嫩芽。这些痕迹成为各位野生访客的饮水点和住所，惠及各位野生动物朋友们～

![Image](images/img_018.png)

**让它再野一点**

![Image](images/img_019.png)![Image](images/img_020.png)

2026年早春，湿地迎来了第一年的维护升级——清除越冬枯萎茎叶，在湿地区靠内侧补种慈姑、茭白，以及一些喜阴的水生植物。

![Image](images/img_021.jpg)

饲养团队在春季播下新的植物

在园林部门的支持下，还引入了成丛的菖蒲，为小型鸟类提供了“能看见四周、又有身后遮挡”的安全感，让鸟儿可以放心在此沐沙浴、梳羽、短暂停留采食。

![Image](images/img_022.gif)

湿地成为了鸟儿们的澡堂~

如果你来到这里待上一会，你也可以观察一下，你是否能在这片湿地周边和菖蒲丛中看到这些画面：白腰文鸟取食草籽、在叶片中跳跃穿梭；麻雀在沙地边缘休憩、翻动沙地；丝光椋鸟在树桩上停歇、在湿地边饮水；乌鸫在草丛间探索、在水中沐浴等。

除了鸟儿的临时光顾，这里还发生着许多的自然小故事，比如新来的绿头鸭带着自己的伴侣来到这里歇息....

![Image](images/img_023.gif)

这些鸟儿们也是红山的野生居民，做这一片湿地，不仅仅是为了让这块地能利用起来，也是为这些蛙、鸟儿提供了一处新的停驻、栖息之所，让它们在这里也能多一个选择。

在这次湿地的改造之中，饲养团队灵活地运用了场地中所有的资源，犀牛留下的厚实粪土成了最肥沃的养料，为大象而设计的喷淋成了湿地的水源，让原本的外运动场成为大象新的福利丰容、泥地变成野生动物朋友的乐园......

如果你来红山，不如在这里停留一会儿，瞧一瞧，原来是一片泥地的它，是如何在变化之间、一步步长成如今这般肆意生长的模样。而绿意之下，藏着太多悄悄发生的故事，正等着你去一一发现～
