# 东北虎

- 场馆：[[虎]]
- 学名：*Panthera tigris altaica*
- 文中昵称：丹丹、图图、奇妙、咖啡、大山

## 趣事

1. 东北虎丹丹踏着沉稳的步子走进紫堇花海。 [[来源1]]
   - 正文依据：东北虎丹丹踏着沉稳的步子走来，带着整座山林的威严，闯入了这片温柔的紫堇梦境。
2. 冬天饲养员在干水池铺满落叶，图图和奇妙会依偎在一起睡觉并互相蹭脑袋。 [[来源2]]
   - 正文依据：在冬天，饲养员会在放干水的水池里铺满厚厚的落叶，奇妙和图图就会依偎在一起睡觉，偶尔互相蹭蹭脑袋，画面温馨。
3. 图图因适应性强被选为搬迁对象，以便未来与雄虎大山进行适应性训练。 [[来源2]]
   - 正文依据：经过长期观察，饲养员发现图图的适应性更强，胆子更大，也是行为训练经验丰富的优等生。
4. 奇妙独居后食欲变好，开始在场馆内到处嗅探并尝试爬上高处。 [[来源2]]
   - 正文依据：最明显的是，她的食欲变好了。食欲变好后，饲养员开始考虑，要不要再给奇妙多尝试一点环境丰容呢？
5. 饲养员更换天猫通道垫材并铺设长颈鹿用过的稻草以辅助奇妙克服恐惧。 [[来源2]]
   - 正文依据：首先，饲养团队更换了天猫通道地面上下坡的垫材，换成更防滑的木板，还在通道中铺了一层老虎们喜欢的长颈鹿用过的稻草
