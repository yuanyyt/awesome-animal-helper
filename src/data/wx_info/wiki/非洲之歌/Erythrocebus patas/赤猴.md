# 赤猴

- 场馆：[[非洲之歌]]
- 学名：*Erythrocebus patas*
- 文中昵称：常乐、常喜、乐佩、乐仔、常笑、笑仔、女王

## 趣事

1. 赤猴能在场馆设计的专用网通道中自由活动和通行。 [[来源1]]
   - 正文依据：比如这个就是“非洲之歌”展区通道里的赤猴，它们在里面活动是完全没有问题的。
2. 幼崽乐佩出生约一月龄时，因睡觉姿势夸张（头向后倒栽）被饲养员误以为有危险，实则是睡得太沉。 [[来源2]]
   - 正文依据：在一次突如其来的降温天...乐佩头深深地向后倒栽着，角度夸张到有些让人担心...才发现原来小家伙只是睡得太沉了，睡得没了睡相~
3. 赤猴幼崽成长极快，乐佩在5个月内从依赖母亲的毛球成长为能自信攀爬、跳跃的个体。 [[来源2]]
   - 正文依据：可这才过去短短5个月呀！...当初那个曾在妈妈怀里歪头大睡的小毛球，早已从容应对独立自主的生活。
4. 面对家中新成员出生导致母亲关爱转移，乐佩并未焦虑，而是主动与家族中其他成员建立社交联系。 [[来源2]]
   - 正文依据：面对家庭成员的关爱转移，它没有表现出任何失落或焦虑，反而自然而然地，花了更多时间与家族中的另一位年长的母亲常笑...待在一起。
5. 赤猴与环尾狐猴群居时会紧密挤在一起抱团取暖，强化社群联系。 [[来源3]]
   - 正文依据：赤猴、环尾狐猴等群居灵长类动物，则将“抱团取暖”的社交本能发挥到极致。它们会紧密地挤在一起，互相依偎，共享温暖，更通过身体接触强化了社群间联系。
6. 被拥在其中的赤猴被称为“女王”。 [[来源3]]
   - 正文依据：被拥在其中的赤猴“女王”
