# 鸬鹚

- 场馆：[[高黎贡]]
- 学名：*Phalacrocorax carbo*

## 趣事

1. 普通鸬鹚进入繁殖期时，头部会长出标志性的白色头羽，俗称“白头发”。 [[来源1]]
   - 正文依据：这就是普通鸬鹚们进入繁殖期最标志性的繁殖羽。除了漂亮的白色头羽
2. 救护中心的第一窝小鸬鹚已顺利长大并被父母赶出巢穴，以便亲鸟孵育下一窝幼崽。 [[来源1]]
   - 正文依据：生活在救护中心的第一窝小鸬鹚已经顺利长大，被爸妈“赶”出了巢，准备孵育下一窝小鸬鹚啦~
3. 在笼舍内由亲鸟抚养长大的普通鸬鹚，放归野外后行为正常且具备生存能力。 [[来源2]]
   - 正文依据：即便是这样情况的一对亲鸟，它们在笼舍内繁殖养育的幼鸟，在回到野外之后竟然能行为正常且有生存能力
4. 戴有追踪设备的鸬鹚被动物园工作人员展示为戴着“小书包”。 [[来源2]]
   - 正文依据：戴着“小书包”的鸬鹚
