# 白鹇

- 场馆：[[高黎贡]]
- 学名：*Lophura nycthemera*

## 趣事

1. 雄性白鹇在春季求偶期会长出高耸的冠羽，脸颊两侧的肉垂变大变鲜艳并向中间靠拢。 [[来源1]]
   - 正文依据：雄性白鹇也在春季求偶期早早地就“梳”起了比平时更加高耸俏丽的“高马尾”~而且，雄性白鹇脸颊两侧的肉垂会变得更大、更鲜艳
2. 雌性白鹇全身橄榄褐色，带有白色波浪状斑纹，保持低调以利于隐蔽。 [[来源1]]
   - 正文依据：雌性白鹇则一身橄榄褐色，带着白色波浪状的斑纹，依然保持低调。
