# 小熊猫

- 场馆：[[高黎贡]]
- 学名：*Ailurus*
- 文中昵称：仲夏、孟夏

## 趣事

1. 小熊猫在二月蓝铺成的紫色花毯上慢悠悠行走，远看像一团移动的焦糖色毛球。 [[来源1]]
   - 正文依据：小熊猫踩着二月蓝铺成的紫色绒毯，步子慢悠悠的。远远望去，就像一团会移动的焦糖色毛球
2. 双胞胎幼崽仲夏和孟夏在室内时曾调皮地爬到妈妈背上“骑大马”。 [[来源2]]
   - 正文依据：甚至调皮地爬到妈妈背上“骑大马”。夏娃妈妈也总是好脾气地待在她视线所及的地方，默默守护，包容着他们。
3. 两只小熊猫在雪中尽情撒欢，在蓬松的雪地里翻滚、追逐，并爬上树枝抖落雪花。 [[来源2]]
   - 正文依据：他们在蓬松的雪地里翻滚、追逐，爬上小树枝抖落一阵阵雪花。在漫天的大雪里尽情撒欢，释放着自己的天性和快乐~
4. 哥哥仲夏曾因体型较小体重落后，饲养员通过按体重补奶和调整喂养策略帮助其追赶。 [[来源2]]
   - 正文依据：将本应是按照年龄提供喂食量的方式，改为按照体重提供喂食量，每天额外给它们人工补奶；同时调整喂养时间，密切观察两只幼崽的个体需求。
