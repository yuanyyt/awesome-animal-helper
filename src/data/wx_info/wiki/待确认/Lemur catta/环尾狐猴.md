# 环尾狐猴

- 场馆：[[待确认]]
- 学名：*Lemur catta*
- 文中昵称：莉莉、coco

## 趣事

1. 环尾狐猴幼崽coco出生时体重不足100g，饲养员通过人工育幼和精细护理，使其在两个月内体重增长至160克。 [[来源1]]
   - 正文依据：Coco也一天天地长大，体重从四月初的不足100克，增长到五月中旬的160克！
2. 饲养员为帮助幼崽coco发育标志性的“梳齿”，特意提供了咬胶作为成长辅助工具。 [[来源1]]
   - 正文依据：饲养员还给coco找到了一个秘密武器——咬胶，来帮助coco在成长初期中发育环尾狐猴标志性的“梳齿”
3. 红山动物园曾为狐猴提供包含五十多种蔬果的丰富食谱，但因强势个体抢食导致弱势个体营养不良，且高糖水果引发粪便异常和肥胖。 [[来源2]]
   - 正文依据：从最初每天十几种蔬菜水果，逐渐增加到最多的时候，每天能够提供五十多种蔬菜和水果。
4. 为解决争食和健康问题，红山将狐猴食谱简化为每餐仅一种食物，并将水果改为行为训练奖励，显著减少了打架并提高了动物配合度。 [[来源2]]
   - 正文依据：一天四餐，每一餐只有一个品种。...我们把水果变成了奖励。结果发现，动物的配合度变得更高了
5. 初到新环境时，环尾狐猴表现得非常谨慎，集体进入观察模式，睁大眼睛远远关注新邻居褐美狐猴的一举一动。 [[来源3]]
   - 正文依据：环尾狐猴们则集体进入了“谨慎观察”模式，睁大圆溜溜的眼睛，远远关注着这些新邻居的一举一动。
6. 在进食时，环尾狐猴十分警惕，一旦褐美狐猴靠近平台就会跳开等待，以免发生冲突或吃到剩食。 [[来源3]]
   - 正文依据：只要褐美狐猴来到平台上进食，环尾狐猴就会跳开或在附近等着，这样一来轮到环尾再上前采食时往往只能吃到一些被挑剩下的食物。
7. 经过饲养员调整喂食方式后，环尾狐猴开始在地面和低矮栖架上活动，悠闲地享受日光浴。 [[来源3]]
   - 正文依据：环尾狐猴更多地在地面和低矮的栖架上活动，悠闲地享受日光浴。
