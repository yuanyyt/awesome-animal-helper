# 猞猁

- 场馆：[[中国猫科]]
- 学名：*Lynx lynx*
- 文中昵称：大王、Kitty

## 趣事

1. 猞猁走入二月蓝花海探寻香气，身影被阳光镀上金边。 [[来源1]]
   - 正文依据：猞猁走入这片梦幻般的二月蓝花海，像是在探寻春天最隐秘的香气。阳光穿过林间，为它的身影镀上一层金边
2. 猞猁大王通过悬挂式食物丰容盒锻炼，体重从31.4kg降至27.2kg，跳跃能力恢复。 [[来源2]]
   - 正文依据：现在的他不仅能轻松跳上更高的平台，活动时身姿也重新变得轻盈矫健，体重更是从31.4kg降到了二字头——27.2kg。
3. 猞猁大王曾因为肥胖气喘吁吁，连不高平台都需踮脚才能爬上去。 [[来源2]]
   - 正文依据：此前大王体重飙升时，出户外展区巡场一圈就气喘吁吁；一个不算高的平台，他都没法直接跳上去，得先找个踮脚的地方才能爬上去。
4. 经过长期脱敏与正向训练，名为“大王”的猞猁会主动将前肢伸入采血架配合静脉采血。 [[来源3]]
   - 正文依据：“大王”主动配合采血
同时，针对静脉采血，饲养员专门为它们定制了采血架。通过长期循序渐进的脱敏与正向训练，猞猁会主动将前肢伸入采血架
5. 名为“Kitty”的猞猁能按照指令到指定位置，全程安稳地完成X光拍摄检查。 [[来源3]]
   - 正文依据：“Kitty”配合X光检查
就连面对X光拍摄，它们也按照饲养员的指令到指定位置，全程安稳的完成检查。
6. 在繁育期照料中，母猞猁能在近距离隔网为幼崽称重时保持全程平静，不干扰工作人员。 [[来源3]]
   - 正文依据：最能体现彼此默契的，当属繁育期的照料工作。即便近距离隔网为猞猁幼崽称重，母猞猁也全程平静，不会上前干扰。
7. 猞猁能在完全清醒的状态下配合腹部B超检查，用于孕期监测与内脏健康评估。 [[来源3]]
   - 正文依据：不止如此，园区的猞猁还能在完全清醒的状态下配合腹部B超检查，方便工作人员开展孕期监测与日常内脏健康评估。
