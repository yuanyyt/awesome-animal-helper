# 豹

- 场馆：[[中国猫科]]
- 学名：*Panthera pardus*
- 文中昵称：憨憨、越越

## 趣事

1. 饲养员通过响片训练教憨憨服药，即使药囊破裂尝到苦味，它仍凭信任将药物咽下。 [[来源1]]
   - 正文依据：可他犹豫了一下，还是凭着对饲养员的那份信任，依旧将食物完整咽了下去。
2. 因疑似糖尿病导致体重从50公斤滑落至42公斤，且出现多饮多食多尿症状。 [[来源1]]
   - 正文依据：明明吃得比之前还多，体重却不增反降，从50公斤滑落到了42公斤。
3. 猫科馆山洞设有加热板，冬暖夏凉吸引豹子常驻以便游客近距离观察。 [[来源2]]
   - 正文依据：比如我们在猫科馆做了一个山洞，里面设置了一些加热板，冬天的时候可以很舒适，夏天的时候也很阴凉，豹子就会倾向于出现在这个地方。
4. 豹子在油菜花丛里慵懒伸懒腰，享受春日午后的花香与阳光。 [[来源3]]
   - 正文依据：当大家都在大快朵颐时，豹子越越却在油菜花丛里慵懒地伸着懒腰，享受着春日午后的花香与阳光
