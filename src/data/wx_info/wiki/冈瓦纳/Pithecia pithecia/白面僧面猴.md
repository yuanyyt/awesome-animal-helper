# 白面僧面猴

- 场馆：[[冈瓦纳]]
- 学名：*Pithecia pithecia*
- 文中昵称：瓜子、杜杜、花花、花生、青团

## 趣事

1. 雄性幼崽出生时脸部周围毛囊即显白色，约两个月大后白毛环绕脸部特征变得鲜明。 [[来源1]]
   - 正文依据：一个最显著的特征就是雄性幼崽出生时，脸部周围的毛囊会显示出白色的迹象。大约是两个月大后，幼崽的毛发开始全面生长，这一特征将变得更加鲜明。
2. 断奶期间母亲引导觅食并分享食物，但在迎来新宝宝后，幼崽学会等待父母取食结束后才拿剩余食物。 [[来源1]]
   - 正文依据：在断奶的过程中，妈妈花花开始引导他接触辅食。真正的转折点，发生在妈妈花花迎来下一个宝宝之后。从那天起，瓜子仿佛一夜之间长大了。他不再从爸爸妈妈嘴里直接要食物，而
3. 幼崽成长过程中逐渐独立，从紧紧依附母亲身体变为在栖架间自主跳跃，并主动寻找父亲玩耍。 [[来源1]]
   - 正文依据：不过，随着时间推移，瓜子不再老待在妈妈身上了。他开始尝试在妈妈周围活动，爬上爬下。他更喜欢找爸爸“杜杜”玩，一会儿跳起来挡在杜杜上方的树枝上，一会儿猛地窜到杜杜
4. 白面僧面猴面对二月兰、雪柳、海棠和桃花等多种春花，表现出选择困难。 [[来源2]]
   - 正文依据：白面僧面猴花生的选择困难症可能要犯了，饲养员给它摆了好几样春花：紫色的二月兰、雪白的雪柳、粉嫩的海棠和桃花。
5. 饲养员通过分散放置食物，引导亚成年个体花生在父母疏离后仍有机会靠近妈妈学习育幼。 [[来源3]]
   - 正文依据：为了确保花生在过渡期能获得足够营养，饲养员将食物分散放置在多个点位。
6. 初到红山的青团起初不敢从饲养员手中接食，只敢等人走远后取走平台上的食物，后来才建立信任。 [[来源3]]
   - 正文依据：最初的几天，他连从饲养员手中接食物都不敢，只肯等人走远后，才迅速取走平台上留下的食物。
7. 青团与花生汇合初期，青团大胆拿走花生的食物，花生跳开警惕观察，随后好奇战胜谨慎并肩进食。 [[来源3]]
   - 正文依据：首先行动的是青团，他最先踏入了花生的空间，甚至十分自然地拿起了花生的食物。花生则瞬间跳开...
8. 12月9日两只猴子首次一起过夜，从保持距离睡在独立巢箱逐渐依偎进同一个巢箱入睡。 [[来源3]]
   - 正文依据：没过多久，两个小家伙的身影终于依偎进了同一个巢箱，在静谧的夜色里安然入睡。
