# 美洲红鹮

- 场馆：[[冈瓦纳]]
- 学名：*Eudocimus ruber*

## 趣事

1. 幼鸟出生时全身覆盖黑色绒毛，与父母鲜艳的红色羽毛截然不同，这种深色伪装有助于融入阴影躲避天敌。 [[来源1]]
   - 正文依据：第一只雏鸟顶破了蛋壳，浑身裹着黑绒般的胎毛，与父母艳红的羽色截然不同。这暗沉的伪装恰是大自然给到的天然保护色，深色绒毛能完美融入阴影处，大大降低被天敌发现的概率
2. 亲鸟采用反刍方式喂食，雏鸟需将喙伸入亲鸟口腔内，摄取经过初步消化的半流质食物。 [[来源1]]
   - 正文依据：亲鸟不会直接将食物送入雏鸟口中，而是由雏鸟主动将细长的喙伸进亲鸟口腔内部，亲鸟再将提前摄入、经过初步消化的半流质食物反刍出来，供给雏鸟进食。
3. 幼鸟离巢后无法直接飞回高处巢穴，它们会顺着树干一边振翅一边跳跃，缓慢爬回巢穴休息。 [[来源1]]
   - 正文依据：只见，他们顺着带有坡度的树干，一边轻轻振翅，一边缓步跳跃，一点点慢慢回到自己的巢穴旁休憩。
4. 幼鸟羽色从灰黑转为鲜红需要一年多时间，经历灰黑、黑褐、淡红最终沉淀为鲜红。 [[来源1]]
   - 正文依据：红鹮羽色由灰黑转为绯红，更是一场漫长而无声的蜕变，从灰黑到黑褐，再渐渐透出淡红，最终沉淀为鲜红，整个过程需要一年多的时间才能完成。
5. 美洲红鹮在繁殖期雌雄个体的鸟喙颜色均由粉红色变为黑色，繁殖季后黑色角质脱落恢复粉色。 [[来源2]]
   - 正文依据：美洲红鹮到了繁殖期，雌性和雄性鸟喙的颜色就会由粉红色变成黑色。这是一个动态的变化过程。
6. 美洲红鹮雏鸟本是灰黑色，因食物中的虾青素羽毛慢慢过渡到红色。 [[来源3]]
   - 正文依据：可它们的雏鸟却是灰黑色的。不过，变红这件事急不得！红色来自食物中的虾青素...羽毛才会慢慢从黑灰色过渡到红色。
