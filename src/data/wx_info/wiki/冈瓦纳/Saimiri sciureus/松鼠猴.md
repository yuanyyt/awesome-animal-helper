# 松鼠猴

- 场馆：[[冈瓦纳]]
- 学名：*Saimiri sciureus*
- 文中昵称：长尾、三藏、牛奶、牛得花、牛得堡

## 趣事

1. 松鼠猴在花间像紫色探险家一样上蹿下跳。 [[来源1]]
   - 正文依据：松鼠猴像是花间上蹿下跳的“紫色探险家”，而刺豚鼠是花下埋头干饭的“佛系干饭人”。
2. 松鼠猴随机抓取二月兰叶子、海棠花和雪柳枝条挑选进食。 [[来源2]]
   - 正文依据：松鼠猴的吃法很随机。抓一把二月兰的叶子，又去揪几朵海棠花，中间还抽空抓了一枝雪柳，挑选得津津有味~
3. 松鼠猴妈妈背着幼崽在树冠层间穿梭，幼崽像书包一样紧贴妈妈背部，仅在哺乳时爬到怀中。 [[来源3]]
   - 正文依据：她背着宝宝在高高的树冠层间灵活穿梭，牛得堡就像一个量身定制的小小“书包”，紧紧贴在妈妈的背上
4. 松鼠猴被镜面取食盒反射的影像吸引，对着镜像驻足打量并歪头思考，忘记了盒内的食物。 [[来源3]]
   - 正文依据：注意力全被玻璃反射出的影像吸引，一会儿跳上盒子仔细观察，一会儿对着“对面的身影”驻足打量
