# 棉顶狨

- 场馆：[[冈瓦纳]]
- 学名：*Saguinus oedipus*
- 文中昵称：康康、牙牙、欢欢、夫人

## 趣事

1. 饲养员通过逐步拉大空间距离的方式帮助康康适应独立生活，期间父母与康康会隔着格网互相梳理毛发或发出叫声传递信号。 [[来源1]]
   - 正文依据：等康康对新空间完全适应后，饲养员才将中间的通道用格网隔断...甚至还能隔着格网互相梳理毛发。
2. 在相亲过程中，雌性“夫人”主动进入康康的空间并留下气味标记，康康从最初的警惕退避到后来放下戒备与夫人互相理毛、玩耍。 [[来源1]]
   - 正文依据：夫人倒是毫不认生...还在他的栖架上留下了自己的气味标记...康康没有躲避，就这样两只小狨猴顺利贴在了一起。
3. 体型娇小的棉顶狨穿梭于较大的山茶花和海棠花瓣间，品尝春天的甜蜜。 [[来源2]]
   - 正文依据：普通狨体型娇小，但饲养员准备的鲜艳山茶花和海棠可不小，但这并不妨碍它们探索的热情，在花瓣间穿梭，品尝着春天的甜蜜。
4. 饲养员用棕榈叶编织仿真蚂蚱进行丰容，小狨猴们被晃动的玩具吸引，纷纷拍打、嗅闻甚至啃咬，啃咬坚韧的棕榈叶起到了天然洁牙的作用。 [[来源3]]
   - 正文依据：还有的直接抱着棕榈蚂蚱啃了起来，原生态的棕榈叶质地坚韧，啃咬的过程恰好能摩擦牙齿，起到了天然洁牙的效果。
5. 小狨猴通过观察和互动探索悬挂的竹筒藏宝洞，利用爪子扒拉或牙齿啃咬孔洞来解锁隐藏其中的水果，展现了丰富的取食技巧。 [[来源3]]
   - 正文依据：有的则把脑袋凑近竹筒口，透过缝隙努力观察内部的食物位置，再用爪子扒拉、牙齿啃咬，去“解锁”这份隐藏美食。
