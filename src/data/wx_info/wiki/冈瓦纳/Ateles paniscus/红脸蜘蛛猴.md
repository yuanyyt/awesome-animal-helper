# 红脸蜘蛛猴

- 场馆：[[冈瓦纳]]
- 学名：*Ateles paniscus*
- 文中昵称：红阳、红阳崽崽、红红

## 趣事

1. 刚出生的红阳通体乌黑，与母亲深黑毛发颜色几乎一致，紧紧贴在妈妈身上时难以被察觉。 [[来源1]]
   - 正文依据：它通体乌黑，和妈妈红红的深黑毛发几乎无缝衔接，一直紧紧贴在红红的臂弯与胸腹间吮吸乳汁，身形和母体贴得极近
2. 幼崽出生时尾巴无绒毛且皮肤光亮，会用尾巴像“第五只手”一样缠绕在妈妈身体不同部位以固定自身。 [[来源1]]
   - 正文依据：凑近看，刚出生的它脑袋圆滚滚的，尾巴上没有绒毛，皮肤乌黑又光亮...它会像“第五只手”一样，一会儿牢牢缠绕在妈妈的尾巴根部、一会儿绕在腰间
3. 红脸蜘蛛猴家族没有群居育幼行为，新生命诞生后家族成员默契地互不干扰，为新手妈妈提供安静空间。 [[来源1]]
   - 正文依据：与川金丝猴“全群育幼”的热闹不同，红脸蜘蛛猴没有“阿姨帮忙带娃”的行为。自红阳出生起，整个家族便默契地选择了另一种温柔：互不干扰
4. 新手妈妈红红护崽属性强，行动变得缓慢稳重，觅食时会主动避开群体争抢，独自取食。 [[来源1]]
   - 正文依据：第一次当妈妈的红红，护崽属性直接拉满。从红阳出生那一刻起，便开启了“全天候警戒模式”。...不再挤在群体中争抢，而是主动避开热闹，安静地独自取食
5. 红脸蜘蛛猴妈妈怀里的红阳崽崽伸出小手想跟妈妈共享一根柳枝。 [[来源2]]
   - 正文依据：连在妈妈怀里的红阳崽崽都伸出了小手，想跟妈妈共享一根柳枝~
6. 红脸蜘蛛猴与松鼠猴跨物种亲密共存，允许松鼠猴爬上爬下、坐在头上吃东西而不驱赶。 [[来源3]]
   - 正文依据：脾气温和的红红从不会驱赶，只是静静地任由这个小家伙在自己身上撒欢
7. 红脸蜘蛛猴遇到透明亚克力取食盒掉落时，不按常理出牌，直接掀开盒面享用美食。 [[来源3]]
   - 正文依据：反而在摸索中直接掀开了一个面，径直享用起里面的美食
