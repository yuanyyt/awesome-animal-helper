# 环尾狐猴

- 场馆：[[冈瓦纳]]
- 学名：*Lemur catta*
- 文中昵称：星星、菀菀、眉眉、楚巴卡、杜鹃、杜仲、星辰

## 趣事

1. 新手妈妈杜鹃抱崽姿势生涩，幼崽杜仲总是滑到腿面，她只能蹲坐用身体圈住幼崽并反复调整。 [[来源1]]
   - 正文依据：可杜仲总是滑到她的腿面上。杜鹃走几步，低头看看，杜仲往下坠了；她赶紧停下来，蹲坐下来，用整个身体把杜仲圈住，等一会儿再站起来，重新试着调整。
2. 亚成体雄性菀菀胆大，曾公然抢夺熟手妈妈星星的食物。 [[来源1]]
   - 正文依据：可稍不留神，胆大亚成体狐猴菀菀竟公然抢夺星星的食物
3. 约一个半月大的幼崽会对母亲口中的食物产生好奇，凑到嘴边舔舐残渣或试探性抢夺辅食。 [[来源1]]
   - 正文依据：两只幼崽就会凑到母亲嘴边，用小小的手试探着抢夺食物，或是轻轻舔舐母亲嘴角残留的残渣。
4. 环尾狐猴在室外可选择在集成小太阳的巢箱里抱团休息度过温暖午后。 [[来源2]]
   - 正文依据：在室外运动场时，她们可以选择自由活动、张开双臂追寻太阳的温暖，也可以选择在巢箱里抱团休息，度过一个温暖的午后。
5. 环尾狐猴在室内依靠恒温空调提供舒适环境安心入眠。 [[来源2]]
   - 正文依据：在室内，恒温的空调则是提供舒适的环境，让他们能够安心入眠~
6. 环尾狐猴用前爪握住带花枝条，从顶端一朵朵咬下绣线菊品尝。 [[来源3]]
   - 正文依据：它们各自找了一根枝条，用前爪稳稳握住，从最顶端的花开始，一朵一朵咬下来，嚼几下，再咬下一朵。
7. 环尾狐猴一家蹲在树上啃食新冒尖的树芽。 [[来源3]]
   - 正文依据：环尾狐猴一家子蹲坐在树上，啃起了刚刚冒尖的树芽。
