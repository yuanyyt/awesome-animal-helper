# 亚洲象

- 场馆：[[象]]
- 学名：*Elephas maximus*
- 文中昵称：麦哥

## 趣事

1. 大象麦哥来到新湿地后，用灵巧的象鼻卷起新鲜的黑麦草嫩叶作为加餐。 [[来源1]]
   - 正文依据：而麦哥也作为这片湿地首位大型访客来到这里，他几乎立刻就爱上了这片“新”的区域。新鲜的黑麦草嫩叶被那根灵巧的象鼻一卷一拔一甩，就成了户外活动间隙的美味加餐。
2. 大象踩出的不规则凹坑蓄满水后，成为其他野生动物的饮水点和住所。 [[来源1]]
   - 正文依据：大象踩出的不规则凹坑也留在了这片湿地中，脚掌带起的泥浆在坑缘堆出天然堤坝，旁边就是刚刚冒头的植物嫩芽。这些痕迹成为各位野生访客的饮水点和住所，惠及各位野生动物朋
3. 大象的粪便被收集并转化为肥料，用于种植植物以反哺动物食物链。 [[来源2]]
   - 正文依据：大象的便便竟没有浪费，而是变身“热门便签本”！
4. 通过密闭式动植物废弃物发酵罐，形成动物吃植物、便便变肥料、肥料种植物、植物喂动物的闭环。 [[来源2]]
   - 正文依据：更有一套“便便黑科技”闭环：动物吃植物→便便变肥料→肥料种植物→植物喂动物。
