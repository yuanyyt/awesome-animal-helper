# 猕猴

- 场馆：[[猕猴世界]]
- 学名：*Macaca*
- 文中昵称：漕帮、水上活动的猕猴群体

## 趣事

1. 猴山改造中设置水隔离带，成为猴子日常丰容区域，诞生了“漂流的猴子”传说。 [[来源1]]
   - 正文依据：这道水隔离不仅可以延缓猴子起跳的距离，同时也可以作为猴子日常丰容的区域。可能传说中的那个漂流的猴子，就是从这开始的。
2. 部分弱势猕猴选择在水边开辟新家园，依托竹筏和水域生活，形成被称为“漕帮”的群体。 [[来源2]]
   - 正文依据：让部分弱势猕猴选择避开核心群体的竞争，转而在水边开辟“新家园”，形成了大家眼中“水上活动的猕猴群体”，也是大家口中常说的“漕帮”
3. 这些猕猴掌握水陆两栖模式，懂得错峰出行，当主群不在时便去岸上活动以巧妙避免冲突。 [[来源2]]
   - 正文依据：他们并非与岸隔绝，反而懂得“错峰出行”。当主群猴儿不在附近时，他们便会自由去岸上，活动、觅食、玩耍丰容设施
4. 饲养员会专门在水面及远离主山的岸边放置食物，保障他们的营养供给。 [[来源2]]
   - 正文依据：关系紧张时，饲养员会专门在水面及远离主山的岸边放置食物，保障他们的营养供给
5. 受伤较轻的猕猴不会离群单独医治，而是留在群体中，利用竹筏区域作为缓冲地带养精蓄锐。 [[来源2]]
   - 正文依据：若伤势较轻，通常不会将其带离群体单独医治...竹筏区域也成了他们的缓冲地带和心灵加油站
