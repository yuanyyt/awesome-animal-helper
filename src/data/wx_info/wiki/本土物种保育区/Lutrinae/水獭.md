# 水獭

- 场馆：[[本土物种保育区]]
- 学名：*Lutrinae*
- 文中昵称：澜沧、韩信、版纳、茶茶

## 趣事

1. 水獭有持续絮窝的习惯，会撕扯芭蕉根部的嫩皮拖回巢箱铺成软垫，甚至将新抽的小芭蕉嫩芽征用。 [[来源1]]
   - 正文依据：它们会撕扯芭蕉根部的嫩皮，拖回巢箱铺成软垫。新抽的小芭蕉常因此遭殃，嫩芽刚冒头就被它们“征用”了。
2. 饲养员加装喷头制造浅水域供水獭玩耍，水獭一家在此打滚踩水弄脏身体后，将其命名为“澜沧江”。 [[来源1]]
   - 正文依据：爸爸澜沧率先踩进去，妈妈韩信和小崽也跟着凑过来，一家子在这儿打滚、踩水，身上糊了一层泥。这么喜欢，那就浅浅命名“澜沧江”吧。
3. 幼崽长大后需自行下水捕猎获取食物，但母亲韩信仍习惯叼食物送到跟前，担心小崽饿着。 [[来源1]]
   - 正文依据：爸爸澜沧这儿，觉得小獭已经具备了自主觅食的能力，不再主动给予，幼崽想要进食，就得自行下水捕猎。
4. 雌性水獭韩信在固定的排泄点意外产下幼崽，随后父母将其衔回巢箱抚育。 [[来源2]]
   - 正文依据：幼崽便在这个意外的地点悄然降生了。韩信似乎没有立刻发现幼崽已经出生，转身又独自回了巢箱。
5. 新手父母轮流带娃，雄性澜沧全程留守巢箱照料幼崽，雌性韩信外出觅食。 [[来源2]]
   - 正文依据：最先走出巢箱寻找食物的，却是韩信，澜沧则全程留守在巢箱，专注照料幼崽。
6. 父亲澜沧会衔取干草和芭蕉皮整理巢箱，保持内部干燥，并提前铺垫休息处。 [[来源2]]
   - 正文依据：澜沧的表现格外细致，常常会就地取材...衔回巢箱，重新整理铺垫，始终让巢箱内部保持干燥
7. 父母先试吃食物筛选后喂给幼崽，若幼崽不吃则由父母吃掉，不浪费食物。 [[来源2]]
   - 正文依据：他们会先自己吃一部分，再衔取另一部分带回巢箱，让幼崽试着品尝；要是幼崽不愿意吃，他们再把食物吃掉
8. 水獭幼崽韩信是妈妈从“厕所”里捡回来的独生幼獭。 [[来源3]]
   - 正文依据：我是韩信家的独生幼獭，是妈妈从“厕所”里“捡”回来的！
