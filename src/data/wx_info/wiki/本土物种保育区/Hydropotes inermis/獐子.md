# 獐子

- 场馆：[[本土物种保育区]]
- 学名：*Hydropotes inermis*

## 趣事

1. 为了让救助的獐子更有安全感，饲养员利用树枝、竹叶等材料为它们搭建遮风避雨的棚子和遮蔽路线。 [[来源1]]
   - 正文依据：我们就利用树枝、竹叶、茅草等材料给它们增加了一些遮风避雨的棚子和行走路线中的遮蔽
2. 经过经验积累，红山动物园成功将救助的獐子放归到南京的湿地系统中。 [[来源1]]
   - 正文依据：经过了一些经验的积累以后，我们也终于将救助的獐子放归到南京的湿地系统中
3. 獐子专门挑选竹叶花椒最鲜嫩的芽尖品尝，避开带有浓郁气味的成熟叶子。 [[来源2]]
   - 正文依据：竹叶花椒的叶子自带浓郁的气味，但獐子偏偏钟情于这份独特的 “风味”，却也只在嫩芽阶段 “解馋”
4. 獐子扫光嫩芽后，未被啃食的植株在短时间内迅速长出新的嫩芽。 [[来源2]]
   - 正文依据：在獐子未曾光顾的仅仅一两天的时间里，竹叶花椒就抓住机会快速生长，长出了新的嫩芽
