# 小麂

- 场馆：[[唐家河]]
- 学名：*Muntiacus reevesi*
- 文中昵称：大王、奶昔、蜜瓜、椰果

## 趣事

1. 饲养员通过蹲守观察和美食脱敏训练，让原本敏感、见到人就会藏起来的小麂能够主动出现在面前进食。 [[来源1]]
   - 正文依据：我就尝试蹲在里面，用望远镜先观察，慢慢地再通过好吃的给它们做一些脱敏的训练。渐渐地，所有小麂都能出现在我面前吃东西了
2. 工作人员记录了5月到8月小麂角的脱落变化，形成换角日记分享给游客，科普其角会每年脱落的特征。 [[来源1]]
   - 正文依据：那段时间我们刚好捡到了它们脱落的角，就在5月到8月记录了角的脱落变化，形成换角日记，分享给来的游客
3. 饲养员通过从颈部到腹部、臀部的渐进式抚触建立信任，使天性敏感的小麂能配合完成肛温检测。 [[来源2]]
   - 正文依据：从去年开始，我们就靠着彼此的信任打底，一步一步、慢慢地做适应引导。先从它们接受度最高的颈部区域进行轻柔抚触...再慢慢将接触范围延伸至腹部、臀部区域
4. 目前可稳定为名为奶昔、蜜瓜、椰果的三只小麂采集有效体温数据。 [[来源2]]
   - 正文依据：目前，我们已经可以稳定为奶昔、蜜瓜、椰果三只小麂采集有效体温数据。
5. 小麂幼崽的肛温会略高于成年个体。 [[来源2]]
   - 正文依据：你知道嘛，小麂幼崽的肛温会略高于成年个体哦~
