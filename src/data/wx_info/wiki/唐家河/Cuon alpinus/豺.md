# 豺

- 场馆：[[唐家河]]
- 学名：*Cuon alpinus*

## 趣事

1. 刚到红山时，胆大的哥哥率先冲出去叼肉后迅速躲回内室，妹妹随后也模仿哥哥的行为取食。 [[来源1]]
   - 正文依据：他探出身，确认安全后火速冲上前叼起肉块，转身就缩回了内室；妹妹望着哥哥吃得香甜，几番犹豫后，终于鼓足勇气探头探脑地跑出来，叼起食物“嗖”地一下就躲了回去。
2. 在定位训练中，饲养员手持目标棒引导它们到指定位置，每次准确停驻都会获得食物奖励以加深信任。 [[来源1]]
   - 正文依据：饲养员手持目标棒，引导豺走到指定位置，一旦到位，立即给予食物奖励。从起初豺兄妹还带着几分犹豫到之后每一次准确的停驻，都是信任的又一次确认与加深。
3. 初次进入外场时，哥哥因紧张四肢颤抖，但在好奇心的驱使下试探着踩上土地并带领妹妹走出。 [[来源1]]
   - 正文依据：哥哥站在门口，身体带着几分谨慎，四肢微微颤抖...最终，好奇心赢了。他试探性地抬起前爪，轻轻点了点外场的土地...紧随其后的妹妹，见哥哥已然确认安全，也鼓足勇气
4. 适应环境后，豺会主动衔起饲养员铺好的羊草，拖到喜欢的角落重新铺成柔软的小窝。 [[来源1]]
   - 正文依据：在阳光下追逐嬉戏，甚至主动衔起饲养员铺好的羊草，拖到自己喜欢的角落，认真地重新铺成一个柔软的小窝。
