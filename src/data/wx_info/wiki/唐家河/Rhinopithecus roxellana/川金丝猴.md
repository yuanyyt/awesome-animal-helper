# 川金丝猴

- 场馆：[[唐家河]]
- 学名：*Rhinopithecus roxellana*
- 文中昵称：大春一家、六娃一家、重阳一家

## 趣事

1. 入冬后，川金丝猴会通过三三两两依偎或全家聚在栖架、巢箱等处紧紧贴在一起，形成圆融的“金球”来保存体温。 [[来源1]]
   - 正文依据：他们依旧会在觅食完后，三三两两依偎或一家聚在栖架、巢箱里、平台或是树干上，紧紧贴在一起，从一小团渐渐汇成一个个圆融的“金球”。
2. 川金丝猴家族中，雌猴之间发生争执后，往往一方主动靠近并紧紧抱住对方，以此作为和解的第一步，使不快烟消云散。 [[来源1]]
   - 正文依据：即便气氛一度紧张，他们也极少真正动手。往往在情绪稍缓的片刻，总会有一方主动迈出和解的第一步，缓缓靠近，然后紧紧抱住对方。
3. 幼猴通过拥抱建立友谊和包容，久别重逢时扑进彼此怀里撒欢，闹不愉快后轻抱致歉，同伴受惊时静静陪着紧贴对方。 [[来源1]]
   - 正文依据：久别重逢时，扑进彼此怀里撒欢；闹了不愉快后，主动凑上前轻抱致歉；忘突友谊找到新奇玩意儿、心情大好时，也会相拥着分享喜悦
4. 川金丝猴家族中存在“阿姨抱”现象，其他雌猴会主动抱抱、抚摸甚至抢婴护婴，帮助母猴觅食并让幼猴适应群体生活。 [[来源1]]
   - 正文依据：新生幼猴总会引来家族其他雌猴的格外关注，他们会主动凑上前抱抱幼崽、轻轻抚摸，甚至出现抢婴、护婴的小剧场。
5. 雄猴作为大家长会用拥抱强化与幼崽的亲子联结，幼崽主动撒娇蹭毛发，雄猴则轻轻环住幼崽或用温热身躯给予回应。 [[来源1]]
   - 正文依据：幼崽们常常主动凑到父亲身边撒娇，用小身子蹭着父亲的毛发，而雄猴也会轻轻环住幼崽，用温热的身躯给予回应，或是“爸爸巴士”即刻发车。
