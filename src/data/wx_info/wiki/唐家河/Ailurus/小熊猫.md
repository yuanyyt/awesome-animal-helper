# 小熊猫

- 场馆：[[唐家河]]
- 学名：*Ailurus*
- 文中昵称：仲夏、孟夏、夏夏

## 趣事

1. 饲养员将竹叶分散布置在栖架各节点与植被之间，增加了觅食难度，让小熊猫有更多探索机会。 [[来源1]]
   - 正文依据：饲养员也会将竹叶放在高处，分散布置在栖架各节点与植被之间，增加了觅食难度的同时，也能够让它们有更多探索的机会。
2. 小熊猫可以利用展区地面的灌木和高草作为天然视觉屏障，躲避游客视线。 [[来源1]]
   - 正文依据：周围是丛生的竹子、灌木与高草形成了的天然视觉屏障...小熊猫们可以选择在地面活动，来躲避游客的视线
3. 双胞胎兄妹仲夏和孟夏于2025年7月17日傍晚出生，哥哥仲夏比妹妹孟夏早出生20分钟。 [[来源2]]
   - 正文依据：20分钟后，第一只幼崽顺利诞生——这就是我们后来的哥哥“仲夏”。又过了10分钟，妹妹“孟夏”也平安落地。
4. 仲夏在三个多月大时患上肺炎，因血管细无法挂水，只能打针和雾化治疗。 [[来源2]]
   - 正文依据：确诊是肺炎后...没有办法进行常规的挂水治疗，只能依靠打针和雾化。
5. 仲夏在康复期间曾在氧舱里拆掉门上的胶条，饲养员认为这是身体好转的迹象。 [[来源2]]
   - 正文依据：接受治疗的第三天，就已经开始在氧舱里搞起了破坏，把氧舱门上的胶条全都拆掉了。
6. 仲夏病愈回家后兴奋追逐妈妈，导致夏娃受惊逃跑，但妹妹孟夏第一时间接纳了哥哥。 [[来源2]]
   - 正文依据：冲上去就想和妈妈贴贴。可当时孟夏已经处于有点“独立”的阶段了...夏娃的第一反应竟是：跑！
7. 仲夏通过少食多餐的专属恢复饮食计划追赶生长，最终健康状况追平妹妹。 [[来源2]]
   - 正文依据：饲养员给大病初愈的仲夏量身定制了专属恢复饮食计划...从清晨六七点的第一顿补奶，到深夜十一点的最后一次照料
